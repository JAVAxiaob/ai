# 第六章：循环神经网络（RNN / LSTM / GRU）

> 面向对象：零基础小白
> 本章目标：理解序列数据的建模方式，掌握 LSTM 的门控机制。

---

## 一、序列数据的独特性

让我们先问一个问题：句子「我讨厌这部电影」和「电影讨厌这部我」—— 相同的词，为什么意思完全不同？

**答案**：在序列数据中，**顺序（order）就是信息**。

**序列数据的特点**：

| 特点 | 例子 |
|:---:|:---|
| **长度可变** | 一句话可能 5 个词，也可能 50 个词 |
| **顺序敏感** | 「我打你」≠「你打我」 |
| **长期依赖** | 「it」指代什么？可能要追溯前面 5 个句子的主语 |
| **元素间相关** | 「an」后面必须接元音开头的词（语法约束）|

**RNN 家族是为序列而生的模型**：它维护一个「隐藏状态 h_t」，其中编码了到当前时间步为止看到的所有信息。

---

## 二、最简单的 RNN：Vanilla RNN

### 1. 核心公式

在每个时间步 t，RNN 做两件事：

`
h_t = tanh( W_hh @ h_{t-1} + W_xh @ x_t + b_h )
y_t = W_hy @ h_t + b_y
`

| 符号 | 含义 |
|:---:|:---|
| x_t | 第 t 个输入（词向量 / 音素 / 股价时刻 t） |
| h_{t-1} | 前一时刻的隐藏状态（携带「看到 t-1 为止的所有信息」）|
| h_t | 新的隐藏状态（融合了 x_t 的新信息）|
| W_hh | 「循环权重」— 把历史信息映射到新状态（所有时间步共享！）|
| W_xh | 「输入权重」— 把当前输入映射到隐藏空间 |
| y_t | 输出（预测下一个词 / 当前时刻的分类）|

**关键设计**：**所有时间步共享同一套 W_hh, W_xh, b_h**。这是「循环」二字的含义 —— 同一个操作在每个时间步反复执行。

**直觉理解**：把 RNN 想象成一个人读句子：
- 读第一个词 → 脑子中有一些理解 → h_1
- 读第二个词 → 在之前的理解上更新 → h_2
- ...
- 读完整个句子 → h_T 编码了整个句子的理解

### 2. 一步步手算一个小例子

**设**：x 是 2 维向量，h 是 2 维向量。

`
参数（全局共享）:
W_hh = [[0.5, 0.1], [0.2, 0.3]]
W_xh = [[0.4, 0.1], [0.1, 0.5]]
b_h = [0, 0]
h_0 = [0, 0] （初始隐藏状态）

时间步 t=1, x_1 = [1, 0]:
z = W_hh @ h_0 + W_xh @ x_1
  = [0,0] + [0.4, 0.1]
  = [0.4, 0.1]
h_1 = tanh([0.4, 0.1]) ≈ [0.380, 0.100]

时间步 t=2, x_2 = [0, 1]:
z = W_hh @ h_1 + W_xh @ x_2 = [0.200, 0.106] + [0.1, 0.5] = [0.300, 0.606]
h_2 = tanh([0.300, 0.606]) ≈ [0.291, 0.542]
`

**可以看到**：h_2 已经融合了 h_1 的信息（即 x_1 的信息）和 x_2 的信息。h_2 携带了前两步的历史。

### 3. 多种输出方式

**（1）每步一个输出**：词性标注、语音识别（每个时刻输出一个标签）
**（2）最后一步输出**：文本分类、情感分析（整个句子 → 一个类别概率）
**（3）多对多（编码-解码 / Seq2Seq）**：机器翻译（英文输入 → 中文输出）

## 三、RNN 的致命问题：梯度消失 / 梯度爆炸

考虑一个 50 步序列的反向传播。对 W_hh 求偏导，梯度含有一个**连乘积**：每多一步就多乘一次 W_hh 和一次 tanh derivative。

**梯度消失**：如果 W_hh 的最大特征值 < 1，连乘 t 次后变成 0（t=50 时 ≈ 0）→ 早期时间步的信息完全传不到梯度中 → 模型学不到「相隔 10 步以上的依赖」。

**梯度爆炸**：如果 W_hh 的最大特征值 > 1，连乘 t 次后指数增长 → 梯度变成 inf → loss 爆 NaN。

**解决梯度爆炸**：**梯度裁剪（Gradient Clipping）**：如果梯度 L2 norm 超过阈值（如 5），把它缩放回去。

**解决梯度消失**：RNN 本身没有好的解决办法 —— 这就是**为什么我们需要 LSTM / GRU**。

## 四、LSTM（Long Short-Term Memory）：引入「细胞状态 c_t」

**核心思想**：在普通 RNN 的 h_t 之外，再加一条「信息高速公路」——细胞状态 c_t。信息可以**几乎无损地在 c_t 上传播很多步**。

LSTM 用**三个门**（gate）来控制 c_t 上的信息流：

| 门 | 公式（简化） | 直觉 |
|:---:|:---:|:---|
| **遗忘门 f_t** | σ(W_f @ [h_{t-1}, x_t] + b_f) | 我该忘记多少旧的 c_{t-1}？ |
| **输入门 i_t** | σ(W_i @ [h_{t-1}, x_t] + b_i) | 我该写入多少新信息到 c_t？ |
| **候选 c̃_t** | tanh(W_c @ [h_{t-1}, x_t] + b_c) | 要写入的「新信息候选」（和普通 RNN 的 h 更新类似）|
| **输出门 o_t** | σ(W_o @ [h_{t-1}, x_t] + b_o) | 我该输出多少 c_t 的信息到 h_t？ |

**更新**：
`
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t
h_t = o_t ⊙ tanh(c_t)
`

其中 ⊙ 表示逐元素相乘（Hadamard product）。

### 关键直觉

**1. 细胞更新 c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t**

想象 c_{t-1} 是「你的长期记忆」（比如「这篇文章的主角是 Alice」）。

- f_t = 遗忘门（0~1 之间的数）：如果 f_t ≈ 1，表示「保留长期记忆」；如果 f_t ≈ 0，表示「忘记这段记忆」
- i_t = 输入门：控制「新信息 c̃_t 有多少进入长期记忆」
- 加和 = 「保留旧记忆的一部分」+「写入新记忆的一部分」

**2. 隐藏状态 h_t = o_t ⊙ tanh(c_t)**

h_t 是「你的工作记忆」—— 当前时刻可以输出给外界的信息。
- tanh(c_t) 把细胞状态压缩到 (-1, 1)
- o_t = 输出门：控制「长期记忆中有多少应该暴露给外界」

**3. 为什么这样能解决梯度消失？**

反向传播时，对 c 的梯度有一条通路：
`
dL/dc_t = dL/dc_{t+1} * dc_{t+1}/dc_t = dL/dc_{t+1} * f_{t+1}
`

每一步只乘一个 f（遗忘门）。如果 f ≈ 1（默认「保留」），梯度可以**无衰减地**传回去 100 步、1000 步。

**这就是 LSTM 能学到长期依赖的根本原因** —— 有一条梯度可以无损耗流动的「高速公路」。

**初始化技巧**：把遗忘门的偏置 b_f 初始化为 1（或更大），让 f_t 在训练初期接近 1，保证梯度能流动。

## 五、GRU：LSTM 的简化版

**GRU（Gated Recurrent Unit，Cho et al. 2014）** 把 LSTM 的 3 个门简化为 2 个门：

| 门 | 公式 | 直觉 |
|:---:|:---:|:---|
| **更新门 z_t** | σ(W_z @ [h_{t-1}, x_t] + b_z) | 「我该用多少新信息替换旧记忆」→ 合并了 LSTM 的遗忘门和输入门 |
| **重置门 r_t** | σ(W_r @ [h_{t-1}, x_t] + b_r) | 「计算候选时，我该多少程度忽略旧 h_{t-1}」|
| **候选 h̃_t** | tanh(W_h @ [r_t ⊙ h_{t-1}, x_t] + b_h) | 新信息候选 |
| **输出 h_t** | (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t | 「旧信息 × (1-z)」 + 「新信息 × z」|

**z_t = 0** → 完全保留旧记忆；**z_t = 1** → 完全替换为新记忆。

**和 LSTM 的对比**：

| 维度 | LSTM | GRU |
|:---:|:---:|:---|
| 门数量 | 3 个门（f, i, o）| 2 个门（z, r）|
| 状态 | 两个状态 c_t 和 h_t | 只有一个状态 h_t |
| 参数数量 | 4 组权重 | 3 组权重 → 少 25% |
| 训练速度 | 较慢 | 较快 |
| 效果 | 在需要长期记忆的任务上稍好 | 在中等序列上差不多 |

**工程经验**：小数据、短序列 → GRU 优先（参数少，不容易过拟合）。大数据、长序列 → LSTM。实际上两者效果很接近，现在有了 Transformer 后两者都用得少了。

## 六、文本处理流水线：从原始文本到 RNN 输入

**任务示例**：情感分类（句子是正面 / 负面）

**第 1 步：分词（Tokenization）**
「这个 电影 真 好看！」→ [「这个」, 「电影」, 「真」, 「好看」, 「！」]

**第 2 步：建立词典（Vocabulary）**
把训练集中出现的词映射到整数 ID。设置一个最低词频（如 5 次），低于阈值的词统一标记为 <UNK>（unknown）。
词典示例：{「这个」:1, 「电影」:2, 「真」:3, 「好看」:4, 「很」:5, 「差」:6, 「！」:7, 「<PAD>」:0, 「<UNK>」:8}

**第 3 步：词嵌入（Word Embedding）**
把每个 ID 映射成一个 d 维向量（如 d=128/256）。One-hot 向量（维度=|V|）不携带语义信息；稠密嵌入让相似词语义接近（如 Word2Vec、GloVe，或与模型端到端训练）。

**第 4 步：RNN/LSTM 编码**
把每个词的 embedding 按顺序喂给 LSTM，得到一串隐藏状态 h_1, h_2, ..., h_T。

**第 5 步：池化 + 分类**
用最后一个 h_T（或 mean/max pooling 所有 h_t）作为句子表示，再过一个 Linear + softmax 输出类别概率。

---

## 七、用 BoW + 朴素贝叶斯做一个简单基线（baseline）

在投入 LSTM 之前，必须先有一个**简单方法的 baseline**，否则你不知道 LSTM 的提升是真的还是幻觉。

**BoW（Bag-of-words，词袋模型）**：忽略顺序，只关心每个词出现几次。
「我 喜欢 这部 电影」→ [1, 1, 1, 1, 0, 0, ...]（向量长度 = 词典大小）

**朴素贝叶斯（Naive Bayes）**：用贝叶斯定理估计 P(类别 | 词向量)。

**效果**：BoW + 朴素贝叶斯在情感分类上往往能做到 75-85% 准确率。LSTM / Transformer 可能做到 85-92%。

**工程经验**：**永远先做一个简单 baseline**（逻辑回归 / 朴素贝叶斯 / LightGBM），再上深度学习。

## 九、问题与答案解析

### Q1：RNN/LSTM 为什么不能并行？每个时间步要等上一步完成吗？

**答**：是的，必须串行。h_t 的计算依赖 h_{t-1}，所以 t=1 完了才能算 t=2，t=2 完了才能算 t=3，...，一直到 t=T。

**对比 CNN / Transformer**：

| 模型 | 并行度 | 长序列计算时间 |
|:---:|:---:|:---|
| RNN | 串行（T 步）| 线性增长 O(T) |
| CNN | 完全并行（不同空间位置独立）| 常数（和 T 无关，只和层数有关）|
| Transformer | 完全并行（注意力一次看全部位置）| 可以并行一次算完，但复杂度 O(T^2 * d) |

**这是 RNN 在现代被 Transformer 取代的核心原因**：GPU 擅长并行，RNN 不能并行 → 在长序列上 GPU 利用率极低，训练极慢。

---

### Q2：为什么 LSTM / GRU 用 sigmoid 做门控，用 tanh 做候选值？

**答**：门控需要输出 (0,1) 之间的值（表示「打开多少」/「保留多少」）。sigmoid σ(z) = 1/(1+exp(-z)) 的值域正好是 (0,1)。

候选值 c̃_t 和 h̃_t 需要被压缩到 (-1, 1)，让信息在合理范围内，tanh 正好是这个范围。

**为什么不用 ReLU？**：
- ReLU 输出 [0, +∞)，不适合门控（>1 的概率会让 c_t 指数增长）
- 也不适合候选（正值输出无法表示负的相关性）

**为什么不用 softmax？**：softmax 会让输出和为 1，但不同门控应该是独立的（遗忘门和输入门不需要相互制约）。sigmoid 让每个门独立决定。

---

### Q3：在 LSTM 中，把一个句子的 h_1, h_2, ..., h_T 如何汇总成一个句子向量？

**答**：常用 4 种方式：

| 方式 | 做法 | 优点 | 缺点 |
|:---:|:---|:---:|:---|
| **只用最后一个 h_T** | 直接拿最后一步 | 简单，RNN 原生支持 | 对长序列早期信息可能被遗忘 |
| **mean pooling** | 对所有 h_t 取平均 | 平滑，对所有时间步等权重 | 「重要词」和「停用词」同等权重 |
| **max pooling** | 每个维度取所有时间步的最大值 | 捕捉「最强烈的特征」| 丢失时间顺序信息 |
| **注意力加权**（Attention） | 学一组权重 α_1...α_T，让 h = Σ α_t h_t | 自动学习「哪些词更重要」，可解释 | 额外参数 |

**现代默认**：对简单分类任务，mean/max pooling 够用。对需要可解释性 / 长序列，用 attention。

---

### Q4：词嵌入（Word Embedding）到底学到了什么？

**答**：两个神奇的现象：

**1. 语义相似度**：相似的词在嵌入空间中距离近
`
distance(猫, 狗) < distance(猫, 汽车)
`

**2. 向量类比（Word2Vec 的经典成果）**：
`
vector(国王) - vector(男人) + vector(女人) ≈ vector(女王)
vector(北京) - vector(中国) + vector(法国) ≈ vector(巴黎)
`

**直觉**：嵌入向量的不同维度编码了不同语义属性（「是否王室」「是否女性」「国家/首都」「比较级」）。向量相减 = 去掉一个属性，向量相加 = 加上一个属性。

**怎么学到的**：Word2Vec 的核心思想是「一个词可以由它周围的词来定义（分布假设 distributional hypothesis）」。用「中心词预测上下文」或「上下文预测中心词」训练。

**现代做法**：不单独训 Word2Vec，直接在 Transformer 中把 Embedding 层和整个模型一起端到端训练（BERT、GPT 就是这样）。

---

### Q5：Batch Size 对 RNN/LSTM 训练有影响吗？

**答**：有，而且比 MLP 更敏感。RNN 的每一步梯度都依赖前面所有步，**梯度路径长 → 梯度方差大 → 对 batch size 更敏感**。

- **过小的 batch**（1~4）：梯度噪声大，训练震荡，收敛慢
- **适中的 batch**（32~128）：梯度噪声足够小，SGD 稳定下降
- **过大的 batch**（>1024）：梯度泛化性下降，需要配合 warmup + 调整学习率

**经验**：LSTM 默认 batch size = 32 或 64；训练时一般用 **packed sequence**（忽略 padding 位置的梯度）；每个 batch 内的序列尽量按长度排序，减少 padding 比例。

---

### Q6：双向 LSTM（Bi-LSTM）是什么？为什么要用？

**答**：一个标准的 LSTM 从左到右读句子 → 每个 h_t 只包含「到 t 为止的上文信息」。

Bi-LSTM 再跑一个反向 LSTM（从右到左），每个位置的最终表示 = [h_t(forward), h_t(backward)]（拼接）。

**好处**：每个位置同时拥有「上文 + 下文」的完整信息。

**例子**：命名实体识别「Apple 发布了新款 iPhone」：
- t=0 的 Apple 仅从左到右时看不到任何上下文 → 不知道是公司还是水果
- Bi-LSTM: h_0(forward) + h_0(backward)（看完「发布了新款 iPhone」→ 知道是公司）→ 拼接后有完整信息

**什么时候需要**：序列标注、命名实体识别、机器翻译的 encoder、阅读理解 —— 几乎所有「需要看整个句子才能做判断」的任务。

**什么时候不需要**：**语言模型（生成下一个词）**只能用单向（因果）LSTM，不能偷看未来。

---

### Q7：RNN 和 1D-CNN 处理文本各有什么优势？

**答**：对比 TextCNN 和 RNN/LSTM：

| 维度 | RNN/LSTM | TextCNN |
|:---:|:---|:---|
| **速度** | 慢（串行）| 快（完全并行）|
| **长依赖** | LSTM 可以学到中等长度 | 固定感受野（核大小=3 → 只能看 3 个词）|
| **位置顺序** | 天然敏感 | 不那么敏感 |
| **小数据** | 容易过拟合（参数多）| 参数更少，小数据上更稳 |

**现在怎么办？**：2017 年 Transformer 出现后，在几乎所有 NLP 任务上同时超越了 RNN 和 CNN。但在：特别短的序列 + 小数据 → CNN 可能更快更准；边缘设备 → LSTM/GRU 推理更简单；作为对比 baseline → 都值得跑一次。

---

### Q8：LSTM 的 c_t 和 h_t 的区别到底是什么？

**答**：用一个「读书并做笔记」的类比：

- **c_t（细胞状态）= 你的长期记忆 / 读书笔记**：你读完整本书后记得的东西。稳定、变化慢。反向传播时梯度可以长期稳定流动（因为 f_t 接近 1）。

- **h_t（隐藏状态）= 你的工作记忆 / 当前注意力**：你正在读第 t 个词时脑子里活跃的内容。变化快。每个时间步对外输出的就是 h_t。由 o_t 控制从 c_t 取多少出来。

---

### Q9：LSTM 有 3 个门，如果去掉其中一个会怎样？

**答**：消融实验（ablation study）：

| 去掉哪个门 | 后果 |
|:---:|:---|
| **去掉遗忘门 f**（即 f ≡ 1）| 细胞状态永远累加 → c_t 无限增长 → 数值不稳定 / 信息溢出 |
| **去掉输入门 i**（即 i ≡ 1）| 每个新信息都被全盘写入 c_t → 新信息覆盖旧记忆 → 长期记忆能力丧失 |
| **去掉输出门 o**（即 o ≡ 1）| h_t = tanh(c_t)，失去「输出多少」的控制 → 不致命但性能下降 |
| **去掉 tanh（让 c̃ 是线性的）**| 两层 LSTM 的表达能力退化（线性+线性=线性）→ 需要 tanh 引入非线性 |

**经验**：LSTM 的三个门都有重要作用。大量实验证明 LSTM 默认设置几乎总是最优。

---

### Q10：如何让 LSTM 学到更长的依赖？

**答**：即使有了 LSTM，学习超过 100-200 步的依赖仍然困难。常用技巧：

1. 初始化遗忘门偏置为 1（让 f_t 初始接近 1，梯度更容易流回去）
2. 梯度裁剪（Gradient Clipping）：防止梯度爆炸
3. Skip Connection（类似 ResNet）：让 h_t = h_t + F(h_t, x_t)，增加梯度通路
4. Layer Normalization：在每个时间步对 h_t 归一化，稳定训练
5. Dropout on input/hidden：输入、隐藏状态、输出分别加独立的 Dropout mask
6. 更长的 BPTT 截断：默认 BPTT 只回传 30-50 步梯度；要学 100+ 步依赖需要调大
7. 更强的输入表示（BERT embedding 而不是 random embedding）
8. **用注意力（Attention）**：让模型显式地从任何时间步取信息（不需要靠隐藏状态传过去）→ Transformer 就是这个思路

**最后一条是终极答案**：只要算力够，**用 Transformer 代替 RNN**。注意力可以一步连通任何两个位置，不需要像 RNN 那样「接力传播」。

---

### Q11：怎么理解 BPTT（Backpropagation Through Time）？

**答**：BPTT 就是「把 RNN 按时间步展开成一个很长的前馈网络，然后正常反向传播」。

`
展开后（每个时间步的 RNN 展开）:
x_1 → Linear+tanh → h_1 → Linear+tanh → h_2 → ... → h_T → Linear → loss
         ↑                       ↑
       W_hh                    W_hh（同一个权重！）
`

**关键**：所有时间步共享同一套 W，所以 W 的梯度 = 每个时间步对 W 的梯度之和（sum over time）。

**工程细节**：BPTT 通常不回传整个序列长度（T=1000 太费内存/梯度不稳定），而是**截断**（truncated BPTT）。把长序列切成若干 30-50 长度的窗口，每个窗口内做 BPTT，窗口之间传递 h（状态继承但不回传梯度）。

## 本章小结

1. **RNN 核心**：维护一个隐藏状态 h_t，每步融合 x_t 和 h_{t-1}，编码到当前时刻的所有历史
2. **参数共享**：所有时间步用同一套 W_hh, W_xh —— 「同一个操作反复执行」
3. **梯度消失/爆炸**：反向传播时连乘 W_hh 导致；爆炸用梯度裁剪，消失靠 LSTM/GRU 解决
4. **LSTM 三要素**：遗忘门 f_t（保留多少旧记忆）+ 输入门 i_t（写入多少新信息）+ 输出门 o_t（暴露多少到 h_t）；细胞状态 c_t 是梯度流动的高速公路
5. **GRU 是 LSTM 简化版**：2 个门，一个状态，参数少 25%，中等任务效果接近
6. **文本处理流水线**：分词 → 词典 → Embedding → LSTM → Pooling → Linear → softmax
7. **Bi-LSTM**：同时从左到右和从右到左读 → 每个位置有完整上下文信息
8. **vs CNN / Transformer**：RNN 不能并行 → 慢；Transformer 全局注意力 + 并行 → 现在的默认
9. **工程最佳实践**：总是有一个简单 baseline（BoW + NB / LR），再上深度学习对比
