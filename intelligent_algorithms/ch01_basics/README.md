## 一、章节知识点

### 1.1 机器学习概述

**Tom Mitchell 定义**：用 E（经验 / 训练数据）在 T（任务）上获得 P（性能）改进。

三大学习范式：

- **监督学习**：数据带有标签。例如「房价预测」（回归，连续值）、「猫狗分类」（分类，离散值）。
- **无监督学习**：无标签。例如「把相似用户分组」（聚类）、「把100维特征压缩成2维」（降维）。
- **强化学习**：以奖励信号驱动智能体做决策，如 AlphaGo。

**核心数学直觉**：所有机器学习问题都可以抽象为三件套：
`
模型 y = f(x; θ)  +  损失 L(y, y_pred)  +  优化器 (θ ← θ - lr * ∇θ L)
`

### 1.3 第一个机器学习程序：手动线性拟合

**模型**：y = w * x + b

**损失（MSE）**：
`
MSE = (1/n) * Σ(y_pred - y_true)^2
`

**梯度下降更新**：
`
w ← w - lr * (2/n) * Σ(y_pred - y_true) * x
b ← b - lr * (2/n) * Σ(y_pred - y_true)
`
lr 叫学习率：太大震荡，太小收敛慢。

**对应代码**：irst_ml_program_demo(epochs=200, lr=0.01)
- 80 个随机样本，真实参数 w=2.5, b=3.0
- 200 轮梯度下降，每 40 轮打印一次 mse
- 最终参数 w≈2.42, b≈2.92

## 二、横向对比

### 本章方法 vs 后续章节方法

| 维度 | 第一章（手动线性拟合） | 后续章节（OLS / 树 / 神经网络） |
|------|----------------------|-------------------------------|
| 模型能力 | 只能拟合线性关系 | 非线性 / 高维 / 序列 / 图像 |
| 实现方式 | NumPy 手写梯度 | 解析解 / sklearn / 复杂框架 |
| 可读性 | ⭐⭐⭐⭐⭐ 每一步都清晰 | ⭐⭐⭐ 黑盒为主 |
| 数值稳定性 | 依赖学习率，可能震荡 | OLS 解析解稳定 |
| 适用场景 | 教学 / 理解梯度 | 工程 / 真实任务 |

### 梯度下降（第一章） vs 最小二乘 OLS（第二章）

- **梯度下降**：迭代式，通用任意可微损失；优点是可扩展到所有深度学习；缺点是要调学习率。
- **OLS 解析解**：θ = (X^T X)^{-1} X^T y，一步到位；缺点是特征巨大时矩阵求逆极慢。

### 直觉总结

第一章告诉你：**所有 ML 都是「参数 + 损失 + 优化」三件套**。后续章节只是模型越来越复杂，但三件套思想永远不变。
