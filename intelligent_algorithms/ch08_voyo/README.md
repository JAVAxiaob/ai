# 第八章：Voyo 算法

> 面向对象：零基础小白
> 本章目标：理解动量 + 自适应学习率的组合思想，实现一个 Adam 风格的优化器。

## 一、章节知识点

### 8.1 Voyo 算法原理

Voyo 是本项目自定义的教学用优化器，灵感来自 Adam（Kingma & Ba, 2014）。
它把两个关键改进结合在一起：

1. **动量（Momentum）**：维护梯度的指数移动平均，像惯性一样让优化方向更稳定；
2. **自适应学习率（RMSprop）**：每个参数有自己的学习率，历史梯度平方大的参数学习率小，反之亦然。

### 8.2 核心公式推导

给定可微目标函数 f(theta)，梯度 g_t = nabla_theta f(theta_t)，Voyo 的五步更新：

(1) m_t = beta1 * m_{t-1} + (1 - beta1) * g_t         # 一阶矩（动量）
(2) v_t = beta2 * v_{t-1} + (1 - beta2) * g_t * g_t     # 二阶矩（梯度平方）
(3) m_hat_t = m_t / (1 - beta1^t)                        # 偏差修正
(4) v_hat_t = v_t / (1 - beta2^t)
(5) theta_t = theta_{t-1} - lr * m_hat_t / (sqrt(v_hat_t) + epsilon)

超参数推荐值：beta1=0.9，beta2=0.999，epsilon=1e-8，lr=1e-3 ~ 1e-4。

目标函数：f(x, y) = (x-2)^2 + 0.5*(y+1)^2 + 3，理论最优 theta* = (2, -1)，f(theta*) = 3。

### 8.4 应用实例

Voyo / Adam 风格的优化器是当前深度学习的默认选择：

| 场景 | 为什么用 Adam 风格 |
|------|------------------|
| 训练大 Transformer（GPT、BERT） | 自适应 lr 让模型对各种参数量级稳定 |
| 图像分类（CNN） | momentum 加速收敛，少调参 |
| 强化学习（DQN、PPO） | 非平稳目标下更稳定 |
| 推荐系统（双塔 / DCN） | 稀疏/稠密特征混合下自适应 |

注意：Adam 并不一定是最好的。在需要极强泛化的图像任务上，带动量的 SGD 有时能泛化更好。

## 二、横向对比

### 主流优化器对比

| 优化器 | 核心思想 | 是否自适应 lr | 是否有动量 | 收敛速度 | 泛化表现 |
|-------|---------|-------------|----------|---------|---------|
| SGD | theta ← theta - lr * g | 否 | 否 | ⭐⭐ | ⭐⭐⭐⭐ |
| Momentum | v ← beta*v + g; theta ← theta - lr*v | 否 | 是 | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| RMSprop | 维护 g^2 的 EMA；除 sqrt(v) | 是 | 否 | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| Voyo / Adam | Momentum + RMSprop + 偏差修正 | 是 | 是 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| AdamW | Adam + 解耦的权重衰减 | 是 | 是 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐（目前最佳） |

### 学习率调度策略对比

| 策略 | 何时用 | 直觉 |
|------|--------|------|
| 固定 lr | 教学 / 简单问题 | 最简单 |
| Step LR | 每隔 N 轮乘 0.1 | 阶段性下降 |
| Cosine Annealing | 大模型训练 | 预热到余弦衰减 |
| Warmup + Cosine | Transformer 训练 | 前期 lr 小，稳定后再升高 |

### 本章（优化器）vs 其他章节（模型）

| 章节 | 角色 |
|------|------|
| 第二章（监督） | 模型家族（线性/树/KNN/NB） |
| 第五、六、七章（CNN/RNN/Transformer） | 模型家族 |
| 第八章（Voyo） | 训练算法：能应用到前面所有模型上 |

关键直觉：优化器和模型是正交的。你可以用 Voyo/Adam 去训练第二章的逻辑回归、第四章的 MLP、第五章的 CNN、第七章的 Transformer。模型决定能学到什么，优化器决定学得有多快、多稳。

### Voyo 相对 SGD 的优势

| 情况 | SGD | Voyo |
|------|-----|------|
| 参数尺度差异大 | 必须仔细归一化 | 自适应 lr 自动处理 |
| 损失曲面有狭长峡谷 | 来回震荡 | 动量顺坡而下 |
| 稀疏特征 | lr 对所有特征相同 | 每个参数自己的 lr |
| 小批量训练 | 噪声大 | EMA 平滑噪声 |
| 需要调参量 | lr 本身 + lr schedule | lr 默认 3e-4 即可 |
