## 一、章节知识点

### 4.1 神经网络原理 / 感知机

**神经元（Neuron）**：z = Σ w_i x_i + b，再经过一个激活函数 φ 得到输出  = φ(z)。

**感知机（Perceptron）**：1957 年 Rosenblatt 提出。
- 更新规则：若 y*(w·x + b) ≤ 0（错分），则 w ← w + lr*y*x, b ← b + lr*y；
- 只能解决**线性可分**问题；
- 对应代码：perceptron_demo(epochs=50, lr=0.1)，
  在简单二分类数据上通常 10 轮内达到 100% 准确率。

### 4.2 反向传播（Backpropagation）

**核心思想**：用链式法则从输出层往输入层逐层计算梯度。

**本章实现**（ackprop_demo(epochs=500, lr=0.05)）：
`
Layer 1 (隐藏层):  z1 = X @ W1 + b1,  a1 = ReLU(z1)
Layer 2 (输出层):  z2 = a1 @ W2 + b2,  a2 = sigmoid(z2)
Loss:              BCE = -mean(y*log(a2) + (1-y)*log(1-a2))
`
链式求导得到 dW1, db1, dW2, db2，随后用梯度下降更新。

**运行结果**：loss 从 ~0.7 逐步下降到 ~0.2，测试准确率 ~94%。

### 4.3 激活函数

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | σ(z) = 1/(1+e^-z) | 输出 [0,1]，概率解释；但 z 很大/很小时梯度趋近 0（梯度消失） |
| Tanh | tanh(z) | 输出 [-1,1]，零中心化；仍有梯度消失问题 |
| ReLU | max(0, z) | 正半轴梯度恒为 1，无消失；计算快；**负半轴死亡** |

本章 ctivation_demo() 画出三者的曲线，可视化保存在 output/ch04_activations.png。

### 4.4 损失函数

- **MSE**：mean((y - p)^2)，用于回归；缺点是当 p 接近 0/1 时对二分类梯度很小。
- **交叉熵 BCE**：-mean(y*log(p) + (1-y)*log(1-p))，用于分类；对置信度错误的样本惩罚大。

本章 loss_demo() 可视化对比 BCE 和 MSE 在 y=0/1 时的差异。

## 二、横向对比

### 单层网络 vs 多层网络

| 维度 | 感知机（单层） | 反向传播网络（多层） |
|------|--------------|--------------------|
| 能解决的问题 | 线性可分 | 可以近似任意连续函数（万能逼近定理） |
| 训练方式 | 错分即更新 | 梯度下降 + 链式法则 |
| 参数量 | O(d) | O(d * hidden) + O(hidden * out) |
| 可解释性 | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| 实现难度 | 5 行 | 50-100 行 |

### 激活函数选择对比

| 场景 | 推荐激活 | 理由 |
|------|---------|------|
| 二分类输出层 | sigmoid | 输出自然落在 [0,1] |
| 多分类输出层 | softmax | 归一化到概率分布 |
| 隐藏层（通用） | ReLU / GELU | 快 + 缓解梯度消失 |
| 小网络 / 需要双向信息 | tanh | 零中心，稳定 |
| LSTM 内部门 | sigmoid + tanh | 门控需 [0,1]，状态需 [-1,1] |

### 损失函数选择对比

| 任务 | 推荐损失 | 本章函数 |
|------|---------|---------|
| 回归（房价、年龄） | MSE / MAE | utils.mse |
| 二分类 | Binary Cross-Entropy | BCE |
| 多分类 | Categorical Cross-Entropy | （扩展） |
| 不平衡二分类 | Focal Loss | （扩展） |

### 本章 vs 第二章（浅层模型）vs 第五章（CNN）vs 第七章（Transformer）

| 章节 | 模型 | 输入形式 | 归纳偏置 | 数据规模 |
|------|------|---------|---------|---------|
| 第二章 | 线性/树/KNN | 表格向量 | 无 | 小→中 |
| 第四章 | MLP/反向传播 | 展平向量 | 通用（无结构先验） | 中 |
| 第五章 | CNN | 2D 图像 | **局部感受野 + 参数共享** | 中→大 |
| 第六章 | RNN/LSTM | 序列 | **时间顺序** | 中→大 |
| 第七章 | Transformer | 序列 / 任意 | **注意力 + 全局交互** | 大 |

> **关键直觉**：MLP 的缺点是「对所有特征一视同仁」，没有先验。
> 所以处理图像时我们使用 CNN（空间局部性），处理文本使用 Transformer（全局注意力）。
