# 第三章：无监督学习

> 面向对象：零基础小白
> 本章目标：在「没有正确答案」的数据中，自动发现结构和模式。

---

## 一、先讲一个场景：电商用户分组

假设你是一个电商数据分析师，手里有 1000 个用户的浏览数据：

| 用户 | 每月浏览次数 | 每次消费金额 | 浏览商品类别 |
|:---:|:---:|:---:|:---:|
| A | 2 | 50 元 | 主要日用品 |
| B | 30 | 2000 元 | 主要数码 |
| C | 25 | 1800 元 | 主要数码 |
| D | 3 | 80 元 | 主要日用品 |
| ... | ... | ... | ... |

这次你**没有标签**——没有人告诉你「哪些是高价值用户，哪些是价格敏感型用户」。你的任务是：**让算法自己把相似的用户归到一起**。

这就是**无监督学习**：只有输入，没有答案，让数据的结构自己说话。

## 二、K-means 聚类：把相似的点分到同一组

### 1. 直觉

K-means 的核心思想：
1. 先决定你想分成几组（K）
2. 在数据空间中随机放 K 个「中心点（centroid）」
3. 每个数据点把自己归到最近的中心点 → 形成 K 个小组
4. 每个小组重新计算自己的「真实中心」（该组所有点的均值）
5. 中心移动了 → 重新分配（第 3 步）
6. 重复 3~4 步，直到中心点不再移动（收敛）

### 2. 一步步手算（K=2）

**数据**（2D 可视化方便）：
A(1,1)、B(2,1)、C(1,2)、D(5,5)、E(6,5)、F(5,6)

**第 0 步**：随机选 2 个初始中心。假设：
- 中心 1 = A = (1, 1)
- 中心 2 = D = (5, 5)

**第 1 步：分配**，对每个点计算到两个中心的距离平方：

| 点 | 到中心1距离² | 到中心2距离² | 归到哪组 |
|:---:|:---:|:---:|:---:|
| A(1,1) | 0 | (4²+4²)=32 | 组 1 |
| B(2,1) | (1²+0²)=1 | (3²+4²)=25 | 组 1 |
| C(1,2) | (0²+1²)=1 | (4²+3²)=25 | 组 1 |
| D(5,5) | 32 | 0 | 组 2 |
| E(6,5) | (5²+4²)=41 | (1²+0²)=1 | 组 2 |
| F(5,6) | (4²+5²)=41 | (0²+1²)=1 | 组 2 |

组 1 = {A, B, C}，组 2 = {D, E, F}

**第 2 步：更新中心**，每组取均值：
- 新中心 1 = ((1+2+1)/3, (1+1+2)/3) = (1.33, 1.33)
- 新中心 2 = ((5+6+5)/3, (5+5+6)/3) = (5.33, 5.33)

**第 3 步：再分配**，用新中心再算一次距离。这次所有点的归属不变 → **算法收敛**，停止。

最终结果：
- 组 1 中心 (1.33, 1.33)：低活跃度 / 低消费用户
- 组 2 中心 (5.33, 5.33)：高活跃度 / 高消费用户

大功告成！

### 3. 数学形式化

**目标函数**：最小化每个点到其所属簇中心的距离平方和，也叫**SSE（Sum of Squared Errors）**或**惯性（inertia）**：

`
SSE = sum_k  sum_{x in cluster_k} || x - μ_k ||²
`

其中 μ_k 是第 k 簇的中心。

**K-means 的两步等价于**：
- **分配** (E-step)：固定中心 μ，把每个 x 分配给最近的 μ_k
- **更新** (M-step)：固定分配，把 μ_k 更新为该组的均值

每一步都不会让 SSE 变大 → **SSE 单调递减**，因此算法一定收敛。

### 4. 选择 K 值：肘部法则

K 是一个**超参数**（需要你自己设）。怎么选？

**直觉**：
- K 太小 → 不同的组被合并，簇内差异大，SSE 大
- K 太大 → 每个点自成一簇，SSE→0，但没有意义（过拟合）

**肘部法则（Elbow Method）**：
1. 试 K=1, 2, 3, ..., 15
2. 对每个 K 训练 K-means，记录 SSE
3. 画 SSE 随 K 变化的曲线
4. 曲线会快速下降 → 然后慢慢下降 → 找「拐弯处」（像手肘一样）
5. 那个拐弯处的 K 就是推荐值

**另一种方法 — Silhouette 系数**：衡量每个样本「在自己簇内有多紧 + 离隔壁簇有多远」，范围 [-1, 1]，越接近 1 越好。

### 5. 初始中心敏感问题

K-means 对初始中心敏感 —— 如果不巧选到了两个很接近的初始中心，可能会收敛到一个差的局部最优。

**解决方法**：
1. **K-means++**：聪明地选择初始中心（先随机选一个，后续每个中心点都倾向离已选中心远一些），标准实现（sklearn 默认）。
2. **多初始化**：重复做 10~20 次不同的随机初始化，取 SSE 最小的那一次结果。

### 6. K-means 的假设和局限

| K-means 擅长 | K-means 不擅长 |
|:---:|:---:|
| 球状、大小相近、密度相近的簇 | 非凸的、长条形状的簇 |
| 各维度尺度相近的数据（记得归一化！）| 簇大小差异巨大 |
| 数据量很大（K-means 是线性复杂度 O(n)）| 有异常值的簇（均值被拉偏）|

**典型失败案例**：两个半月形的数据（如 sklearn 的 make_moons），K-means 会切出奇怪的分界线。这种情况需要 **DBSCAN（密度聚类）**或谱聚类。

## 三、主成分分析（PCA）：把数据「压薄」

### 1. 直觉：为什么要降维？

- **可视化**：你有 100 维数据，人眼只能看 2D/3D，需要把它压到 2 维
- **减少计算量**：1000 维 → 100 维，下游模型快 10 倍
- **去噪**：数据的很多维度其实是噪声，去掉后模型更准
- **去冗余**：比如「身高厘米」和「身高英寸」同时存在 → 几乎线性相关，可以合并

**PCA 的目标**：找到 d' 个正交方向，使得数据投影到这些方向上后，**保留的方差最大**。换句话说：用尽量少的维度，留住尽量多的信息。

### 2. 一步步手算

**数据**（5 个 2 维点，我们故意让它们沿一条斜线分布）：
(2.5, 2.4)、(0.5, 0.7)、(2.2, 2.9)、(1.9, 2.2)、(3.1, 3.0)

**第 1 步：中心化**（每个维度减去该维度的均值）

均值 mean = ((2.5+0.5+2.2+1.9+3.1)/5, (2.4+0.7+2.9+2.2+3.0)/5) = (10.2/5, 11.2/5) = (2.04, 2.24)

中心化后 X：
`
[0.46, 0.16]
[-1.54, -1.54]
[0.16, 0.66]
[-0.14, -0.04]
[1.06, 0.76]
`

**为什么要中心化？** 因为我们接下来要算协方差矩阵（衡量各维度围绕均值的波动），不中心化的话「均值大小」会被当成方差的一部分，误导主成分方向。

**第 2 步：计算协方差矩阵 Σ**

`
Σ = (1/(n-1)) * X^T @ X
`

（除以 n-1 而不是 n：统计学上的无偏估计。）

`
X^T @ X =
[[0.46²+(-1.54)²+0.16²+(-0.14)²+1.06²,   0.46*0.16+(-1.54)*(-1.54)+0.16*0.66+(-0.14)*(-0.04)+1.06*0.76],
 [对称,                                0.16²+(-1.54)²+0.66²+(-0.04)²+0.76²]]
`

计算得到：
`
Σ ≈ [[0.675, 0.612],
     [0.612, 0.717]]
`

**解读协方差矩阵**：
- 对角线 0.675, 0.717：x1 和 x2 各自的方差
- 非对角线 0.612：x1 和 x2 的协方差（为正，说明 x1 大时 x2 也大，正相关）

**第 3 步：对 Σ 做特征值分解**

求 Σ v = λ v，即 det(Σ - λI) = 0：

`
|0.675-λ, 0.612    | = 0
|0.612,   0.717-λ|

(0.675-λ)(0.717-λ) - 0.612² = 0
λ² - 1.392λ + 0.484 - 0.375 = 0
λ² - 1.392λ + 0.109 = 0
`

解得 λ1 ≈ 1.284, λ2 ≈ 0.108

**第 4 步：选主成分**

按特征值从大到小排列，对应的特征向量就是主成分方向：
- PC1（第一主成分）：对应 λ1=1.284，方向向量 ≈ (0.68, 0.73)
- PC2（第二主成分）：对应 λ2=0.108，方向向量 ≈ (-0.73, 0.68)

**第 5 步：决定保留几个主成分**

解释方差比例 = λ / sum(λ) = 1.284 / (1.284+0.108) ≈ **92%**

**直觉**：沿 PC1 方向的方差占总方差 92%！只保留 PC1（1 维），就保留了 92% 的信息。数据从 2D 压到 1D，几乎没损失。

**第 6 步：投影**

把每个样本 x 投影到保留的主成分上：

`
z = x @ V_selected
`

比如对 A(2.5, 2.4) 中心化后 = (0.46, 0.16)：
z = 0.46*0.68 + 0.16*0.73 ≈ 0.313 + 0.117 = **0.430**

得到 1 维的压缩表示。

### 3. 如何选主成分数 d'？

**方法 1：解释方差 ≥ 95%** 最常用。按 λ 排序，累加解释方差直到达到 95%。

**方法 2：Scree 图 + 肘部法则**，类似 K-means，找 λ 下降的「拐弯点」。

**方法 3：特征值 > 1（Kaiser 准则）**，只保留方差 ≥ 1 原特征的主成分（因为原数据标准化后方差=1，保留「至少等于一个原始特征信息量」的主成分）。

### 4. PCA 的意义和局限

**PCA 的意义**：
- 是最简单、最通用的降维方法
- 主成分是正交的（相互独立）—— 对需要独立特征的模型（如线性回归）很友好
- 计算高效：只需要一次特征值分解

**PCA 的局限**：
- 只能捕捉**线性**关系。如果数据在低维流形上（比如瑞士卷 Swiss Roll），PCA 会把它压扁而不是展开 → 需要 t-SNE 或 UMAP 等非线性降维
- 主成分可能没有物理意义（「第一个主成分 = 0.68×年龄 + 0.73×收入」—— 这是什么东西？），解释性差
- 对尺度敏感：必须先做标准化！

## 四、层次聚类：用树状图组织数据

### 1. 直觉：从「每个人自己是一组」开始

层次聚类（Agglomerative）自底向上：
1. 开始时每个样本都是独立的簇（n 个样本 → n 个簇）
2. 每次把「最相似的两个簇」合并
3. 重复直到只剩 1 个簇

**结果**：一个**树状图（dendrogram）**，纵轴表示合并时的距离（高度），横轴是样本。

**怎么决定最终簇数？**：在树状图上「横切一刀」，切的高度决定簇数。

### 2. 簇之间的距离怎么定义？（Linkage 方法）

| Linkage 方法 | 定义 | 优点 | 缺点 |
|:---:|:---|:---:|:---|
| **Single** | 两簇样本对的**最小**距离 | 能发现非凸的形状 | 对噪声敏感，容易链式合并 |
| **Complete** | 两簇样本对的**最大**距离 | 倾向紧凑的球形簇 | 对大簇不利 |
| **Average** | 两簇样本对距离的**平均** | 折中方案 | 无明显缺点 |
| **Ward**（最常用）| 合并后簇内方差的增量 | 倾向同样大小的簇，稳定 | 只适合欧氏距离 |

**工程默认**：不确定就用 **Ward**。

### 3. 手算演示（用 Single linkage）

**数据**：A(1,1), B(2,1), C(5,5), D(6,5)

**距离矩阵**（欧氏距离，对称）：

|  | A | B | C | D |
|:---:|:---:|:---:|:---:|:---:|
| A | 0 | 1 | √32≈5.66 | √41≈6.40 |
| B | - | 0 | √18≈4.24 | √32≈5.66 |
| C | - | - | 0 | 1 |
| D | - | - | - | 0 |

**第 1 步**：最小距离 = 1（A-B，C-D 并列），选一个先合并，比如把 {A} 和 {B} 合并成 {A,B}

**第 2 步**：重新计算簇 {A,B} 到 C、D 的距离（Single linkage 取最小）：
- dist({A,B}, C) = min(d(A,C), d(B,C)) = min(5.66, 4.24) = 4.24
- dist({A,B}, D) = min(d(A,D), d(B,D)) = min(6.40, 5.66) = 5.66
- dist(C, D) = 1

最小距离 = 1，合并 {C} 和 {D}。

**第 3 步**：合并 {A,B} 和 {C,D}（距离 4.24），只剩 1 组，停止。

树状图高度：A-B 和 C-D 在高度 1 处合并，两组在高度 4.24 处合并。

### 4. 层次聚类 vs K-means

| 维度 | 层次聚类 | K-means |
|:---:|:---|:---|
| 是否需要先指定 K | 不需要（可以后看 dendrogram 选） | 必须先指定 K |
| 时间复杂度 | O(n² log n) — 对大 n 很慢 | O(n·K·iter·d) — 线性，适合大数据 |
| 结果是否确定性 | 是（给定 linkage 唯一） | 否（依赖随机初始中心） |
| 能发现非凸簇吗 | ⭐⭐（single linkage 可以） | ❌（只能球状） |
| 可视化辅助 | dendrogram 展示层次结构 | 画散点 + 中心 |
| 大数据 n > 1 万 | ❌ 内存爆炸、太慢 | ✅ 首选 |

**经验**：数据小（n<1000）→ 用层次聚类 + dendrogram 分析结构；数据大 → K-means。

## 五、三种无监督方法横向对比

| 维度 | K-means | PCA | 层次聚类 |
|:---:|:---|:---|:---|
| **目标** | 发现 K 个簇 | 找到方差最大的方向，降维 | 构建聚类层次树 |
| **超参数** | K（簇数）| d'（保留维度数）| K 或 距离阈值 + linkage |
| **时间复杂度** | O(n·K·iter·d) 线性 | O(min(n,d)²·d) | O(n²·log n) 二次 |
| **能发现非凸簇吗** | ❌ 不行 | ❌ 不行（本质线性） | ⭐⭐⭐（single linkage 可以）|
| **对初始化敏感** | 高 | 无（特征值分解唯一） | 低 |
| **输出是否唯一** | 否（随机初始化） | 是 | 是（给定 linkage） |
| **对数据规模** | 大、中、小都可 | 大、中、小都可 | 小数据专用 |
| **如何评估效果** | SSE / Silhouette / 外部指标 | 解释方差比例 | dendrogram 观察 + 外部指标 |

## 六、无监督学习如何评估？（「没有答案怎么算准不准？」）

### 1. 内部指标（不需要真实标签）

**Silhouette 系数**：对每个样本 i：
`
a_i = i 到同簇其他样本的平均距离（簇内紧密度）
b_i = i 到最近的隔壁簇所有样本的平均距离（簇间分离度）
s_i = (b_i - a_i) / max(a_i, b_i)
`

s_i ∈ [-1, 1]，越接近 1 越好（样本在自己簇内很紧，离隔壁簇很远）；接近 0 表示在边界上；负值表示可能分错了簇。

**其他**：Calinski-Harabasz 指数（簇间方差 / 簇内方差）、Davies-Bouldin 指数（越低越好）

### 2. 外部指标（需要真实标签）

如果有真实标签（比如在公开 benchmark 数据集 iris 上）：

**ARI（Adjusted Rand Index）**：衡量「预测的簇和真实类别」的一致性，调整了随机猜测的基线。范围 [-1, 1]，1 为完美。

**NMI（Normalized Mutual Information）**：信息论度量，衡量两个划分共享的信息。范围 [0, 1]，1 为完美。

**纯度（Purity）**：每个簇以多数类为该簇预测类，计算准确率。范围 [0, 1]。

### 3. 下游任务评估（最实用）

无监督学习是中间步骤，最终看：
- 用 K-means 得到的簇作为特征，喂给监督学习，**监督任务的准确率有没有提升**？
- 用 PCA 降维后，**下游模型的训练速度提升了多少，准确率下降了多少**？
- 聚类后**人工检查**几个簇的样本，看它们是否语义上相似（比如都是「母婴用品用户」）

## 八、问题与答案解析

### Q1：K-means 一定能收敛吗？会收敛到全局最优吗？

**答**：**一定收敛**（SSE 每轮单调递减且有下界 0），但**不一定收敛到全局最优**。算法对初始中心敏感，可能卡在一个局部最优。

**直观理解**：想象 SSE 是一片有很多「山谷」的地形。K-means 每轮沿当前山谷滚到底，但起始位置决定了你滚到哪一个山谷。山谷越深（SSE 越小）越好。

**工程解决**：多初始化几次（sklearn 默认 n_init=10），取 SSE 最小的一次；或用 K-means++ 初始化。

---

### Q2：如果数据分布是两个半月形，K-means 效果会怎样？

**答**：会很差。K-means 隐含假设簇是球形的、大小相近、密度相近。半月形的数据会被 K-means 沿直线切成奇怪的块。

**解决方案**：
1. **DBSCAN（密度聚类）**：按「高密度区域」定义簇，能发现任意形状
2. **谱聚类（Spectral Clustering）**：先用样本相似度矩阵的特征向量做嵌入，再在新空间用 K-means
3. **Gaussian Mixture Models（GMM）**：允许椭圆形状（每个簇是一个高斯分布，可以扁、可以斜），比 K-means 更灵活

---

### Q3：PCA 为什么要先做标准化 / 归一化？

**答**：PCA 找「方差最大」的方向。如果一个特征的单位是「年收入（元）」，方差可能是 1e8；另一个是「年龄（岁）」，方差可能是 100。前者的方差大 100 万倍，**PCA 的第一个主成分基本等于年收入这个特征**，其他信息被淹没。

**规则**：只要用 PCA，**先标准化每个特征到均值 0、方差 1**（StandardScaler）。如果你已经确认所有特征量纲相同，可以跳过，但一般不省这一步。

---

### Q4：PCA 能做特征选择吗？

**答**：**不能**（至少不是传统意义上的特征选择）。PCA 做的是**特征抽取（feature extraction）**：
- 原来的特征是 [年龄, 收入, 消费频率]
- PCA 后变成 [0.7×年龄 + 0.6×收入 + 0.2×消费频率, -0.5×年龄 + 0.3×收入 + 0.8×消费频率]

新特征是**所有老特征的线性组合**，你失去了「哪个原始特征重要」的可解释性。

如果你的目标是**特征选择（选出最有用的原始特征子集）**，用：
- 相关性分析 / 互信息
- L1 正则化（Lasso → 部分 w 变 0）
- 基于树模型的 feature_importances_
- 递归特征消除 RFE

---

### Q5：PCA 的解释方差 = 95% 和 = 99% 有什么区别？

**答**：95% 已经保留了大部分信息，压缩率高（1000 维 → 可能 50 维），是工程上最常用的阈值。99% 保留更多信息，但压缩率低很多（1000 维 → 可能 200 维），速度慢、可能还保留了一些噪声。

**经验**：
- 可视化目的：固定 2 或 3 个 PC
- 下游模型降维：95% 作为默认
- 数据质量好 / 维度不高（<50）：有时根本不需要 PCA
- 觉得过拟合：把解释方差降一降（85-90%），让压缩更激进，强制模型用更少信息

---

### Q6：层次聚类选择哪种 linkage？

**答**：经验法则：
- **默认试 Ward**：大多数情况稳定、好用，倾向产生大小均匀的簇
- **数据有噪声 / 异常值**：Average linkage 更稳健
- **数据是非凸形状**：Single linkage 能发现长条、弯弯的簇，但对噪声敏感（可能产生「链式效应」，一个一个点连成一长串）
- **Complete linkage**：当你知道簇是紧凑的球形时

**更好的做法**：不是只试一种，而是多种 linkage 都跑一遍，对照 dendrogram 和 Silhouette 系数看哪个更合理。

---

### Q7：无监督学习和监督学习是什么关系？可以结合吗？

**答**：可以很好地结合。常见的组合方式：

1. **先无监督后有监督（Pipeline）**：先用 PCA 降维，然后用逻辑回归。降维减少了冗余特征，有时会提升监督模型泛化（去噪）。
2. **用无监督做特征工程**：用 K-means 得到每个样本到 K 个簇中心的距离，作为新特征拼到监督模型里。
3. **Deep Cluster（先聚类后分类）**：在图像/文本数据上先用无监督聚类得到伪标签，再用伪标签预训练一个深度模型，最后用少量真标签 fine-tune。这是无监督/自监督学习的核心思想。
4. **半监督学习**：大部分样本无标签，少量有标签。先用 K-means 对无标签样本聚类，同一簇的样本大概率同类别 → 扩充标签集。

---

### Q8：t-SNE 和 UMAP 是什么？和 PCA 有什么关系？

**答**：PCA 是**线性**降维方法，t-SNE 和 UMAP 是**非线性**降维方法，主要用于**可视化**（不是用于下游建模）。

| 方法 | 性质 | 保留的信息 | 复杂度 |
|:---:|:---:|:---:|:---:|
| PCA | 线性 | 全局方差最大 | O(min(n,d)²·d) |
| t-SNE | 非线性 | 局部近邻关系 | O(n²)，慢 |
| UMAP | 非线性 | 拓扑结构（局部 + 一定全局） | 较快，比 t-SNE 快 |

**直觉**：PCA 像「把一个 3D 球压扁成 2D 圆片」（保留整体大小）；t-SNE 像「把一张褶皱的纸展平」（让挨在一起的点继续挨在一起，但远处的距离不可信）。

**使用建议**：
1. **永远先用 PCA**：快、简单、看看线性结构够不够
2. PCA 做不好 → **试试 t-SNE / UMAP**
3. t-SNE/UMAP 主要用于**可视化探索**，不建议把它们的输出喂给下游模型（因为距离是「相对局部」的，没有全局意义）
4. t-SNE/UMAP 的困惑度（perplexity）/ n_neighbors 对结果影响很大，多试几个值

---

### Q9：聚类数量 K 怎么选？有什么实用流程？

**答**：一个实用流程：

`
1. 用不同的 K（如 2~15）跑 K-means
2. 记录每个 K 的 SSE（inertia）
3. 画 SSE vs K 的肘部图，找拐弯点 → 得到 K1
4. 再画 Silhouette 系数 vs K，找最大的几个 → 得到 K2
5. 再画 Calinski-Harabasz 指数 vs K → 得到 K3
6. K1、K2、K3 三者参考，结合业务常识（你期望几类用户？）选一个 K
7. 最终检查：在 K 值下，每个簇至少有 5% 的样本，人工抽样看语义一致性
`

---

### Q10：K-means 对异常值敏感，怎么处理？

**答**：两种思路：

**方法 1：先检测并移除 / 裁剪异常值**
- 用 Isolation Forest、DBSCAN、或简单的 IQR 方法（1.5×IQR 以外定义为异常）
- 或者对特征做 clipping（封顶在 1% / 99% 分位数）

**方法 2：用对异常值鲁棒的聚类算法**
- **K-medoids（PAM）**：和 K-means 类似，但中心必须是某个真实样本（用「中位数」思路而不是均值），对异常值更鲁棒
- **Gaussian Mixture Models**：每个样本有一个「属于该簇的概率」，不是 0/1 硬分配，异常样本可以被分配为低概率
- **DBSCAN**：密度聚类，天然把「低密度区域」标记为噪声 → 异常点自动被排除

---

### Q11：层次聚类的 dendrogram 怎么读？

**答**：
- 横轴：样本（或样本 ID）
- 纵轴：合并时的距离（也叫 height / linkage distance）
- 两个样本的「树枝」在什么高度合并 → 说明它们在那个距离上被认为「相似到可以合并」
- 高的合并 = 差异大；低的合并 = 差异小
- **怎么决定 K**：在 dendrogram 上画一条水平线，看它穿过多少根「竖线」 → 就是 K
- 选那条线的高度一般在「最长竖线」附近，那是数据结构变化最大的地方
- 注意：dendrogram 的横轴排列只是为了画图清晰，**相邻的样本不一定相似**（要看竖线高度）

---

### Q12：K-means 距离一般用欧氏距离，但我有分类特征（比如城市）怎么办？

**答**：K-means 的数学推导（均值最小化 SSE）本质上假设了欧氏距离。如果有分类特征：

1. **One-Hot Encoding**：把「城市」变成 [1,0,0]、[0,1,0] 等向量 → 然后和其他数值特征拼起来 → 用 K-means。缺点：One-Hot 产生 0/1 特征，和数值特征的尺度不一致，需要归一化。

2. **K-prototypes**：专门为「混合类型特征」设计的 K-means 变种。数值特征用欧氏距离，分类特征用匹配数（0/1 距离）。Python 有 kmodes 库。

3. **先用 embeddings**：如果分类特征有顺序关系（城市可以用人口、GDP、消费水平等数值特征表示），用这些代替。

4. **换一个算法**：DBSCAN 可以自定义距离函数 → 自己实现一个混合距离。

---

## 本章小结

1. **K-means**：K 个中心、分配-更新交替、收敛一定但可能局部最优、需要归一化、对初始中心敏感、擅长球状簇
2. **PCA**：中心化 → 协方差矩阵 → 特征值分解 → 取前 d' 个主成分 → 投影，线性降维，解释方差比例衡量保留了多少信息
3. **层次聚类**：自底向上合并，dendrogram 可视化结构，linkage 选择决定合并方式，小数据首选
4. **评估**：Silhouette 系数 / CH 指数（内部），ARI / NMI（需要标签），下游任务效果（最实用）
5. **非线性降维**：t-SNE / UMAP 用于可视化，不建议作为下游模型输入
6. **K 选择**：肘部图 + Silhouette + 业务常识，没有绝对正确答案
7. **和监督学习结合**：PCA 降维后喂给监督模型、用聚类距离作为新特征等常见 Pipeline
