# 第二章：监督学习

> 面向对象：零基础小白
> 本章目标：理解 5 种最常用的监督学习算法，并能在真实数据上使用它们。

---

## 一、先讲一个真实场景：预测顾客是否点击广告

想象你是一个电商公司的数据科学家。你有这样的数据：

| 顾客ID | 年龄 | 收入 | 网站停留时间 | 是否点击了广告（标签） |
|:---:|:---:|:---:|:---:|:---:|
| 1 | 25 | 3000 | 10分钟 | ✅ 是 |
| 2 | 55 | 8000 | 2分钟 | ❌ 否 |
| 3 | 32 | 5000 | 8分钟 | ✅ 是 |
| 4 | 48 | 7500 | 3分钟 | ❌ 否 |

你的任务是：给一个新顾客（年龄28，收入4500，停留6分钟），**预测 TA 会不会点击广告？**

这就是**监督学习**——输入（年龄、收入、停留时间）+ 标签（是/否）→ 学出一个「预测函数」。

**监督学习分两大类**：
- **回归**：预测一个连续数（预测点击概率 0.73）→ 本章线性回归
- **分类**：预测一个类别（是/否）→ 本章逻辑回归、决策树、KNN、朴素贝叶斯

## 二、线性回归（Linear Regression）—— 「画一条最准的直线」

### 1. 模型形式

线性回归假设输入和输出的关系是**一条直线**（高维是超平面）：

`
y_pred = w1*x1 + w2*x2 + ... + wd*xd + b
`

用矩阵写法更简洁：y_pred = X @ w + b

| 符号 | 是什么 | 在广告例子里 |
|:---:|:---|:---|
| x1, x2, ..., xd | d 维输入特征 | x1=年龄, x2=收入, x3=停留时间 |
| w1, w2, ..., wd | d 个权重（每个特征的重要性）| w1=年龄影响，w2=收入影响... |
|  | 偏置 / 截距 | 所有特征为 0 时的预测值 |
| y_pred | 预测输出 | 预测点击的「倾向值」|

### 2. 怎么学 w 和 b？—— 最小二乘法

我们要找一条直线，让它「和所有数据点的距离平方和最小」。这叫**最小二乘法**（Ordinary Least Squares, OLS）。

**损失函数：均方误差 MSE**

`
MSE = (1/n) * sum( (y_pred_i - y_true_i)^2 )
    = (1/n) * || X @ w + b - y ||^2
`

### 3. 为什么是平方而不是绝对值？

| 取平方 (MSE) | 取绝对值 (MAE) |
|:---:|:---:|
| 处处可导，可以用微积分求最小值 | y_pred=y_true 处不可导 |
| 对大误差惩罚重，模型优先修正「差很多」的点 | 线性惩罚，对异常值更鲁棒 |
| 有解析解（闭式解） | 需要迭代求解（如 subgradient） |
| 数学性质好（高斯噪声假设下是最大似然估计）| 数学上不那么优雅 |

**一句话**：绝大多数场景选 MSE；只有你**明确**知道数据有异常值时才用 MAE。

### 4. 两种方法找最优 w 和 b

#### 方法 A：解析解（直接解方程）

对 b 做一个技巧：把每个 x 加一个恒为 1 的维度（对应 b），于是模型变成 y = X_aug @ θ，其中 θ = [w; b]，X_aug 的最后一列全是 1。

对 MSE 求导令其等于 0：

`
∂/∂θ ( (1/n) || X_aug θ - y ||² ) = (2/n) X_aug^T (X_aug θ - y) = 0
`

解得：

`
θ = (X_aug^T @ X_aug)^{-1} @ X_aug^T @ y
`

这就是**解析解**，一步到位得到最优参数。

**什么时候用解析解**：特征数 d 不大（< 10000），数据也不大（< 100 万）时，直接用。

#### 方法 B：梯度下降（迭代法）

当 d 很大 / 数据很大时，矩阵求逆 O(d³) 算不动。用梯度下降：

`
∂MSE/∂w = (2/n) * X^T (X @ w + b - y)
∂MSE/∂b = (2/n) * sum(X @ w + b - y)
`

每步更新：

`
w ← w - lr * ∂MSE/∂w
b ← b - lr * ∂MSE/∂b
`

迭代 200~1000 次后，w 和 b 会收敛到接近解析解的值。

### 5. 手算一个具体例子

**数据**：面积 = [50, 60, 70, 80], 房价 = [120, 150, 180, 210]

**构造成增广矩阵**（每一行 = [面积, 1]）：
`
X_aug = [[50, 1], [60, 1], [70, 1], [80, 1]]
y = [120, 150, 180, 210]
`

**计算 X_aug^T @ X_aug**：
`
= [[50*50+60*60+70*70+80*80, 50+60+70+80],
   [50+60+70+80,           1+1+1+1]]
= [[17400, 260],
   [260,   4]]
`

**求逆矩阵**（略过具体计算，用 numpy）：
`
inv([[17400, 260], [260, 4]]) ≈ [[0.001, -0.065], [-0.065, 4.35]]
`

**最终 θ = inv(X^T X) @ X^T @ y = [3, -30]**

所以模型是：**房价 = 3 × 面积 - 30**

## 三、逻辑回归（Logistic Regression）—— 「预测概率而不是数值」

### 1. 为什么不直接用线性回归做分类？

回到广告点击例子：如果用线性回归预测 0/1 标签，会有两个致命问题：

1. **输出可能是 -2 或 3.7**（不是概率！不能解释）
2. **被极端点严重拉偏**：一个特别异常的样本会把整个拟合线拉歪

**解决方法**：在外面套一个 **Sigmoid 函数**，把输出压缩到 (0, 1) 之间，就能解释为概率。

### 2. Sigmoid 函数

`
σ(z) = 1 / (1 + exp(-z))
`

**重要性质**：
- σ(-∞) → 0，σ(+∞) → 1，σ(0) = 0.5
- 导数：σ'(z) = σ(z) * (1 - σ(z))，非常简洁
- σ(-z) = 1 - σ(z)（对称）

**直觉**：z > 0 → σ(z) > 0.5 → 预测类别 1（点击）；z < 0 → 预测类别 0（不点击）。

### 3. 逻辑回归模型

`
P(y=1 | x) = σ( w^T @ x + b ) = 1 / (1 + exp(-(w^T x + b)))
P(y=0 | x) = 1 - P(y=1 | x)
`

**怎么解读 w？**
- w_i > 0：特征 x_i 越大 → z 越大 → 越可能预测类别 1
- w_i < 0：特征 x_i 越大 → 越可能预测类别 0
- |w_i| 大小表示这个特征的影响力

### 4. 损失函数：交叉熵 BCE（Binary Cross-Entropy）

**直觉**：对一个真实标签是 1 的样本，如果模型预测概率 0.99 → 很好；如果预测 0.01 → 非常差，要给很大的损失。

`
BCE = -(1/n) * sum( y_true_i * log(y_pred_i) + (1-y_true_i) * log(1 - y_pred_i) )
`

**为什么这个损失合理？**
- 如果 y_true = 1，损失项 = -log(y_pred)。当 y_pred 接近 1 时 log(1) = 0 → 损失小；当 y_pred 接近 0 时 log(0) → -∞ → 损失巨大（模型自信地错了！）
- 如果 y_true = 0，损失项 = -log(1-y_pred)。类似地，预测接近 0 时损失小。

**为什么不用 MSE？**
- MSE 对逻辑回归来说会产生多个局部极小点（非凸），梯度下降可能卡住。
- BCE 是凸的，有唯一最小值，优化稳定。
- 当模型置信度高但预测错时，BCE 的梯度比 MSE 大得多，能快速修正。

### 5. 训练：梯度下降

对单个样本 (x, y)：

`
令 z = w^T @ x + b,  p = σ(z)
∂BCE/∂w = (p - y) * x      # 形式非常简洁！
∂BCE/∂b = (p - y)
`

**直觉**：误差越大（p-y 绝对值大），梯度越大，更新越猛烈，自动关注那些「最不确定」的样本。

## 四、决策树（Decision Tree）—— 「玩 20 问游戏」

### 1. 直觉：像画流程图一样分类

想象你要判断一个人「是否会点击广告」。你可以设计一串问题：

`
网站停留时间 > 5 分钟？
    ├─ 是 → 年龄 < 45？
    │         ├─ 是 → ✅ 点击 (概率 0.8)
    │         └─ 否 → ❌ 不点击 (概率 0.3)
    └─ 否 → ❌ 不点击 (概率 0.1)
`

每问一个问题，数据被分成两份「更纯」的子集。最终每个叶子节点给出一个预测。这就是**决策树**。

### 2. 怎么选择「下一个问题」？—— 信息熵和信息增益

**信息熵（Entropy）**衡量一个集合的「混乱程度」：

`
H(S) = -sum( p_k * log2(p_k) )
`

其中 p_k 是类别 k 在集合 S 中的比例。

**直觉**：
- 10 个样本全是同一类：p=[1, 0]，H = -(1*log2(1) + 0) = **0**（完全纯净）
- 5 个正、5 个负：p=[0.5, 0.5]，H = -(0.5*(-1) + 0.5*(-1)) = **1**（最混乱）
- 7 个正、3 个负：H ≈ 0.88（较混乱）

**信息增益（Information Gain）**：用一个特征分裂前后，熵减少了多少？

`
IG(S, feature) = H(S) - sum( |S_v|/|S| * H(S_v) )
`

对每个候选问题（每个特征的每个可能阈值），计算信息增益，**选择最大的那个**。

**Gini 不纯度（Gini Impurity）**是另一种常用度量：

`
Gini(S) = 1 - sum( p_k^2 )
`

和熵类似，Gini = 0 表示纯净，Gini = 0.5 表示两类各半。

sklearn 的 DecisionTreeClassifier 默认用 Gini。

### 3. 决策树怎么处理连续特征？

对「年龄」这样的连续值，先把所有样本按年龄排序（25, 32, 48, 55），然后依次尝试每个可能的分割：

- 年龄 > 28.5（把 25 和其他分开）→ 算信息增益
- 年龄 > 40（把 25, 32 和 48, 55 分开）→ 算信息增益
- 年龄 > 51.5（把 25, 32, 48 和 55 分开）→ 算信息增益

选增益最大的那个阈值。

### 4. 过拟合和剪枝

决策树有个坏毛病：**可以一直分裂，直到每个叶子节点只剩一个样本**。这样训练准确率 100%，但测试准确率可能只有 60%。

**防止过拟合的方法**：
- **限制最大深度 max_depth**（最有效）：比如限制树深 ≤ 5
- **限制叶子节点最少样本数 min_samples_leaf**：每个叶子至少有 5 个样本
- **剪枝 Pruning**：先让树长到最大，然后把对验证集没帮助的分支剪掉
- **集成方法**：用很多棵树投票 → 随机森林（Random Forest）、GBDT、XGBoost

## 五、K 近邻（KNN）—— 「近朱者赤，近墨者黑」

### 1. 直觉

KNN 是所有算法里最简单的。核心思想：**预测一个新样本时，看它附近的 K 个邻居是什么类别，多数投票**。

**具体步骤**：
1. 计算新样本和所有训练样本之间的**距离**
2. 找到最近的 K 个邻居
3. 这 K 个邻居中出现次数最多的类别 → 就是预测结果

**优点**：
- 零训练时间（只需要存储数据，也叫「懒惰学习」）
- 简单、直觉、易于解释
- 对非线性数据也能处理

**缺点**：
- 预测时要和所有训练样本算距离 → O(n) 慢
- 对特征尺度极其敏感（距离被大尺度特征主导）
- 维度诅咒：高维空间里「最近邻」其实很远，失去意义

### 2. 距离怎么算？

**欧氏距离（默认）**：

`
distance(a, b) = sqrt( (a1-b1)^2 + (a2-b2)^2 + ... + (ad-bd)^2 )
`

**曼哈顿距离**：
`
distance(a, b) = |a1-b1| + |a2-b2| + ... + |ad-bd|
`

**切比雪夫距离**：max(|ai-bi|)

### 3. K 选多少？

| K 太小 | K 太大 |
|:---:|:---:|
| 例如 K=1，只看最近的一个邻居 → 对噪声极度敏感，预测抖动大 | 例如 K=n（所有样本），不管输入是什么都预测多数类 → 等于没学 |
| 决策边界很「崎岖」 | 决策边界太「平滑」，失去局部信息 |

**经验**：K 一般取 3~20，用交叉验证选择最好的。也可以取 K=√n（n 是训练样本数）。

### 4. 距离加权（Weighted KNN）

不是所有邻居都同等重要。更近的邻居的投票可以更重：

`
每个邻居的权重 = 1 / distance^2  （或 e^{-distance^2/σ^2}）
`

预测 = 权重加权和最大的类别。这让 KNN 对 K 的选择不那么敏感。

### 5. 必须做特征归一化！

假设特征是「年龄（20~60）」和「收入（2000~20000）」。收入的尺度是年龄的几百倍，**欧氏距离基本只被收入主导**，年龄信息被淹没。

**解决**：标准化每个特征到均值 0、方差 1：

`
x_new = (x - mean) / std
`

**规则**：KNN / SVM / 神经网络 / 逻辑回归 → **必须归一化**；决策树 / 随机森林 → **不需要**（因为按阈值分，不比较不同特征的大小）。

## 六、朴素贝叶斯（Naive Bayes）—— 「用概率做分类」

### 1. 贝叶斯定理

贝叶斯定理描述「有了新证据后，如何更新信念」：

`
P(y | X) = P(X | y) * P(y) / P(X)
`

| 符号 | 名称 | 直觉 |
|:---:|:---|:---|
| P(y) | 先验概率（Prior）| 不看任何数据时，认为类别 y 发生的概率 |
| P(X \| y) | 似然（Likelihood） | 已知类别是 y 时，出现特征 X 的可能性 |
| P(X) | 证据（Evidence）| 归一化因子，保证所有类别概率之和为 1 |
| P(y \| X) | 后验概率（Posterior）| 看到特征 X 后，认为类别是 y 的概率 |

**分类时**：计算每个类别的后验，取最大的那个。

**注意**：P(X) 对所有类别都一样，不影响「谁最大」。所以实际计算时只需要：

`
预测类别 = argmax_y  P(y) * Π P(x_i | y)
`

### 2. 「朴素」是什么意思？

**朴素假设**：所有特征在给定类别下**条件独立**。即：

`
P(x1, x2, ..., xd | y) = P(x1 | y) * P(x2 | y) * ... * P(xd | y)
`

**这个假设几乎永远不成立**（比如「收入」和「停留时间」肯定相关），但朴素贝叶斯依然常常工作得很好。原因：
1. 虽然概率估计不准，但「哪个类别概率最大」的排序常常是对的；
2. 参数少（每个特征在每个类别下一个分布），小数据下也不易过拟合。

### 3. 文本分类中的朴素贝叶斯（详细例子）

**任务**：判断一封邮件是不是垃圾邮件。

**训练语料**（简化版）：
- 垃圾邮件（共 4 封）：「中奖 免费」「免费 中奖 点击」「中奖 点击 链接」「免费 礼物 点击」
- 正常邮件（共 4 封）：「会议 时间」「报告 会议」「项目 进度」「会议 报告 项目」

**先验概率**：
P(垃圾) = 4/8 = 0.5，P(正常) = 4/8 = 0.5

**词表**：中奖, 免费, 点击, 链接, 礼物, 会议, 时间, 报告, 项目, 进度（共 10 个词）

**似然 P(词 | 类别)**（先数每个词在每类出现的次数，再做拉普拉斯平滑 +1，分母加词表大小 10）：

垃圾邮件中各词计数：中奖=3, 免费=3, 点击=3, 链接=1, 礼物=1，其他=0
正常邮件中各词计数：会议=3, 时间=1, 报告=2, 项目=2, 进度=1，其他=0

**计算似然（平滑后）**：
垃圾邮件总词数 = 13（3+3+3+1+1+0+0+0+0+0）
P(中奖|垃圾) = (3+1) / (13+10) = 4/23 ≈ 0.174
P(免费|垃圾) = (3+1) / 23 = 4/23 ≈ 0.174
P(会议|垃圾) = (0+1) / 23 = 1/23 ≈ 0.043
...

**新邮件**：「中奖 免费」

**计算后验（用对数相加避免下溢）**：
log P(垃圾 | 中奖, 免费) ∝ log(0.5) + log(4/23) + log(4/23) ≈ -0.693 -1.743 -1.743 = -4.179
log P(正常 | 中奖, 免费) ∝ log(0.5) + log(1/22) + log(1/22) ≈ -0.693 -3.091 -3.091 = -6.875

垃圾邮件的后验更大 → 预测为**垃圾邮件**。✅

### 4. 为什么需要「拉普拉斯平滑（+1 平滑）」？

如果某个词在某个类别中从未出现过（比如「会议」在垃圾邮件中），P(会议|垃圾) = 0，那整个乘积就是 0，即使其他词都强烈指向该类别，也会被这一个零概率彻底否决。

**拉普拉斯平滑**：每个词的计数都「假装」多出现一次，分母加词表大小 V：

`
P(word | y) = (count(word, y) + 1) / (total_words_in_y + V)
`

**直觉**：即使没见过，也保留一丝可能性，不给「判死刑」。这是**概率平滑**的一种，防止 0 概率毁掉一切。

## 七、5 种方法横向对比

| 算法 | 模型形式 | 训练速度 | 预测速度 | 是否需归一化 | 是否可解释 | 数据量建议 | 最适合场景 |
|:---:|:---|:---:|:---:|:---:|:---:|:---:|:---|
| 线性回归 | y = wx+b | 快（解析解 O(nd²)）| 极快 O(d) | ✅ 建议 | ⭐⭐⭐⭐⭐ 每个 w 是特征重要性 | 小→大 | 特征和输出大致线性 |
| 逻辑回归 | P = σ(wx+b) | 快（迭代 O(nd·T)）| 极快 O(d) | ✅ 必须 | ⭐⭐⭐⭐⭐ 每个 w 是 log odds | 小→大 | 二分类 / 多分类 baseline |
| 决策树 | if-else 流程图 | 中等 O(n·d·log n) | 快 O(log n) | ❌ 不需要 | ⭐⭐⭐⭐ 可视化后一目了然 | 小→中 | 特征间有复杂交互 |
| KNN | 存储数据，最近邻投票 | O(1) （懒惰学习）| 慢 O(n·d) （对大 n 致命）| ✅ 必须 | ⭐⭐⭐ 可以说「因为你的邻居都是 A」 | 小 | 数据量不大、维度不高 |
| 朴素贝叶斯 | 贝叶斯 + 条件独立假设 | 极快 O(n·d) | 极快 O(d) | ❌ 不需要 | ⭐⭐⭐ 可以用概率解释 | 小→中 | 文本分类、特征独立（近似成立）|

## 八、本章 vs 其他章节

- **vs 第三章（无监督）**：本章有标签，模型目标明确；第三章只有数据、没有答案，靠「发现结构」。
- **vs 第四章（神经网络）**：本章模型浅层、参数少、解释性强；神经网络是深度模型，能学到极复杂的函数但更难解释。
- **vs 第五章（CNN）**：本章的 5 个方法都**不擅长图像**（图像是 2D 结构 + 高维输入）。CNN 专门为 2D 数据设计的「局部感受野 + 参数共享」是图像任务的正确选择。
- **vs 第七章（Transformer）**：文本分类任务上，朴素贝叶斯是一个极强的 baseline（训练 1 秒，准确率 80%）；BERT 可能需要训练几小时，准确率 90%+。工业界习惯：先上朴素贝叶斯/逻辑回归看 baseline，再决定花资源上大模型。

## 十、问题与答案解析

### Q1：线性回归如果用了 x² 项，是不是就不是「线性」回归了？

**答**：它仍然叫「线性回归」！「线性」指的是**参数线性**（w 和 b 是线性出现的），而不是输入线性。

- y = w1*x + w2*x^2 + b → 参数 w1、w2、b 仍然线性 → 是线性回归（叫多项式回归，属于线性回归的一种）
- y = w1 * x^w2 + b → 参数 w2 在指数上，非线性 → 不是线性回归

**直觉**：把 x² 当作一个新特征 z，那么模型就是 y = w1*x + w2*z + b，在 (x, z) 空间是线性的。原空间虽然看起来曲线，但本质还是线性模型在学习加权组合。

---

### Q2：如果 X^T X 不可逆怎么办？

**答**：X^T X 不可逆意味着特征之间有线性相关（比如「年收入」和「月收入×12」同时存在），也可能特征维度 d > 样本数 n。

**解决方法**：
1. **去掉冗余特征**（人工检查，删除线性相关的列）
2. **加 L2 正则化**（Ridge 回归）：θ = (X^T X + λI)^{-1} X^T y，加一个 λ 倍单位矩阵保证可逆。同时 λ 大时会把 w 压缩到 0 附近，减轻过拟合。
3. **加 L1 正则化**（Lasso 回归）：会让某些 w 恰好是 0，起到「特征选择」的作用。
4. **用梯度下降训练**（迭代优化对奇异性没那么敏感）

**工程默认**：大多数 sklearn 里的 LinearRegression 已经做了 SVD 分解来处理数值不稳定。如果数据量中等，先试试加 Ridge。

---

### Q3：R² 是什么？为什么比 MSE 更直观？

**答**：R²（R-squared）衡量「模型解释的方差占总方差的比例」：

`
SS_res = sum( (y_true - y_pred)^2 )   模型残差平方和
SS_tot = sum( (y_true - mean(y))^2 )   总方差
R² = 1 - SS_res / SS_tot
`

**解读**：
- R² = 1 → 完美预测，SS_res = 0
- R² = 0 → 模型不比「直接预测均值」好
- R² 可能为负 → 模型比预测均值还差（很罕见，通常是 bug）

**为什么比 MSE 好**：MSE 的大小依赖 y 的尺度（房价以万元计 MSE 是 100，换成元就是 1e10），无法跨数据集比较。R² 是无量纲的，范围 (-∞, 1]，任何回归问题都可以比较。

---

### Q4：逻辑回归为什么叫「回归」？它明明是分类啊！

**答**：历史原因。在 Sigmoid 里面，z = w^T x + b 本身是一个线性回归模型（预测一个连续的 z）。外面套 Sigmoid 把 z 变成概率。所以「回归」指的是内层 z 是一个回归预测，「逻辑」指的是外层用了 Logistic（Sigmoid 的另一个名字）函数。

**Probit 回归**是另一种类似的方法，用正态分布的累积分布函数代替 Sigmoid。

---

### Q5：逻辑回归输出的「概率」是真实概率吗？

**答**：不一定。如果模型训练得好、数据充足，输出可以解释为校准过的概率。但通常：
- 逻辑回归的概率输出往往**过于自信**（接近 0 或 1，而不是合理的 0.8）
- 需要「概率校准（Probability Calibration）」—— 用 Platt scaling（对逻辑回归输出再做一次逻辑回归）或 Isotonic regression 把输出调整到更像真实频率

**什么时候需要校准**：如果你要用概率值做阈值（比如「概率>0.7 才推广告」），校准很重要。如果只是取最大概率做分类，一般不需要。

---

### Q6：决策树深度越大越好吗？

**答**：不是。太深的树会过拟合（对训练数据的噪声也学习到了）。

**调参策略**：
1. 先让树自由生长（不限制 max_depth），看训练集/验证集准确率的差距；
2. 如果训练集 99%、验证集 70% → 严重过拟合，减小 max_depth（比如设为 5）；
3. 如果都差 → 欠拟合，增大 max_depth 或加更多特征；
4. 常用参数：max_depth, min_samples_split, min_samples_leaf, max_features；
5. 更有效的是**用很多棵树**：随机森林（Random Forest）训练多棵树投票，效果显著好于单棵决策树。

---

### Q7：为什么 KNN 对大 n 很慢？有加速方法吗？

**答**：KNN 预测时要计算新样本和所有 n 个训练样本的距离 → O(n·d)。n=100 万时每次预测就要算 100 万次距离。

**加速方法**：
1. **KD Tree**：用树结构组织数据，只搜索附近的子空间（sklearn 内置）
2. **Ball Tree**：类似，更适合高维
3. **ANN（Approximate Nearest Neighbor）**：放弃精确最近邻，找「大概最近的」，速度快几十倍 → FAISS（Facebook）、Annoy、HNSW
4. **降维先用 PCA**：把 d 从 1000 降到 50，距离计算快 20 倍

---

### Q8：KNN 的 K 是奇数还是偶数有影响吗？

**答**：当二分类 K=偶数时，可能出现平票（3 个正类 3 个负类）。解决方法：
1. **用奇数 K**（简单粗暴但有效）
2. **按距离加权**：不是按票数，而是按 1/distance² 加权求和 → 几乎不会平票
3. **平票时选先验概率大的类**（训练集中数量更多的类）

---

### Q9：朴素贝叶斯的「条件独立」假设明显不对，为什么它还好用？

**答**：一个有趣的经验发现：即使独立假设被严重违反，朴素贝叶斯在**分类排序**上常常仍然是对的（P(正|x) > P(负|x) 的判断正确，即使精确值错了）。

**适用场景**：
- 文本分类（垃圾邮件、情感分析）—— 词之间虽然相关，但朴素贝叶斯作为 baseline 非常强
- 小数据集 —— 参数少，不轻易过拟合
- 需要解释性且速度快 —— 可以说「这个词有 80% 概率出现在垃圾邮件中」

**不适用**：
- 特征高度相关（比如同时放身高厘米和身高英寸）→ 双重计数，被该类特征过度影响
- 需要精确概率值 → 概率估计不准，只适合比较大小

---

### Q10：如何选择「用哪种算法」？

**答**：一个实用的决策流程：

`
开始
 │
 ├─ 数据量小 (<1 万样本, <50 特征)
 │     ├─ 分类问题 → 朴素贝叶斯 / 逻辑回归
 │     └─ 回归问题 → 线性回归 / 决策树回归
 │
 ├─ 中等数据 / 表格数据 (结构化数据)
 │     └─ ⭐ 默认选 XGBoost / LightGBM / GBDT（工业界 gold standard）
 │
 ├─ 图像 / 语音 / 空间 2D 数据
 │     └─ ⭐ CNN / ResNet（第五章）
 │
 ├─ 文本 / 序列数据
 │     ├─ 小数据 / baseline → 朴素贝叶斯 + TF-IDF
 │     └─ 大数据 / SOTA → Transformer / BERT（第七章）
 │
 └─ 需要可解释性（医疗、金融、法律）
       └─ 逻辑回归 / 决策树（可画出流程图）
`

**通用建议**：先用最简单的（逻辑回归 / 朴素贝叶斯 / 决策树）建立 baseline，看准确率在哪个级别。如果 baseline 已经够用，就不要再花资源。如果 baseline 还不够，再上更复杂的模型。

---

### Q11：训练集准确率 99%，测试集准确率 70%，说明什么？

**答**：典型**过拟合**。模型死记硬背了训练数据的噪声而不是规律。

**解决方法（按优先级）**：
1. **更多训练数据**（最根本）
2. **数据增强**（图像：随机裁剪翻转；文本：同义词替换）
3. **正则化**：
   - 线性模型：L1/L2 正则化
   - 决策树：限制 max_depth / 剪枝
   - 神经网络：Dropout / Weight Decay
4. **简化模型**：减小层数 / 减小隐藏层宽度
5. **Early Stopping**：监控验证集 loss，一旦 N 轮不降就停止（防止继续学噪声）
6. **集成方法**：随机森林 / XGBoost / Bagging（让多个弱模型投票，降低过拟合方差）

---

### Q12：训练集和测试集准确率都差（60% 左右），说明什么？

**答**：典型**欠拟合**。模型太简单，没有足够能力学习数据中的规律。

**解决方法**：
1. **换更复杂的模型**（线性→树→GBDT→神经网络）
2. **做更好的特征工程**：加交互项（x1*x2）、多项式特征（x²）、统计特征
3. **增加模型容量**（树深更大、网络更宽更深）
4. **调超参数**（减小正则化强度 λ，让模型有更大自由）

---

### Q13：为什么要做交叉验证？

**答**：把数据切一次分成训练集/验证集，有两个问题：
1. 你可能「幸运」切了一个好的验证集，结果虚高；
2. 验证集本身也是珍贵的数据，被切出去后就不能用来训练。

**K 折交叉验证**：把数据分成 K 份，轮流用 K-1 份训练、1 份验证，K 次结果取平均。这样每份数据都当过一次验证集，结果更稳定。

**常见 K 值**：5 或 10。特别小的数据 (<100 样本) 用留一法 (LOOCV, K=n)。

---

### Q14：特征工程对这 5 种算法影响大小一样吗？

**答**：不一样。按「受特征工程影响程度」排序：

`
KNN / SVM / 神经网络 >> 线性回归 / 逻辑回归 >> 决策树 / GBDT
`

- KNN/神经网络**极度依赖特征质量和尺度**：一个未归一化的特征就能毁掉 KNN
- 线性模型**需要特征是线性可加**：如果关系是非线性的，需要手动加 x²、log(x) 等
- 决策树 / GBDT**对特征工程最不敏感**：自动学习阈值分裂，能处理非线性交互，不需要归一化 —— 这也是为什么 GBDT 在表格数据上一直是 gold standard

---

### Q15：这 5 种算法在现代工业界还有人用吗？还是被深度学习替代了？

**答**：都有人用，而且用得很多。工业界的经验：

- **表格数据（Excel / SQL 表）**：XGBoost / LightGBM / CatBoost 是 gold standard，在大多数结构化数据任务上**仍然比深度学习好**，而且快几十倍、省几十倍计算资源。这是因为表格数据的关系通常是稀疏、离散的，Transformer/MLP 的归纳偏置不匹配。
- **图像**：CNN / Transformer（ViT）基本垄断，传统方法几乎退出。
- **文本**：大模型（BERT、GPT、LLaMA）是 SOTA，但**朴素贝叶斯 + TF-IDF / 逻辑回归 + TF-IDF** 作为 baseline 仍然非常常见（训练几秒钟就能有不错的准确率，帮助你判断任务的难度天花板）。
- **推荐系统**：工业级推荐常用双塔模型（Embedding + MLP）或 GBDT + 逻辑回归融合。

**一句话**：深度学习不是万金油。在表格数据上，GBDT 仍然是王者。在图像/文本上，深度学习是首选。**对每个实际问题，先用简单方法建立 baseline，再决定要不要花资源上大模型**。

## 本章小结

1. **5 种监督学习算法**：线性回归、逻辑回归、决策树、KNN、朴素贝叶斯
2. **线性回归**：学习一条直线 y=wx+b，MSE 损失，有解析解 + 梯度下降两种训练方式
3. **逻辑回归**：Sigmoid 把输出压到 (0,1) 作为概率，用 BCE 损失训练，是分类任务的首选 baseline
4. **决策树**：用「20 问」的方式分裂，信息增益 / Gini 选择分裂点，容易过拟合 → 限制深度或用随机森林
5. **KNN**：最近邻投票，零训练时间，预测 O(n) 慢，必须归一化，K 值用交叉验证选
6. **朴素贝叶斯**：用贝叶斯定理 + 条件独立假设，速度极快，文本分类的强 baseline，需要拉普拉斯平滑防 0 概率
7. **工程经验**：先建立简单 baseline，看是否够用；表格数据默认用 XGBoost/LightGBM；图像用 CNN；文本看数据量大小选朴素贝叶斯或 Transformer
8. **过拟合 / 欠拟合**：训练好测试差 = 过拟合 → 加数据 / 正则化；都差 = 欠拟合 → 加复杂度 / 特征工程
