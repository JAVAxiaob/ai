# 第7章：小波变换与多分辨率处理

> **面向零基础读者**：傅里叶变换能告诉你"图像中有哪些频率"，但不能告诉你"这些频率在什么位置"。小波变换同时提供频率和位置信息——这就是"时间-频率局部化"。本章学习图像金字塔和小波变换。

---

## 一、傅里叶变换的局限

### 1.1 傅里叶的"双刃剑"

| 傅里叶的优势 | 傅里叶的劣势 |
|------------|------------|
| 频率分析完美 | 完全丢失位置信息 |
| 全局变换 | 无法定位局部特征 |
| 适合平稳信号 | 不适合突变/非平稳 |

**问题**：频谱中一个高频尖峰 = 图像某处有边缘——但你不知道在哪个位置！

---

## 二、多分辨率：图像金字塔

### 2.1 高斯金字塔（Gaussian Pyramid）

**构造**：每一层 = 上一层高斯模糊 + 2倍降采样。

```
Level 0: 512×512  原图像
Level 1: 256×256  模糊后每2×2取一个像素
Level 2: 128×128  （再模糊+降采样）
...
Level n: 1×1      （最终）

视觉：
■■■■■■  L0 (精细)
  ■■■■  L1
    ■■  L2 (粗糙)
     ■  Ln
```

**数学**：
```
G_l = REDUCE(G_{l-1}) = Σ_{m=-2..2} Σ_{n=-2..2} w(m,n) · G_{l-1}(2i+m, 2j+n)

其中 w = 5×5 高斯近似核（权重和=1，可分离）
     [1 4 6 4 1] / 256 的变体
```

### 2.2 拉普拉斯金字塔（Laplacian Pyramid）

**构造**：每一层 = 当前高斯层 - 上一层的2倍上采样。

```
L_l = G_l - EXPAND(G_{l+1})

其中 EXPAND = 先0填充到2倍大小，再用同样的高斯核模糊插值

视觉含义：
L_l = G_l 中"被降采样丢掉的细节" → 即高频残差！

L0 + L1的EXPAND + L2的EXPAND... = 完美重建原图！
```

**应用**：
- 渐进式传输（先传粗糙版本，再传细节补全）
- 图像融合（如可见光+红外：用金字塔各层选择更清晰的残差）
- 纹理合成

## 三、小波变换：时间-频率局部化

### 3.1 核心直觉

```
傅里叶 = 用无限长正弦波来"匹配"信号
小波 = 用有限长度、会"消失"的小波（wavelet）来"匹配"信号

正弦波（傅里叶）：
    ▁▂▃▅▆▇▇▆▅▃▂▁▂▃▅▆▇▇▆▅▃▂▁▂▃▅▆▇... （无限延伸，无定位）

Haar小波：
    ▁▃▅▆▅▃▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁...            （有限宽度，有定位！）

通过"缩放"小波的宽度（尺度）+ "滑动"小波的位置，得到：
- 大尺度小波 → 匹配低频（大结构）
- 小尺度小波 → 匹配高频（细节/边缘）
```

### 3.2 连续小波变换（CWT）

```
W_f(a, b) = (1/√a) · ∫ f(t) · ψ*((t-b)/a) dt

其中:
  a = 尺度参数（a大=低频，a小=高频）
  b = 位置参数（时间/空间位置）
  ψ = 母小波（mother wavelet），需满足 ∫ψ(t)dt = 0（即均值为0，像带通）
  ψ* = 复共轭

W_f(a,b) = f 和"缩放到a、平移到b的ψ"的相似度
         ↑ 一个 2D 函数！在每个(尺度, 位置)都有系数
```

### 3.3 离散小波变换（DWT）

**Mallat 算法（1989）**：通过正交滤波器组（低通h，高通g）实现 DWT。

```
一维 DWT（一层分解）：

输入信号 f[n]
   ├─ 与低通 h 卷积 → 近似系数 cA（低频，"整体形状"）
   └─ 与高通 g 卷积 → 细节系数 cD（高频，"细节/边缘"）

对 cA 和 cD 做 2:1 降采样（每2个取1个）→ 总数不变，不冗余！

对 cA 重复 → 多级分解：
f → cA1, cD1
     cA1 → cA2, cD2
           cA2 → cA3, cD3 ...

完美重建（IDWT）：对 cA, cD 上采样 + 与合成滤波器卷积 + 求和 = 原信号！
```

**二维 DWT（图像）**：先逐行做一维DWT，再逐列做。

```
一层二维 DWT 输出 4 个子带：

┌─────────┬─────────┐
│  LL   │  HL   │   ← LL = 行低通+列低通（近似，下一层的"原图像"）
│         │  水平边缘   │   ← HL = 行低通+列高通（列方向的变化 = 水平边缘）
├─────────┼─────────┤
│  LH   │  HH   │   ← LH = 行高通+列低通（垂直边缘）
│  垂直边缘 │  对角边缘   │   ← HH = 行高通+列高通（对角/纹理/噪声）
└─────────┴─────────┘

下一层分解只对 LL 子带继续分解...
```

### 3.4 常见小波

| 名称 | 支撑长度 | 消失矩阶数 | 典型用途 | 代码中使用 |
|------|---------|----------|---------|----------|
| Haar | 2 | 1 | 教学演示 | haargen |
| Daubechies (dbN) | 2N | N | 信号/图像处理 | daub(N) |
| Symlet | 2N | N | 接近对称，相位失真小 | symlet(N) |
| Coiflet | 6N | 2N | 最对称 | coif(N) |
| Biorthogonal | 可变 | 可变 | JPEG2000 | bior(N,M) |
| Reverse Bior. | 同上 | 同上 | JPEG2000合成端 | rbio(N,M) |

## 四、DWT vs DFT：理解两种变换

| 性质 | DFT（傅里叶） | DWT（小波） |
|------|-------------|------------|
| 基函数 | 正弦/余弦（全局支撑） | 小波（局部支撑，缩放+平移） |
| 时间定位 | ❌ 无 | ✅ 有 |
| 频率定位 | ✅ 完美（单频率） | ⚠️ 有限（由尺度决定的频率带） |
| 冗余 | 无（正交） | 无（正交小波） |
| 对突变信号 | ❌ 吉布斯现象（ringing） | ✅ 能用少数系数表示突变 |
| 自然图像稀疏 | 稀疏（大部分能量在低频） | **更稀疏**（边缘用很少系数即可表示） |
| 计算复杂度 | O(N log N) (FFT) | O(N) (Mallat) |
| 典型应用 | 频域滤波、压缩 | 压缩(JPEG2000)、去噪、特征提取 |

## 五、小波去噪：软阈值 vs 硬阈值

**Donoho 的"小波萎缩"思想（1995）**：

1. 做正向 DWT
2. 对高频系数做"阈值处理"——小系数认为是噪声，置零或缩小
3. 做逆 DWT 重建

**两种阈值**：
```
硬阈值（Hard Thresholding）：
η_hard(x, T) = x  if |x| ≥ T
              = 0  otherwise

软阈值（Soft Thresholding）：
η_soft(x, T) = sign(x) · max(|x| - T, 0)

图形：
硬阈值:       软阈值:
   ↗            ↗        ← x
  /             ↗
 /             /
●───●         ●─────●    ← 零区域
               /
              /
             ↗
             T  ← 阈值
```

**阈值 T 的选择**（Donoho 的通用阈值）：
```
T = σ · √(2 · log N)

其中 σ = 噪声标准差（可从最高频子带的 MAD/0.6745 估计）
     N = 信号长度

MAD = Median Absolute Deviation = median(|c - median(c)|)
    = 对异常值鲁棒的标准差估计
```

**为什么小波去噪效果好？**
- 自然图像的"边缘"在小波域只有少数大系数
- 噪声在小波域是均匀散布的小系数
- 只需去掉小系数 = 去除大部分噪声而保留边缘！

## 六、本章函数完整参考

### 1. `wavelet_reconstruct_demo()`

**功能**：演示小波的构造（Haar / Daubechies 4）——画小波函数的形状。

代码中 `haargen` 和 `daub(4)` 为 haar 和 db4 小波的滤波器系数。

---

### 2. `dwt_haar_1d(signal)`

**功能**：手动实现一维 Haar 小波（教学用）。

```
近似系数: cA[k] = (signal[2k] + signal[2k+1]) / √2
细节系数: cD[k] = (signal[2k] - signal[2k+1]) / √2

（Haar 小波 = 相邻两数的平均和差，最简单的小波）
```

---

### 3. `dwt_haar_2d(img, level=3)`

**功能**：用 PyWavelets 做二维 Haar 小波多级分解并显示。

---

### 4. `wavelet_multilevel(img, wavelet='db2', level=3)`

**功能**：用指定小波（如 db2）做多级分解。

**输出**：显示每层的 LL, LH, HL, HH 子带。

---

### 5. `wavelet_reconstruct_demo2(img, wavelet='db2')`

**功能**：演示正向→逆向变换的完美重建（误差 < 1e-10）。

---

### 6. `wavelet_denoise(img, wavelet='db2', mode='soft', sigma=25)`

**功能**：小波去噪（软/硬阈值）。

**参数**：
| 参数 | 含义 | 推荐 |
|------|------|------|
| wavelet | 小波类型 | db2/db4（通用），bior（压缩） |
| mode | 阈值模式 | soft（连续，无伪影），hard（锐利） |
| sigma | 噪声σ | 先估计，或用程序自动估计 |

---

### 7. `wavelet_compress(img, wavelet='db2', ratio=0.1)`

**功能**：小波压缩——只保留最大的 10% 系数。

**ration=0.1 含义**：保留系数数量 = 0.1 × 总系数数。

**压缩原理**：自然图像在小波域是稀疏的——大部分系数接近0，可以丢弃而视觉损失很小。

## 七、图像金字塔函数（补充知识点）

### `gaussian_pyramid(img, levels=4)` / `laplacian_pyramid(img, levels=4)`

**高斯金字塔用途**：
- 多尺度特征检测（如 SIFT 在多个尺度找关键点）

- 纹理分析

**拉普拉斯金字塔用途**：

- 多尺度降噪

## 八、初学者常见问题解答

### Q1: 小波和傅里叶到底有什么本质区别？为什么需要两个？

**答**：用"食谱"类比：

```
傅里叶变换 = 告诉你这道菜含有多少糖、盐、油（各"成分"的总量）
              但不告诉你这些成分在盘子里的位置

小波变换   = 用不同大小的"勺子"去舀食物
              大勺子 = 尝到整体味道（低频/结构）
              小勺子 = 尝到局部细节（高频/边缘）
              且知道每个勺子的位置！

需要哪个？
- 如果你只关心"整体成分比例" → 傅里叶
- 如果你关心"哪里有什么变化" → 小波
- 如果你需要两者 → 两者都用或用短时傅里叶变换(STFT)
```

**数学表述**：傅里叶基是正弦函数（无限支撑、单频率）；小波基是母小波的缩放平移（有限支撑、多频率带）。

### Q2: Haar 小波看起来特别简单——为什么不用它做所有事情？

**答**：Haar 是最简单的小波（只有两个系数 [1, 1]/√2 和 [1, -1]/√2），但有严重局限：

| Haar 的优点 | Haar 的缺点 |
|-----------|-----------|
| 计算极快 | 不连续 → 重建有方块伪影 |
| 易理解 | 只1阶消失矩 → 不能稀疏表示光滑函数 |
| 正交 | 频域泄漏严重 → 子带不纯净 |

**实际选择**：
- 教学/演示 → Haar
- 一般信号处理 → db4 或 db8
- 图像压缩/最自然重建 → bior4.4（JPEG2000标准）
- 追求对称性 → symlet 或 coiflet

### Q3: JPEG2000 用小波，但为什么 JPEG2000 没取代 JPEG？

**答**：技术上 JPEG2000 确实更好（压缩率更高、无块效应、支持渐进传输和感兴趣区域编码）。但有工程/历史原因：

1. **专利问题**：早期 JPEG2000 涉及大量专利，厂商不愿用。而原版 JPEG 已专利过期。
2. **计算复杂度**：小波变换比 DCT 复杂——早期硬件/软件解码慢。
3. **生态锁定**：JPEG 无处不在。数十亿设备都支持JPEG，更换标准的成本极高。
4. **现代替代品**：WebP/AVIF/HEIC 等新格式基于更现代的方法（帧内预测 + 变换），性能往往更好。

## 九、章节总结

```
本章知识结构
├── 多分辨率：图像金字塔
│   ├── 高斯金字塔：G_l = REDUCE(G_{l-1}) = 模糊+2倍降采样
│   ├── 拉普拉斯金字塔：L_l = G_l - EXPAND(G_{l+1}) = 细节残差
│   └── 应用：渐进传输、图像融合、多尺度检测（SIFT的基础）
├── 小波变换
│   ├── 傅里叶的局限：无位置信息
│   ├── 连续小波变换（CWT）：W_f(a,b) = f和(缩放到a,平移到b的ψ)的相似度
│   ├── 离散小波变换（DWT）：Mallat 算法 = 低通h + 高通g + 2:1降采样
│   ├── 2D DWT = 逐行DWT + 逐列DWT → 4个子带 (LL, LH, HL, HH)
│   │   ├─ LL = 近似（下一层分解对象）
│   │   ├─ LH = 垂直边缘
│   │   ├─ HL = 水平边缘
│   │   └─ HH = 对角/纹理/噪声
│   ├── 常见小波：Haar（教学）, dbN（通用）, bior（压缩/JPEG2000）, symlet（对称）
│   └── DWT vs DFT：局部化 vs 全局；对突变信号更稀疏表示
├── 小波应用
│   ├── 去噪：Donoho阈值 → soft/hard → T = σ√(2logN)
│   ├── 压缩：稀疏性 → 只保留最大N%系数
│   └── 特征：不同尺度的LH/HL/HH = 多尺度边缘/纹理特征
└── 工程选择
    ├── 简单教学：Haar
    ├── 一般图像处理：db2 或 db4
    ├── 压缩（JPEG2000标准）：bior4.4 / cdf9/7
    └── 对称性优先：symlet, coiflet
```
