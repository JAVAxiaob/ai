# 第9章：数学形态学

> **面向零基础读者**：形态学（Morphology） = "形状的科学"。本章不关心"像素值是多少"，只关心"哪些像素是物体的一部分"——即图像的**形状和结构**。核心思想：用一个小"探针"（结构元）在图像上滑动，探测局部形状。

---

## 一、基本集合运算（形态学的数学基础）

设 A、B 为二维像素集合（图像），其中 A 是图像，B 是结构元（SE）。

| 运算 | 数学定义 | 视觉效果 |
|------|---------|---------|
| **并集** A ∪ B | {x | x ∈ A 或 x ∈ B} | 两物体合并 |
| **交集** A ∩ B | {x | x ∈ A 且 x ∈ B} | 公共区域 |
| **补集** Aᶜ | {x | x ∉ A} | 黑白翻转 |
| **差集** A - B | A ∩ Bᶜ = A 中不在 B 里的部分 | 从 A 中擦除 B |
| **平移** A + z | {a + z | a ∈ A} | 整体移动 |
| **反射** B̌（或 -B） | {-b | b ∈ B} | 以原点为中心翻转180° |

**集合论的重要概念**：
- 前两个运算构成布尔代数基础
- 反射在腐蚀/膨胀定义中是关键

---

## 二、两个基本运算：腐蚀与膨胀

### 2.1 腐蚀（Erosion）

**定义**：用结构元 B 腐蚀图像 A：

```
A ⊖ B = { z | (B + z) ⊆ A }

直觉: "B能完全放进A中的所有位置z的集合"
```

**可视化**（B = 3×3 方形结构元）：

```
输入 A:    结构元 B:    腐蚀后 A⊖B:
■ ■ ■ ■     ■ ■ ■       □ □ □ □   ← 边界被"吃掉"
■ ■ ■ ■     ■ ■ ■       □ ■ ■ □   ← 内部保留
■ ■ ■ ■     ■ ■ ■       □ ■ ■ □   ← 只有那些"足够深"在A中的点保留
■ ■ ■ ■               □ □ □ □   ← 边界一圈消失

B = 5×5 时腐蚀效果更强：
输入:      腐蚀后:
■ ■ ■ ■ ■    □ □ □ □ □
■ ■ ■ ■ ■    □ □ ■ □ □   ← 只有中心保留！
■ ■ ■ ■ ■    □ □ □ □ □
■ ■ ■ ■ ■    □ □ □ □ □
■ ■ ■ ■ ■    □ □ □ □ □
```

**典型用途**：
1. 去掉小噪声颗粒（"斑点"）
2. 分离相互接触的物体（断开粘连）
3. 找到物体的边界（A - (A⊖B) = 内部边界）

---

### 2.2 膨胀（Dilation）

**定义**：用结构元 B 膨胀图像 A：

```
A ⊕ B = { z | (B̌ + z) ∩ A ≠ ∅ }
      = ∪ (A + b) for b ∈ B

直觉: "将A按B的形状'长出'一圈"

当B是对称的（如方形、圆形，B̌=B），简化为：
A ⊕ B = { z | (B + z) ∩ A ≠ ∅ }

直觉: "B与A至少有一个公共点的所有位置z的集合"
```

**可视化**（B = 3×3 方形）：

```
输入 A:    膨胀后 A⊕B:
□ ■ □      ■ ■ ■ ■ □   ← 向四周"长出"一圈
□ ■ ■      ■ ■ ■ ■ ■
□ ■ □      ■ ■ ■ ■ □
           ■ ■ ■ ■ □
           □ ■ ■ ■ □

注意：如果B非对称，反射会改变方向！
```

**典型用途**：
1. 填充物体中的小孔（比物体小的洞）
2. 连接断裂的物体（桥梁断开处）
3. 加粗线条

---

## 三、两个组合运算：开运算与闭运算

### 3.1 开运算（Opening）

**定义**：先腐蚀，后膨胀。

```
A ○ B = (A ⊖ B) ⊕ B
```

**直觉**："擦除小突出物，平滑大物体边界"。

**形状解释**：
- 用B在A内部"滚动"，能"触及"到的所有位置
- 物体小于B的凸起部分被去掉
- 物体大于B的部分基本保留（但略有缩小）

**数学性质**：
- 幂等性：(A ○ B) ○ B = A ○ B（做多次效果相同）
- 单调性：A ⊆ C → A ○ B ⊆ C ○ B
- 反向扩展：A ○ B ⊆ A（总是结果的子集）

---

### 3.2 闭运算（Closing）

**定义**：先膨胀，后腐蚀。

```
A ● B = (A ⊕ B) ⊖ B
```

**直觉**："填充小孔，连接邻近物体"。

**形状解释**：
- 用B在A外部"滚动"，B的所有不与A重叠的位置被去掉
- 小于B的洞被填充
- 邻近（距离 < B直径）的物体被连接

**数学性质**：
- 幂等性：(A ● B) ● B = A ● B
- 单调性
- 扩展：A ⊆ A ● B（总是结果的超集）

---

### 3.3 开运算 vs 闭运算：选择指南

| 你想做什么 | 使用哪个 | 示例 |
|-----------|---------|------|
| 去掉小噪点（小于SE） | 开运算 | 文字识别中去掉墨迹斑点 |
| 分离粘连的物体 | 先腐蚀（或开运算） | 血细胞计数中分离重叠细胞 |
| 填充小孔/裂缝 | 闭运算 | 扫描文档中填补字笔画断裂 |
| 平滑凸边界 | 开运算 | 使物体轮廓更规则 |
| 平滑凹边界 | 闭运算 | - |
| 同时平滑内外边界 | 先开后闭（或开闭交替） | 噪声清理后使边界规则 |

## 四、边界提取（Morphological Gradient）

### 4.1 内部边界 / 外部边界 / 梯度边界

```
内部边界 β_i(A) = A - (A ⊖ B)   ← A中会被腐蚀掉的边界像素
外部边界 β_o(A) = (A ⊕ B) - A   ← 膨胀新增的边界像素
梯度边界 β_g(A) = (A ⊕ B) - (A ⊖ B)   ← 膨胀-腐蚀 = 对称边界（最常用）

示例: A是一个实心圆:

A:     A⊖B:    A⊕B:    β_g = A⊕B - A⊖B:
●●●     □□□     ○○○     ○●○
●●●●●    □●□●□   ○●●●○    ○●●●●○
●●●●● →  □●●●□   ○●●●●○  → ○●●●●○  ← 只有边界一圈
●●●●●    □●□●□   ○●●●○    ○●●●○
●●●     □□□     ○○○     ○●○
```

**代码中 `morph_boundary(img)` 用 A - (A⊖B) 提取内部边界**。

## 五、区域填充（Hole Filling）

**问题**：二值图像中，物体内部可能有洞（被物体包围的白色背景）。如何填充它们？

**算法**：
```
输入: 二值图像 A（物体=1，背景=0，洞=0但被1包围）
目标: 输出填充了所有洞的图像

1. 从图像边界的0像素开始，做背景的区域生长
   X_0 = 边界上所有的0像素
   X_k = (X_{k-1} ⊕ B) ∩ Aᶜ   for k = 1, 2, ...
   （不断向内部生长，但只停留在0像素区域）

2. 最终X = 所有背景像素（包括边界上的）

3. 填充结果 = Xᶜ = 所有非背景像素 = 物体 + 原本被包围的洞

直觉: "从边界的外面开始往里面灌水，水不能穿过物体。
         没被水淹没的区域 = 物体 + 被物体包围的洞"
```

**代码中 `morph_hole_fill(img)` 实现此算法**。

## 六、击中/击不中变换（Hit-or-Miss）

**用途**：在二值图像中寻找**精确匹配**某种局部形状的位置。

**定义**：
```
A ⊛ B = (A ⊖ B1) ∩ (Aᶜ ⊖ B2)  where B = (B1, B2)

其中:
  B1 = "命中"模式（必须全为1的位置）
  B2 = "击不中"模式（必须全为0的位置）
  B1 ∩ B2 = ∅（它们不重叠，否则无意义）
```

**例子：查找孤立的1像素（3×3中心是1，其他全0）**：

```
B1 = □ ■ □      B2 = ■ □ ■
     ■ ■ ■           □ □ □
     □ ■ □           ■ □ ■

A ⊛ B 输出的每个1 = "此处A精确匹配中心1+周围0的模式" = 孤立点检测
```

## 七、结构元的选择

| 结构元形状 | 效果 | 典型用途 |
|-----------|------|---------|
| 方形（3×3, 5×5） | 各向同性但有"角"偏好 | 通用，最常用 |
| 圆形（disk） | 各向同性，无方向偏好 | 需要保持圆形对称性时 |
| 十字形（+） | 对垂直/水平结构敏感 | 水平/垂直线条处理 |
| 水平线条（1×N） | 只保留水平结构，去除垂直结构 | 提取水平线 |
| 垂直线条（N×1） | 只保留垂直结构 | 提取垂直线 |
| 菱形/八角形 | 介于方/圆之间 | 特定形状检测 |

**大小选择**：SE越大 → 效果越强（腐蚀/膨胀更激进）。

## 八、灰度图像的形态学：拓展

将上述二值运算拓展到灰度图像——用邻域极值代替集合运算。

| 二值运算 | 灰度等价（对f(x,y), SE B） | 公式 |
|---------|--------------------------|------|
| 腐蚀 | 局部最小值 | (f ⊖ B)(x,y) = min{f(x+s,y+t) | (s,t)∈B} |
| 膨胀 | 局部最大值 | (f ⊕ B)(x,y) = max{f(x+s,y+t) | (s,t)∈B} |
| 开运算 | 先min后max | f ○ B = (f ⊖ B) ⊕ B |
| 闭运算 | 先max后min | f ● B = (f ⊕ B) ⊖ B |

**直觉**：
- 灰度腐蚀 = 使暗的区域更暗（"从暗色侵蚀亮色"）
- 灰度膨胀 = 使亮的区域更亮
- 灰度开运算 = 去掉亮的小噪点（比B小的亮斑）
- 灰度闭运算 = 去掉暗的小孔（比B小的暗斑）

**代码中 `grayscale_open(img)` 和 `grayscale_close(img)` 演示此概念**。

## 九、本章函数完整参考

### 1. `morph_erode(img, kernel_size=3)`：腐蚀（邻域最小值）

### 2. `morph_dilate(img, kernel_size=3)`：膨胀（邻域最大值）

### 3. `morph_open(img, kernel_size=3)`：开运算 = 先腐蚀后膨胀

### 4. `morph_close(img, kernel_size=3)`：闭运算 = 先膨胀后腐蚀

### 5. `morph_boundary(img)`：内部边界 = 原图 - 腐蚀图

### 6. `morph_hole_fill(img)`：填充孔洞（从边界区域生长）

### 7. `hit_or_miss(img, kernel)`：击中/击不中（精确模式匹配）

### 8. `remove_small_objects(img, min_size=100)`：移除小连通区域（基于连通分量）

### 9. `grayscale_open(img, kernel_size=3)` / `grayscale_close(img, kernel_size=3)`：灰度开闭

### 10. `morphological_gradient(img)`：形态学梯度 = 膨胀 - 腐蚀（边缘检测）

### 11. `top_hat(img, kernel_size=5)`：顶帽变换（Top-Hat）

```
Top-Hat(f) = f - (f ○ B) = 原图 - 开运算图

作用: 提取比结构元小的"亮细节"（在较暗背景上的小亮物体）

典型应用: 细胞计数、缺陷检测（从不均匀光照提取小目标）
```

### 12. `bottom_hat(img, kernel_size=5)`：底帽变换（Black-Hat）

```
Black-Hat(f) = (f ● B) - f = 闭运算图 - 原图

作用: 提取比结构元小的"暗细节"（在较亮背景上的小暗物体）
```

## 十、形态学实用流程

**典型场景1：从噪声的二值图像中清理物体**

```
输入: 有小噪点 + 有小孔洞的二值图像

1. 开运算 (3×3) → 去掉小噪点
2. 闭运算 (3×3) → 填充小空洞 + 连接断裂
3. 可选: 再开运算/闭运算（幂等性保证不会更差）

输出: 干净的二值物体
```

**典型场景2：从不均匀光照的图像中提取目标**

```
输入: 背景光照不均匀的灰度图像（一边亮一边暗）

1. 顶帽变换 (15×15) → 提取"比局部背景亮的物体"（同时抵消光照不均）
2. 阈值化 → 得到二值目标
3. 开运算 (3×3) → 清理小噪点

输出: 二值目标
```

## 十一、初学者常见问题解答

### Q1: 腐蚀让物体变小，膨胀让物体变大——为什么不直接用resize？

**答**：形态学操作改变的是**形状**，不是均匀缩放。腐蚀/膨胀的效果取决于**局部结构**：

```
原图: 细长的"手指"形状  → 腐蚀(3×3) → 手指变细且变短，甚至可能断裂！

相比之下: resize(0.9)  → 只是均匀缩小0.9倍，形状比例不变

关键区别: 形态学探测"形状"——细长部分更易被腐蚀掉
```

直觉：想象结构元是一个小圆。腐蚀 = "在物体内部滚这个圆，不能触及的点被去掉"——细的地方圆无法通过，被整个"切掉"。

### Q2: 开闭运算顺序重要吗？先开后闭 vs 先闭后开有区别吗？

**答**：有显著区别！

| 顺序 | 效果 | 适用场景 |
|------|------|---------|
| 先开后闭 | 先去小亮点→再填小暗洞 | 大多数情况（噪声是亮点+内部有小孔） |
| 先闭后开 | 先填小暗洞→再去小亮点 | 噪声是暗点为主 |

**但实际上**：两者差异通常不大（尤其SE较大时），经验法则是先用开运算去噪。

**开闭交替**：有时用 open→close→open→close 会得到更平滑的结果（但幂等性保证同一运算重复无区别）。

## 十二、章节总结

```
本章知识结构
├── 集合论基础
│   ├── 并 ∪、交 ∩、补 Aᶜ、差 A-B、平移 A+z、反射 B̌
│   └── 结构元(SE) B = "探针"/"核"
├── 二值形态学四运算
│   ├── 腐蚀 A⊖B = { z | B+z ⊆ A } → 物体变小，去亮点噪点，断开粘连
│   ├── 膨胀 A⊕B = { z | (B̌+z) ∩ A ≠ ∅ } → 物体变大，填暗孔，连接断裂
│   ├── 开运算 A○B = (A⊖B)⊕B → 去小凸包，平滑边界（幂等）
│   └── 闭运算 A●B = (A⊕B)⊖B → 填小凹洞，连接邻近物体（幂等）
├── 形态学应用
│   ├── 边界提取: β = A - (A⊖B) 或 (A⊕B) - (A⊖B)
│   ├── 区域填充: 从边界0开始生长 → 取反=填充结果
│   ├── 击中/击不中: 精确模式匹配
│   └── 移除小物体: (A○B) 或 连通分量分析后过滤
├── 灰度形态学
│   ├── 腐蚀(f,B) = 局部最小值
│   ├── 膨胀(f,B) = 局部最大值
│   ├── 开运算 = 去小亮斑
│   ├── 闭运算 = 去小暗洞
│   ├── Top-Hat = f - (f○B) → 提取亮小物体（抵消光照不均）
│   └── Black-Hat = (f●B) - f → 提取暗小物体
├── 结构元选择
│   ├── 3×3方形: 通用首选
│   ├── 圆形/圆盘: 各向同性（无方向偏好）
│   ├── 水平/垂直线: 仅处理特定方向结构
│   └── SE大小 = 控制"激进程度"
└── 实用流程
    ├── 去噪清理: 开运算(3×3) → 闭运算(3×3)
    ├── 光照不均: Top-Hat(大SE) → 阈值化
    └── 连通区域: 分析后按面积过滤小噪点
```
