# 第11章：表示与描述

> **面向零基础读者**：分割后我们得到了物体的像素集合（"这个区域是一个物体"），但计算机还需要一种简洁的**数学表示**才能理解"这是什么形状"。本章学习如何从像素集合中提取描述形状、纹理和边界的特征。

---

## 一、表示 vs 描述

| 表示（Representation） | 描述（Description） |
|-----------------------|-------------------|
| 用什么数据结构存储形状 | 从形状中提取的数值特征 |
| 链码、多边形近似、骨架 | 面积、周长、圆形度、矩不变量、傅里叶描述子 |
| 关注"如何表示形状" | 关注"这个形状有什么特性" |
| 用于重建/可视化 | 用于分类/识别 |

## 二、边界表示：链码（Chain Code）

### 2.1 4-方向链码（Freeman 码）

```
从边界上一个起点开始，按顺时针/逆时针方向跟踪边界。
每个步的方向编码为 0/1/2/3:

方向码（4方向）:
   3 ↑
     |
 2 ←-●-→ 0
     |
     ↓ 1

例: 正方形边界（从左上角开始，顺时针）:

● → ● → ●
          ↓
●        ●
↑        ↓
●        ●
↑        ↓
● ← ● ← ●

链码: 0,0,1,1,2,2,3,3 （走右,右,下,下,左,左,上,上）

归一化链码: 将起点旋转到最小字典序（消除起点依赖）
```

### 2.2 8-方向链码

```
方向码（8方向，对角线也允许）:
5  6  7
 \ | /
4 -●- 0
 / | \
3  2  1

0=右, 1=右下, 2=下, 3=左下, 4=左, 5=左上, 6=上, 7=右上
```

**链码的优势**：
- 存储紧凑（边界用一串数字表示）
- 易于计算长度（4-链码：垂直/水平=1，8-链码：对角=√2）
- 可做差分链码（旋转不变的第一步）

## 三、边界描述符：傅里叶描述子（Fourier Descriptors）

**思想**：把边界看作二维曲线 → 参数化 → 做傅里叶变换 → 用低频系数描述整体形状，高频描述细节。

```
边界上的 N 个点: (x₀,y₀), (x₁,y₁), ..., (x_{N-1}, y_{N-1})

定义复序列: s(k) = x(k) + j·y(k), k = 0, 1, ..., N-1

DFT: F(u) = (1/N) Σ s(k)·exp(-j·2π·u·k/N), u = 0, 1, ..., N-1

F(0) = 边界的质心位置（平移敏感，通常忽略或归一化）
F(1) = 最主要的形状分量（整体轮廓）
...
F(u) 大 = 有对应频率的形状变化

用前 M 个系数（M << N）重建:
s'(k) = Σ_{u=0}^{M-1} F(u)·exp(+j·2π·u·k/N)

M=2 → 椭圆近似（最低频，整体形状）
M=8 → 较好轮廓
M=32 → 几乎完美重建
```

**傅里叶描述子的不变性**（关键性质！）：

| 操作 | 对描述子的影响 | 如何归一化使其不变 |
|------|--------------|-----------------|
| 平移 s+Δ | F(0)+Δ, F(u≠0)不变 | 忽略 F(0) 或减去 |
| 旋转 θ° | F(u)·exp(j·θ·u) | 用 |F(u)|（幅度谱）或相对相位 |
| 缩放 s×α | F(u)×α | 除以 |F(1)| 或最大幅度 |
| 起点偏移 s(k+k₀) | F(u)·exp(-j·2π·u·k₀/N) | 用幅度或归一化相位 |

**结论**：用 |F(u)|/|F(1)| 作为描述子 → 对平移、旋转、缩放、起点都不变！

## 四、区域描述符：矩与矩不变量（Moments）

### 4.1 基本矩

```
图像 f(x,y) 的 p+q 阶矩:
m_{p,q} = Σ_x Σ_y x^p · y^q · f(x,y)

对二值图像（f=1 在物体内，f=0 在物体外）:
m_{0,0} = 物体像素数 = 面积 A
m_{1,0} = Σ x·f(x,y) → x方向的"一阶矩"
m_{0,1} = Σ y·f(x,y) → y方向的"一阶矩"

质心（centroid）:
x̄ = m_{1,0} / m_{0,0}
ȳ = m_{0,1} / m_{0,0}
```

### 4.2 中心矩（对平移不变）

```
μ_{p,q} = Σ_x Σ_y (x - x̄)^p · (y - ȳ)^q · f(x,y)

μ_{0,0} = m_{0,0} = A（不变，因为 Σ(x-x̄)^0·(y-ȳ)^0·f = Σ f = A）
μ_{1,1} = 二阶中心混合矩（协方差的度量）
μ_{2,0}, μ_{0,2} = x/y方向的"方差"
μ_{2,0} + μ_{0,2} = 对所有方向都有意义（各向同性度量）
```

### 4.3 归一化中心矩（对缩放+平移不变）

```
η_{p,q} = μ_{p,q} / μ_{0,0}^{(p+q+2)/2}

直觉: 把"矩的尺度"用 μ_{0,0} = 面积来归一化
     放大2倍 → μ 放大 2^{p+q}·2²（坐标放大2倍 + 每个像素代表4像素）
     → η 不变！
```

### 4.4 Hu 矩不变量（Hu's Moment Invariants，1962）

**7 个 Hu 矩**（对平移、旋转、缩放都不变！）：

```
φ₁ = η₂,₀ + η₀,₂
φ₂ = (η₂,₀ - η₀,₂)² + 4·η₁,₁²
φ₃ = (η₃,₀ - 3·η₁,₂)² + (3·η₂,₁ - η₀,₃)²
φ₄ = (η₃,₀ + η₁,₂)² + (η₂,₁ + η₀,₃)²
φ₅ = (η₃,₀ - 3·η₁,₂)(η₃,₀ + η₁,₂)·[(η₃,₀+η₁,₂)² - 3·(η₂,₁+η₀,₃)²]
    + (3·η₂,₁ - η₀,₃)(η₂,₁ + η₀,₃)·[3·(η₃,₀+η₁,₂)² - (η₂,₁+η₀,₃)²]
φ₆ = (η₂,₀ - η₀,₂)·[(η₃,₀+η₁,₂)² - (η₂,₁+η₀,₃)²]
    + 4·η₁,₁·(η₃,₀+η₁,₂)(η₂,₁+η₀,₃)
φ₇ = (3·η₂,₁-η₀,₃)(η₃,₀+η₁,₂)·[(η₃,₀+η₁,₂)²-3·(η₂,₁+η₀,₃)²]
    - (η₃,₀-3·η₁,₂)(η₂,₁+η₀,₃)·[3·(η₃,₀+η₁,₂)²-(η₂,₁+η₀,₃)²]
```

**关键性质**：
- φ₁-φ₆: 对平移、旋转、缩放、反射（镜像）都不变
- φ₇: 对反射变号（"手征"度量，可区分左右对称形状）

**实际使用**：Hu 矩的值通常很小（10⁻³ ~ 10⁻¹⁰），为数值稳定通常取 log(|φ|) 或归一化。

**代码中 `hu_moments(img)` 计算并打印 7 个 Hu 矩**。

## 五、简单形状描述符

| 描述符 | 公式 | 含义 | 典型值（圆形=1） |
|-------|------|------|-----------------|
| **面积（Area）** | A = 物体像素数 | 大小 | - |
| **周长（Perimeter）** | P = 边界像素数（链码长度） | 边界长度 | - |
| **圆形度（Circularity）** | C = 4π·A/P² | 接近圆形的程度 | 圆=1，正方形=π/4≈0.79 |
| **长宽比（Aspect Ratio）** | AR = width/height | 细长程度 | 圆/方=1，细长线>>1 |
| **偏心率（Eccentricity）** | ε = √(1-(b/a)²) a=长半轴 b=短半轴 | 偏离圆形 | 圆=0，线→1 |
| **实心度（Solidity）** | A / A_convex （A_convex=凸包面积） | 凹/凸程度 | 凸形状=1 |
| **极值点** | 最小/最大 x,y | 边界框 | - |
| **投影** | 水平/垂直投影直方图 | 形状的"投影" | - |

**圆形度的直觉**：
```
圆: A = πr², P = 2πr → C = 4π·πr²/(2πr)² = 4π²r²/4π²r² = 1 ✅
正方形（边长s）: A = s², P = 4s → C = 4π·s²/(4s)² = π/4 ≈ 0.79
细长方形（1×100）: A = 100, P ≈ 202 → C = 4π·100/202² ≈ 0.03

所以: 圆 → 1（最大），越细长 → 越小
```

## 六、纹理描述（Texture Description）

### 6.1 什么是纹理？

> 纹理 = "局部模式的重复"——草、布纹、木纹都是纹理。纹理比"光滑"区域有更多高频信息。

### 6.2 灰度共生矩阵（Gray-Level Co-occurrence Matrix, GLCM）

**核心思想**：计算"在距离 d、方向 θ 上，两个像素分别为 i 和 j 的频率"。

```
设图像有 L 个灰度级（如 0-255，但通常压缩到 0-15 以减少计算）

GLCM P(i, j | d, θ) = 图像中满足以下条件的像素对(x,y)和(x',y')的数量:
1. 距离 |(x,y)-(x',y')| = d
2. 方向 (x',y')-(x,y) = θ
3. f(x,y) = i, f(x',y') = j

典型 d=1, θ = 0°（水平）, 45°, 90°, 135°

从 GLCM 提取的纹理特征:

1. **对比度（Contrast）** = Σ Σ (i-j)²·P(i,j)
   （大对比度 = 相邻像素差异大 = 粗糙纹理）

2. **相关度（Correlation）** = Σ Σ [(i·j·P(i,j)) - μ_i·μ_j]/(σ_i·σ_j)
   （高相关 = 纹理有规律的重复模式）

3. **能量（Energy/ASM）** = Σ Σ P(i,j)²
   （高能量 = 均匀纹理，少变化）

4. **逆差分矩（Homogeneity）** = Σ Σ P(i,j)/(1+|i-j|)
   （高同质性 = 光滑，变化小）

直觉对比:
- 细沙地（均匀）: 能量高、对比度低、同质性高
- 粗糙石头: 能量低、对比度高、同质性低
- 有规律条纹: 相关度高
```

## 七、主成分分析（PCA）：降维特征

**思想**：如果有 D 维特征，但很多维度相关（冗余），PCA找最重要的 K 个方向（方差最大）。

```
设特征向量矩阵 X (N样本×D维):
1. 去均值: X_c = X - mean(X)
2. 协方差: C = X_cᵀ X_c / (N-1)
3. 特征分解: C = V Λ Vᵀ （V=特征向量, Λ=对角特征值矩阵）
4. 按 λ 降序排列 V 的列
5. 取前 K 列: V_K (D×K)
6. 降维: Y = X_c · V_K (N×K)

直觉: 找到数据"变化最大的方向"=最具区分力的方向

总方差: Σ λ_i（所有特征值之和）
解释方差比例: (Σ_{i=1}^{K} λ_i) / (Σ_{i=1}^{D} λ_i)
通常取K使比例 ≥ 95%
```

**代码中 `pca_analysis(data, n_components=3)` 使用 sklearn PCA**。

## 八、本章函数完整参考

### 1. `calculate_area(img)`：面积 = 物体像素数（对二值图像）

### 2. `calculate_perimeter(img)`：周长 = 边界长度（邻接4/8连接的边界像素）

### 3. `bounding_rectangle(img)`：边界框 = min/max x,y 的矩形

### 4. `centroid(img)`：质心 = (x̄, ȳ) = (m₁₀/m₀₀, m₀₁/m₀₀)

### 5. `centroid_moments(img)`：中心矩 μ_{p,q}

### 6. `hu_moments(img)`：7个 Hu 矩不变量（平移/旋转/缩放不变）

### 7. `circularity(img)`：圆形度 C = 4π·A/P²

### 8. `aspect_ratio(img)`：长宽比

### 9. `eccentricity(img)`：偏心率（从协方差矩阵的特征值比）

### 10. `compute_projections(img)`：水平/垂直投影

### 11. `chain_code(img)`：4-方向链码

### 12. `fourier_descriptors(img, n_descriptors=10)`：傅里叶描述子（前N个DFT系数）

### 13. `glcm_features(img, distances=[1], angles=[0])`：灰度共生矩阵特征（对比度/相关度/能量/同质性）

### 14. `lbp_features(img, radius=1, n_points=8)`：局部二值模式（Local Binary Pattern）纹理

**LBP 直觉**：对每个中心像素，比较周围8个邻居 → 大于中心=1，小于=0 → 得到8位二进制数 → 转换为0-255 → 用 LBP 值的直方图描述纹理

### 15. `hog_features(img, cell_size=8, block_size=2, n_bins=9)`：方向梯度直方图（Histogram of Oriented Gradients）

**HOG 直觉**（2005 Dalal & Triggs 人体检测论文）：
```
1. 把图像分成 8×8 的小单元格（cell）
2. 对每个cell，计算每个像素的梯度方向 θ = arctan2(Sy, Sx)
3. 把梯度方向离散化为 9 个 bin（0-180°，每20°一个bin）
4. 每个像素按梯度幅度加权投票到方向直方图
5. 相邻 2×2 cell 组成 block，归一化（对光照变化鲁棒）
6. 拼接所有block的直方图 → 最终特征向量

直觉: HOG描述"局部的边缘方向分布"→人类的轮廓可以由这些方向的组合描述

优点: 对光照/对比度变化鲁棒（归一化步骤）
缺点: 不处理遮挡，计算量大

**skimage.feature.hog 为工业标准实现**
```

### 16. `pca_analysis(data, n_components=3)`：PCA降维（可视化高维数据）

### 17. `skeletonize(img)`：骨架化（把物体变薄为1像素宽的"骨架"）

**骨架 = 形状的"中轴"**，保留拓扑和形状比例。

## 九、特征选择与融合

**为什么需要多种特征？**

| 只用一种特征 | 问题 |
|------------|------|
| 只用 Hu 矩 | 不区分纹理（光滑圆 vs 纹理圆相同） |
| 只用 HOG | 不区分整体形状 |
| 只用 GLCM | 不区分整体大小/比例 |

**最佳实践：特征融合**（Concatenate multiple feature types）

```
特征向量 = [Hu矩（7维）, 形状描述（4维）, GLCM（4维）, HOG（3780维）]
           整体形状 +     比例   +   纹理   +  精细边缘

然后: 用 PCA 降维（如3795维 → 50维）以减少冗余并加速后续分类
```

## 十、初学者常见问题解答

### Q1: Hu 矩的"不变性"真的完美吗？实际使用中有什么坑？

**答**：理论上 Hu 矩对平移、旋转、缩放严格不变——但在**离散图像**（像素网格）上有实际问题：

```
挑战1: 离散化误差
        连续形状旋转后在像素网格上采样 → 边界像素略有不同
        → Hu矩有微小变化（<5%通常可以接受）

挑战2: 小形状
        小物体（<20×20像素）的矩估计很不可靠
        → 先放大或用更细的描述（如傅里叶描述子）

挑战3: 数值稳定性
        Hu 矩的值通常很小（φ₁~10⁻², φ₇~10⁻¹⁰）
        → 实际使用常取 log(|φ|) 或归一化

挑战4: "相似"但"不同"的形状可能有相近的Hu矩
        → Hu矩是"粗描述"，不是唯一标识
        → 建议与傅里叶描述子/HOG组合使用
```

**改进方案**：Zernike矩（正交，有更好重建性质，对噪声更鲁棒，旋转严格不变，但计算更复杂）。

## 十一、章节总结

```
本章知识结构
├── 边界表示
│   ├── 链码: 4/8方向Freeman码（紧凑存储+长度计算）
│   └── 多边形近似: RDP算法（用最少线段近似）
├── 边界描述（从边界提取数值特征）
│   └── 傅里叶描述子: s(k)=x(k)+jy(k) → DFT → F(u)
│       ├─ F(0)=质心，F(1)=主要形状
│       └─ 归一化幅度 |F(u)|/|F(1)| → 平移/旋转/缩放/起点不变
├── 区域描述（从整个物体提取数值特征）
│   ├── 基本矩: m_{p,q}=ΣΣ x^p y^q f
│   ├── 中心矩: μ_{p,q}=ΣΣ (x-x̄)^p (y-ȳ)^q f → 平移不变
│   ├── 归一化中心矩: η_{p,q}=μ_{p,q}/μ_{0,0}^{(p+q+2)/2} → +缩放不变
│   ├── Hu矩不变量: 7个φ → 平移+旋转+缩放不变
│   │   └─ φ₇对镜像变号（手征）
│   ├── 简单形状:
│   │   ├─ 圆形度 C=4π·A/P²（圆=1，越细长越小）
│   │   ├─ 长宽比 AR=w/h
│   │   ├─ 偏心率 ε=√(1-b²/a²)
│   │   └─ 实心度 A/A_convex
│   └── 拓扑属性: 欧拉数 E = C - H（连通数-洞数，拓扑不变）
├── 纹理描述
│   ├── GLCM: P(i,j|d,θ) = 灰度对(i,j)出现频率
│   │   ├─ 对比度=ΣΣ(i-j)²P, 相关度, 能量=ΣΣP², 同质性
│   │   └─ 典型d=1, θ=0/45/90/135°
│   └── LBP: 对每个中心，邻居与中心比较→二进制→直方图
├── 整体形状/轮廓描述
│   ├── HOG: 8×8 cell梯度方向直方图 → 2×2 block归一化
│   │   └─ 2005年人体检测论文，现代特征基线
│   ├── SIFT/SURF: 局部兴趣点描述子（见下一章）
│   └── 骨架/中轴: 保持形状拓扑+比例
├── 降维
│   └── PCA: 协方差→特征值分解→取前K个最大方差方向
│       └─ 解释方差≥95%常用选择K
└── 实践建议
    ├── 分类/识别: Hu矩+傅里叶描述子+HOG的组合
    ├── 纹理/材质: GLCM+LBP
    ├── 检测对齐形状: 简单形状描述符（面积、长宽比）
    └── 先降维(PCA)再送入分类器
```
