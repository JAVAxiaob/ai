# 第5章：图像复原与重建

> **面向零基础读者**：图像增强（第3章）是"让图片看起来更好"，而图像复原则是"试图恢复图片本来的样子"——前者是主观美化，后者是客观重建。本章学习如何去除模糊（运动/散焦）、抑制噪声，甚至从投影重建CT图像。

---

## 一、图像复原 vs 图像增强

| 维度 | 图像增强（第3章） | 图像复原（本章） |
|------|------------------|----------------|
| 目标 | 主观视觉改善 | 客观重建原始信号 |
| 方法 | 启发式（hist EQ, CLAHE...） | 基于模型（退化模型+逆过程） |
| 先验知识 | 极少 | 需假设噪声/模糊类型和参数 |
| 评价 | 主观视觉 | PSNR/SSIM/与真值对比 |

## 二、噪声模型

### 2.1 噪声分类与来源

| 噪声 | PDF/模型 | 典型来源 | 图像特征 |
|------|---------|---------|---------|
| **高斯** | N(μ, σ²) | 电子读出噪声、热噪声 | 均匀散布颗粒 |
| **瑞利** | f(z) = (z/b)·exp(-z²/2b) | 雷达/超声成像 | 正偏斜，长尾 |
| **爱尔兰（伽马）** | f(z) = z^(a-1)·exp(-z/b) / b^a·Γ(a) | 激光成像 | 正偏，更尖锐 |
| **指数** | f(z) = (1/b)·exp(-z/b) | 成像系统缺陷 | 衰减极快 |
| **均匀** | f(z) = 1/(b-a) | 量化误差 | 所有值等概率 |
| **椒盐/脉冲** | P(0)=p_a, P(255)=p_b | 传输错误、死像素 | 黑白散点 |
| **周期** | A·sin(2π(ux+vy)/N + φ) | 电源/电机干扰 | 规则条纹 |
| **斑点（乘性）** | f·η, η~Gamma | SAR雷达、超声 | 与信号强度成正比 |

**估计噪声参数**：
- 从均匀区域取一小块，计算直方图 → 拟合高斯/瑞利等分布
- σ = 该区域像素值的标准差

### 2.2 空间域去噪（第3章回顾 + 本章扩展）

**均值滤波器家族**：

| 方法 | 公式 | 特点 | 适用 |
|------|------|------|------|
| 算术均值 | g = (1/MN)·Σf | 简单模糊 | 高斯噪声 |
| 几何均值 | g = (Πf)^(1/MN) | 比算术均值保留更多细节 | 高斯噪声 |
| 谐波均值 | g = MN / Σ(1/f) | 对"盐"噪声好，对"椒"差 | 盐噪声 |
| 反谐波均值 | g = Σf^(Q+1) / Σf^Q | Q=-1去盐，Q=1去椒 | 椒盐噪声，已知类型 |

**统计排序滤波器**：

| 方法 | 操作 | 备注 |
|------|------|------|
| **中值** | 排序取中间值 | 椒盐噪声克星 |
| **最大值** | 取邻域最大值 | 消除"椒"（黑点） |
| **最小值** | 取邻域最小值 | 消除"盐"（白点） |
| **中点** | (max+min)/2 | 对均匀/高斯噪声 |
| **修正α-均值** | 去掉d个最大最小后取平均 | 灵活折中 |

**自适应滤波器**：

```
自适应局部降噪（Adaptive Local Noise Reduction）：

设:
  σ_η² = 噪声方差（预先估计，或从均匀区域计算）
  σ_L² = 局部邻域方差
  f_L  = 局部邻域均值

则: g(x,y) = f(x,y) - (σ_η² / σ_L²) · (f(x,y) - f_L)

直觉：
- 如果 σ_L² 很大（边缘区域）→ 修正项小 → 几乎不变（保留边缘）
- 如果 σ_L² ≈ σ_η²（平坦区域，噪声主导）→ 修正项大 → 输出接近均值
- 如果 σ_L² 很小（完全平坦）→ 修正项适中
```

**双边滤波（Bilateral Filter）**：

空间域 + 灰度值域双权重的边缘保持平滑。

```
w(i,j,k,l) = w_s · w_r

w_s = exp(-((i-k)²+(j-l)²)/(2σ_s²))  ← 空间域权重（距离越近越信任）
w_r = exp(-(|f(i,j)-f(k,l)|²)/(2σ_r²))  ← 值域权重（灰度越接近越信任）

g(x,y) = (Σ w·f) / (Σ w)
```

关键：在边缘处，两侧像素灰度差大 → w_r 小 → 不做平均 → 边缘保留！

## 三、图像退化模型

### 3.1 线性空间不变退化

```
g(x,y) = (h * f)(x,y) + η(x,y)

其中:
  g = 观察到的退化图像
  h = 退化函数（点扩散函数 PSF）
  f = 原始清晰图像（待恢复！）
  η = 加性噪声
  * = 二维卷积
```

**频域表示**：
```
G(u,v) = H(u,v) · F(u,v) + N(u,v)
```

### 3.2 常见退化函数

| 退化 | h(x,y) 或 H(u,v) | 参数 | 图像特征 |
|------|------------------|------|---------|
| **运动模糊** | h = rect(x/T)·δ(y)（沿x方向匀速运动T时间） | 运动长度/角度 | 方向性条纹模糊 |
| **散焦模糊** | h = circ(r/R)/πR²（均匀圆盘） | 半径R | 对称圆形模糊 |
| **高斯模糊** | h = exp(-(x²+y²)/2σ²) | σ | 自然平滑模糊 |
| **大气湍流** | H = exp(-k·(u²+v²)^(5/6)) | k | 高空/航拍图像 |
| **运动+噪声** | 上述 + 高斯噪声 | σ_η | 最常见实际场景 |

## 四、逆滤波（Inverse Filtering）

### 4.1 朴素逆滤波

```
Ĝ = G / H = F + N/H

问题：
1. H(u,v)=0 的频率处 → 除零错误
2. 高频处 |H| 很小 → |N/H| 可能巨大 → 噪声被"无限"放大！
```

### 4.2 伪逆滤波（Pseudo-inverse）

```
Ĥ⁺(u,v) = 1/H(u,v)  if |H(u,v)| ≥ ε
         = 0        otherwise

或更平滑的版本：
Ĥ⁺ = H* / (|H|² + ε)

其中 ε 是一个小常数，避免除零。
```

代码中的 `inverse_filter(img, threshold=0.01)`：
```
h_inv = conj(h) / (|h|² + threshold)
```

## 五、维纳滤波（Wiener Filtering）——"最优"线性复原

### 5.1 最小均方误差意义下的最优

维纳滤波最小化 E[|f - f̂|²]（期望均方误差）。

**频域形式**：
```
Ĝ(u,v) = [ H*(u,v) / (|H(u,v)|² + S_η/S_f) ] · G(u,v)

其中:
  H* = H 的复共轭
  S_η = |N|² = 噪声功率谱
  S_f = |F|² = 信号功率谱（原图像，未知！）

简化（代码中使用）：
假设 S_η/S_f = K（常数，信噪比的倒数）

Ĝ = [ H* / (|H|² + K) ] · G
```

**参数 K 的意义**：
- K = 0 → 退化为逆滤波（无噪声时最优）
- K 大 → 噪声主导 → 更"保守"，输出更平滑
- K 小 → 信号主导 → 更接近逆滤波

**如何选择 K？**
1. 先验知识（已知 SNR → K = 1/SNR）
2. 试验法（视觉调整）
3. 迭代优化（如 Richardson-Lucy）

代码中 `wiener_filter_spatial(img, K=0.01)` 假设噪声不大（高SNR场景）。

## 六、约束最小二乘（Constrained Least Squares）

**思想**：既要拟合观测数据，又要输出"平滑"。

**优化问题**：
```
min ||g - h*f̂||² + γ · ||∇²f̂||²
      ↑ 保真项        ↑ 平滑正则项（拉普拉斯平方和）
```

**频域解**：
```
Ĝ = [ H* / (|H|² + γ·|P|²) ] · G

其中 P = 拉普拉斯算子的傅里叶变换
P(u,v) = -4π²(u²+v²)
```

**与维纳的关系**：形式相同，但分母第二项是 γ·|P|² 而非 K——对高频的抑制更强（因为 |P| ∝ u²+v²），所以对边缘以外的区域平滑更激进。

代码中 `constrained_least_squares(img, gamma=0.1)`：
- gamma 大 = 更强平滑 = 更保守
- gamma 小 = 更接近逆滤波 = 更锐利但噪声多

## 七、盲复原（Richardson-Lucy）

**问题**：前面的方法都假设已知 h（退化函数）——但实际中往往不知道！

**Richardson-Lucy 算法**（1972）：在泊松噪声模型下的最大似然估计。

**迭代更新**：
```
f̂^(k+1) = f̂^(k) · [ (g / (f̂^(k) * h)) * h_flip ]

直觉：
- g / (f̂*h) = "修正因子"：如果当前估计好 → 比值接近1
- 通过 h 的反向卷积传播修正
- 泊松噪声下可证收敛到 ML 解
```

**特点**：
- ✅ 不需要显式估计噪声方差
- ✅ 对泊松噪声（光子计数成像，如天文、荧光显微）理论最优
- ⚠️ 需要知道 h（或同时估计 h 和 f，变成真正的"盲"问题）
- ⚠️ 迭代过多会产生振铃（需提前停止）

代码中 `blind_deconvolution(img, iterations=5)` 使用 scikit-image 的实现。

## 八、Radon 变换与投影重建（CT原理）

### 8.1 Radon 变换

```
给定图像 f(x,y)，沿角度 θ 的投影：
R_θ(t) = ∫∫ f(x,y) · δ(x·cosθ + y·sinθ - t) dxdy

直觉：从某个方向"透视"图像，累计每个"射线"穿过的像素值。

物理类比：CT扫描 = X射线从不同角度穿过人体，探测器记录投影强度。
```

### 8.2 滤波反投影（Filtered Back Projection, FBP）

重建步骤：
```
Step 1: 采集所有角度的投影 → 得到 sinogram（R_θ(t)）
Step 2: 对每个投影的 t 维度做 1D 滤波
   频域：ρ_ω = |ω| · R_θ(ω) （斜坡滤波，抑制低频，增强高频=边缘）
Step 3: 反投影（将滤波后的投影"涂抹"回图像空间）
Step 4: 对所有角度的反投影求和 → 重建图像
```

代码中 `radon_reconstruction_demo(img, num_angles=180)`：
- 使用 scikit-image 的 radon/iradon
- 180个角度 = 每度一个投影（医学CT典型值~1000个角度）
- 角度越少 → 图像质量越差（欠采样伪影）

## 十、初学者常见问题解答

### Q1: 图像去噪和图像增强有什么本质区别？

**答**：图像增强 = 主观改善（让你"觉得"更好），图像复原 = 客观重建（试图恢复"真实"图像）。

| 方法 | 属于增强还是复原？ | 依据 |
|------|-----------------|------|
| 直方图均衡化 | 增强 | 改变分布，不基于噪声模型 |
| 中值滤波 | 两者皆可 | 如是去椒盐噪声=复原；如是平滑=增强 |
| 维纳滤波 | **复原** | 明确建模：g = h*f + η，试图恢复f |
| Unsharp Masking | 增强 | 经验性锐化，无退化模型 |
| 同态滤波 | **复原（部分）** | 有照度-反射物理模型 |

实际工程中，两者常常组合使用——先复原去噪，再增强对比度。

### Q2: 维纳滤波为什么比逆滤波好？K值应该怎么选？

**答**：逆滤波在H≈0处会极大放大噪声（N/H → ∞），而维纳滤波有个"安全垫"——分母是 |H|² + K，永远不为零。

```
逆滤波:  F_hat = G/H = F + N/H    ← N/H 可能爆炸！
维纳滤波: F_hat = (H*/(|H|²+K))·G = (|H|²/(|H|²+K))·F + (H*/(|H|²+K))·N
            ↓                        ↓
          当|H|大时≈1（信号通过）  当|H|小时≈H*/K（噪声被抑制）
```

**K的选择经验**：
- 先看图像噪声多不多，凭直觉选初始 K = 0.001 ~ 0.1
- 看输出：太锐利有噪声 → 增大K；太模糊 → 减小K
- 如果你能估计噪声方差 σ² 和信号方差 σ_f²：K ≈ σ²/σ_f²

### Q3: CT重建是怎么从"投影"得到"横断面"的？魔术吗？

**答**：不是魔术——数学上可以精确证明：**足够多方向的投影可以唯一确定原始图像**（这是Radon 1917年的工作，Cormack/Hounsfield 因此获1979诺贝尔奖）。

**简化直觉**：
```
想象从顶部看一个人：
← 从左投影 → [亮 暗 暗 亮] （骨头挡住X光所以暗）
← 从斜角投影 → [亮 暗 亮 暗] （不同角度看到不同"叠加"）

如果你有几百个角度的投影，你可以反解出每个位置的"密度"！

滤波反投影 = 先对每个投影做"反锐化"补偿模糊，再"涂抹"回图像
```
