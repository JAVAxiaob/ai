# 第10章：图像分割

> **面向零基础读者**：图像分割 = "把图像分成有意义的区域"——前景 vs 背景、物体 vs 其他物体。这是从"像素"到"语义"的关键一步——没有分割就没有识别。本章学习多种分割方法：阈值、边缘、区域、聚类等。

---

## 一、阈值化（Thresholding）：最简单但最有用

### 1.1 基础阈值

```
g(x,y) = 1  if f(x,y) ≥ T
        = 0  otherwise

T = 阈值

视觉: 所有亮于T的像素→白(1)，暗于T的像素→黑(0)
```

**适用场景**：目标与背景灰度差异明显，直方图有明显双峰。

---

### 1.2 Otsu 方法（大津法）：自动找最优阈值

**核心思想**：找一个阈值 T，使得被分开的两类（"亮"和"暗"）之间的**类间方差**最大。

```
设:
  p_i = 灰度值i的概率 (直方图归一化)
  T = 当前候选阈值
  ω_0(T) = Σ_{i=0}^{T} p_i   = 暗类像素比例
  ω_1(T) = Σ_{i=T+1}^{L-1} p_i = 亮类像素比例
  μ_0(T) = Σ_{i=0}^{T} i·p_i / ω_0(T) = 暗类平均灰度
  μ_1(T) = Σ_{i=T+1}^{L-1} i·p_i / ω_1(T) = 亮类平均灰度
  μ_T = 全局平均 = ω_0·μ_0 + ω_1·μ_1

类间方差 σ_B²(T) = ω_0(T)·(μ_0(T)-μ_T)² + ω_1(T)·(μ_1(T)-μ_T)²
                 = ω_0(T)·ω_1(T)·(μ_0(T)-μ_1(T))²

最优 T* = argmax σ_B²(T)  （遍历所有可能的T，找最大的那个）

遍历范围: T = 0, 1, 2, ..., 255
```

**为什么是方差而不是均值？** 方差衡量"类之间有多不同"——方差大意味着两类确实分开了（远）。

---

### 1.3 自适应阈值（局部阈值）

**问题**：光照不均时，单一全局阈值失败（亮处的暗像素和暗处的亮像素都被错误分类）。

**解决**：每个像素用自己邻域的统计量决定阈值。

```
T(x,y) = α · mean(f in W(x,y)) - β
        或
T(x,y) = α · median(f in W(x,y)) - β

其中:
  W(x,y) = 以(x,y)为中心的邻域窗口（如 15×15 或更大）
  α = 系数，一般 = 1.0
  β = 偏移量，如 -10（使阈值略低于均值）

g(x,y) = 1  if f(x,y) ≥ T(x,y)
        = 0  otherwise
```

**直觉**：看局部邻居的平均亮度——如果我比邻居都亮，我就是"物体"；否则是"背景"。

**代码中 `adaptive_threshold(img, block_size=15, C=10)`** 使用 OpenCV 的 `cv2.ADAPTIVE_THRESH_MEAN_C`。

## 二、边缘检测（Edge Detection）

### 2.1 什么是边缘？

**数学定义**：图像灰度的**突变**——即一阶导数的极大值，或二阶导数的零交叉。

```
1D 信号（沿x方向扫描一行）：

f(x):    ▁▁▁▁▂▃▅▆▇▇▇▆▅▃▂▁▁▁▁   ← 灰度值（从暗到亮再到暗）

一阶导:  ▁▁▁▁▂▃▅▆▇▆▅▃▂▁▁▁▁▁▁   ← 最大正值 = 亮边缘（从暗到亮）

二阶导:  ▂▃▄▄▅▆▇▇▆▄▃▂▁▂▃▄▄▅   ← 从正到负的"零交叉" = 精确边缘位置
         
               ↑ 边缘在这里！

2D 图像的边缘方向 = 梯度方向（灰度变化最快的方向）
```

---

### 2.2 Sobel 算子

```
Sobel x 方向（检测垂直边缘）:
[ -1  0  +1 ]
[ -2  0  +2 ]
[ -1  0  +1 ]

Sobel y 方向（检测水平边缘）:
[ -1 -2 -1 ]
[  0  0  0 ]
[ +1 +2 +1 ]

梯度幅度: |∇f| = √(S_x² + S_y²)
梯度方向: θ = arctan2(S_y, S_x)

（为加速，实际代码中常用 |S_x|+|S_y| 近似）
```

**特点**：简单、计算快，但对噪声敏感，边缘较粗。

---

### 2.3 Canny 边缘检测（工业标准！）

**Canny 的 4 步骤**：

```
1. 高斯平滑（去噪）:
   f_smooth = f ⊗ G_σ   （σ 通常 = 1.0 ~ 2.0，大 = 去噪强但边缘丢失）

2. Sobel 梯度计算:
   S_x, S_y = Sobel(f_smooth)
   |∇f| = √(S_x² + S_y²)
   θ = arctan2(S_y, S_x)

3. 非极大值抑制（NMS，Non-Maximum Suppression）:
   对每个像素，检查它在梯度方向上的两个邻居
   如果当前像素的 |∇f| 大于两个邻居 → 保留（是边缘）
   否则 → 抑制（设为0，不是边缘）
   目的: 把粗边缘"细化"为1像素宽的细线

4. 双阈值 + 滞后连接（Hysteresis）:
   两个阈值: high（强边缘）和 low（弱边缘），通常 low = high/3 或 high/2
   
   if |∇f| > high: 标记为强边缘（1）
   if |∇f| < low:  标记为非边缘（0）
   if low ≤ |∇f| ≤ high: 标记为弱边缘
   
   最后一步连接: 弱边缘如果与强边缘相连 → 保留；否则 → 删除
   （这就是"滞后"——从强边缘延伸到弱边缘的连接过程）

最终输出: 二值边缘图
```

**为什么 Canny 好？**
- 高斯平滑 + NMS → 对噪声鲁棒，边缘细且准
- 双阈值 + 连接 → 减少断裂，边缘连续
- 可通过调整 σ 和阈值控制灵敏度

**代码中 `canny_edge(img, low=50, high=150)` 直接调用 OpenCV Canny**

## 三、区域生长（Region Growing）

**思想**：从"种子像素"开始，逐步将相似的邻居合并进来。

```
算法:
1. 选择/标记种子点（可以人工选，也可以自动选择）
2. 将种子点标记为区域
3. while 有新像素被加入:
   a. 对区域边界的每个像素，检查未标记的邻居
   b. if 邻居与区域的灰度差 < T（或其他相似性度量）
      → 标记为区域的一部分
4. 输出区域

相似度判据（"相似"的定义）:
- 绝对灰度差: |f(x,y) - mean_region| < T
- 统计相似性: 邻域直方图相似
- 梯度: 跨区域的梯度 < T（边缘表示区域边界）
```

**代码中 `region_growing(img, seed_row, seed_col, threshold)`** 手动实现了基础区域生长。

## 四、聚类分割：K-Means

**思想**：图像 = N 个像素，每个像素 = d 维特征向量（灰度=1维，RGB=3维，RGB+位置=5维）。将像素聚类为 K 组。

```
算法（Lloyd 迭代）:
1. 初始化 K 个聚类中心（随机选择K个像素）
2. while 未收敛:
   a. 分配: 每个像素 → 最近的聚类中心
   b. 更新: 每个聚类中心 = 该类所有像素的均值
3. 每个像素标记为其聚类中心的索引 → 分割结果

距离度量（"最近"的定义）:
- 仅灰度: d = |f - μ_k|
- 颜色: d = √((R-μ_kR)² + (G-μ_kG)² + (B-μ_kB)²)
- 颜色+位置: d = α·颜色距离 + β·空间距离（SLIC 超像素的思想）
```

**K 的选择**：通常先验知识决定（2类=前景背景，3类=天空+地面+物体...）。

**代码中 `kmeans_segment(img, k=3)` 使用 OpenCV cv2.kmeans**

## 五、霍夫变换（Hough Transform）：检测直线和圆

### 5.1 霍夫直线变换

**核心洞察**：一条直线在图像空间（x-y）= 一个点在参数空间（ρ-θ）。

```
直线的参数方程（法线式）:
ρ = x·cosθ + y·sinθ

其中:
  ρ = 原点到直线的垂直距离
  θ = 法线角度（0 ≤ θ < π）

空间→参数的"投票"过程:
对每个边缘像素(x,y):
  for θ = 0, 1, 2, ..., 179 (1°步长):
    ρ = x·cosθ + y·sinθ
    在累加器 accumulator[ρ, θ] += 1

最终: accumulator 中局部最大值 → 对应图像空间的直线
```

**例**：一条水平直线 → θ=90°, ρ=y₀ → 对应参数空间一个点

**代码中 `hough_line(img, threshold=100)` 使用 cv2.HoughLines（经典版本）**

---

### 5.2 霍夫圆变换

**参数**：(x₀, y₀, r) = 圆心 + 半径（3维参数空间）

```
投票（经典方法）:
对每个边缘像素(x,y):
  for r = r_min to r_max:
    for θ = 0 to 2π:
      x₀ = x - r·cosθ
      y₀ = y - r·sinθ
      accumulator[x₀, y₀, r] += 1

问题: 3D累加器太大 → 计算很慢！

改进: Hough Circles Gradient (OpenCV使用)
1. 用Canny找到边缘像素和边缘方向
2. 每个边缘点 → 沿边缘方向（即径向）画一条线 → 在可能的圆心投票
3. 分两步: 先找到圆心（2D），再确定半径（1D）
   （利用"圆心在通过它的所有边缘点的法线上"这个性质）
```

**代码中 `hough_circle(img, param1=100, param2=30)` 使用 cv2.HoughCircles**

## 六、边缘连接与边界跟踪

**问题**：Canny 输出的边缘可能有断裂，不构成闭合轮廓。

**解决方案：形态学闭合 + 连通分量分析**

```
1. 二值边缘图 E
2. 闭运算: E_closed = (E ⊕ B) ⊖ B （连接邻近的边缘段）
3. 连通分量标记: 对 E_closed 做连通性分析，得到边缘段列表
4. 按长度/曲率过滤: 去除太短的段（噪声）
5. 输出: 连通的、较长的边缘段
```

## 八、方法对比：什么时候用什么？

| 方法 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **全局阈值** | 目标背景亮度差异大，直方图双峰 | 简单，快 | 对光照不均、噪声敏感 |
| **Otsu** | 同上（自动阈值） | 无需手动T，理论最优 | 多峰时可能分错 |
| **自适应阈值** | 光照不均、背景渐变 | 鲁棒性好 | 参数（窗口大小）需调 |
| **Sobel** | 边缘检测（粗边界） | 简单 | 边缘粗、有噪声 |
| **Canny** | 边缘检测（高精度） | 细、连续、低噪声 | 参数多（σ, low, high） |
| **区域生长** | 目标颜色/纹理一致 | 能得到闭合区域 | 需要种子点，对参数敏感 |
| **K-Means** | 无监督，多目标分割 | 无需种子，自动聚类 | K需指定，对噪声敏感 |
| **霍夫变换** | 检测直线/圆/规则形状 | 鲁棒、抗断裂 | 计算量大（3D+） |
| **分水岭** | 粘连物体分割 | 自然边界，闭合轮廓 | 易过度分割，需种子 |

## 九、初学者常见问题解答

### Q1: Otsu 是怎么"自动"找到阈值的？它真的总是最优吗？

**答**：Otsu 通过遍历所有可能的 T（0-255），计算每个 T 下的类间方差，选择最大的。

**关键推导**：
```
σ_B²(T) = ω_0(T)·ω_1(T)·(μ_0(T)-μ_1(T))²
          ↑     ↑     ↑
      暗类比例 亮类比例 两类均值差

这在数学上等价于最大化类间方差 → 最小化类内方差（因为总方差=常数）

Otsu = Fisher 线性判别分析（LDA）在一维上的特殊情况

何时最优? ✅ 当图像真的是"两个高斯分布的混合"（双峰直方图）
何时失败? ❌ 三峰/多峰、单峰、直方图平坦时，可能分在不理想的位置

改进: 2D Otsu（利用邻域均值）、多阈值 Otsu（分>2类）
```

### Q2: Canny 的两个阈值比例为什么是 1:3？有依据吗？

**答**：这是 Canny 在他 1986 年的经典论文中建议的经验值，基于大量实验。

```
经验法则（推荐默认）:
high = 图像梯度幅度的某个高百分位（通常70-80%百分位）
low = high / 3 或 high / 2

但实际调参建议:
1. 先固定 σ=1.0（小图像或精细图像用 σ=0.5）
2. 调整 high: 太高 → 边缘少但准；太低 → 边缘多但噪声多
3. 调整 low = high/2 ~ high/3
4. 如果边缘断 → 降低 low；如果边缘多噪声 → 提高 high
```

**根本原因**："滞后连接"是为了处理噪声导致的边缘断裂——需要一个较低阈值让边缘"延伸"过噪声，但又不能太低以免引入假边缘。

## 十、章节总结

```
本章知识结构
├── 阈值化分割
│   ├── 基础阈值: g = 1 if f ≥ T else 0
│   ├── Otsu自动阈值: 最大化σ_B²(T) = ω_0·ω_1·(μ_0-μ_1)²
│   │   ├─ 遍历T=0..255，找类间方差最大的T*
│   │   └─ 适用: 双峰直方图（前景背景灰度差明显）
│   └── 自适应阈值: T(x,y) = mean(局部邻域) - C
│       └─ 适用: 光照不均场景（文档扫描等）
├── 边缘检测
│   ├── 边缘定义 = 灰度突变 = 一阶导极大 = 二阶导零交叉
│   ├── Sobel: Sx = [[-1,0,1],[-2,0,2],[-1,0,1]]; Sy 类似
│   │              |∇f| = √(Sx²+Sy²)
│   ├── Prewitt: 与Sobel类似，权重为1而非2
│   ├── Laplacian: 二阶导，对噪声极敏感 → 先高斯平滑再Laplacian = LoG
│   └── Canny（工业标准，4步）:
│       ├─ 1. 高斯平滑 f ⊗ G_σ
│       ├─ 2. Sobel梯度 |∇f|, θ
│       ├─ 3. NMS非极大值抑制（边缘细化为1像素）
│       └─ 4. 双阈值+滞后连接（low=high/3 经验值）
├── 区域方法
│   ├── 区域生长: 从种子开始，|f-μ_region|<T则合并
│   ├── 分裂合并: 自上而下（分裂）+ 自下而上（合并），四叉树
│   ├── K-Means聚类: 像素=特征向量，聚类为K类
│   └── 分水岭: 图像=地形，山谷灌水→分水岭为边界
├── 霍夫变换
│   ├── 直线: ρ = x·cosθ + y·sinθ，参数空间投票
│   ├── 圆: (x₀,y₀,r)，3D空间 → 梯度改进版（分2步找圆心+半径）
│   └─ 思想: "每个边缘像素投票，得票多的参数=检测到的形状"
└── 实践选择
    ├── 简单+均匀光照: 全局阈值/Otsu
    ├── 光照不均: 自适应阈值
    ├── 只需要边缘: Canny（Sobel为备选）
    ├── 要闭合区域: 区域生长/K-Means/分水岭
    ├── 已知形状: 霍夫变换（直线/圆）
    └── 分割粘连物体: 距离变换 + 分水岭
```
