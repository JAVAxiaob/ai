## 一、图像的数学表示：从像素到矩阵

### 1.1 数字图像的正式定义

**定义**：一幅数字图像是一个二维函数 f(x, y)，其中 x, y 是空间坐标，f 是该位置的亮度/灰度值。

```
在计算机中存储为 M×N 矩阵：

     [ f(0,0)  f(0,1)  ...  f(0,N-1) ]
     [ f(1,0)  f(1,1)  ...  f(1,N-1) ]
f = [   ...     ...   ...     ...    ]
     [ f(M-1,0) f(M-1,1) ... f(M-1,N-1) ]
```

**灰度图像**：f(x, y) ∈ {0, 1, 2, ..., 255}（uint8，256个级别）

**彩色图像**：f(x, y) = [R(x,y), G(x,y), B(x,y)]，每个通道同上

### 1.2 图像坐标系：原点在哪里？

| 系统 | 原点位置 | y轴方向 | 典型软件 |
|------|----------|---------|---------|
| **数学/工程** | 左下角 | ↑ 向上 | Matlab, 数学论文 |
| **OpenCV/Python** | **左上角** | ↓ **向下** | OpenCV, Pillow, NumPy |
| **OpenGL/游戏** | 左下角 | ↑ 向上 | 图形API |

⚠️ **重要提醒**：本书代码使用 OpenCV 约定——**原点在左上角**，y 向下增加。

```
(0,0) → x → (0,N-1)
  |
  ↓ y
  |
(M-1, 0)      (M-1, N-1)
```

## 二、采样与降采样：深入理解 `downsample`

### 2.1 降采样的数学描述

**降采样（Downsampling）** = 每 factor 个像素取一个像素。

```
设原图为 f[x, y]，x=0..M-1, y=0..N-1
降采样因子为 k（即 factor）
降采样后图像: g[m, n] = f[m·k, n·k]
其中 m=0..⌊M/k⌋-1, n=0..⌊N/k⌋-1
```

**示例（k=2）**：
```
原图（8×8）→ 降采样（4×4）
[ 1  2  3  4  5  6  7  8]     [ 1  3  5  7]
[ 9 10 11 12 13 14 15 16]     [ 9 11 13 15]
[17 18 19 20 21 22 23 24]  →  [17 19 21 23]
[25 26 27 28 29 30 31 32]     [25 27 29 31]
...                            ...
```

### 2.2 为什么降采样后要再恢复原尺寸？

`downsample` 函数在降采样后立刻用最近邻插值恢复到原尺寸。为什么？

```
目的：演示目的——让你直接对比观察降采样的效果
     
实际工程中（如金字塔多尺度分析）：
Step 1: 高斯平滑 g = blur(f, σ)  ← 先平滑抗混叠！
Step 2: 降采样 g_down = downsample(g, 2)
Step 3: 在低分辨率上做处理（更快）
Step 4: （可选）上采样恢复
```

**关键工程细节（代码省略了此步）**：

> 正确的降采样必须先进行**抗混叠滤波**（低通），否则会产生严重的频谱混叠伪影！

```
❌ 直接降采样（代码中演示的方式）：
   g_direct[m,n] = f[2m, 2n]
   问题：高频内容会"折叠"到低频，产生假纹理

✅ 正确降采样（实际工程）：
   g_smooth = 高斯模糊(f, σ)    ← 先去除高频
   g_correct[m,n] = g_smooth[2m, 2n]
   通常：σ = k/√(12) 或使用 0.5*k 半径的高斯核
```

### 2.3 参数调优

| factor | 像素保留率 | 视觉效果 | 典型用途 |
|--------|-----------|----------|---------|
| 2 | 25% | 轻微马赛克 | 图像金字塔底层 |
| 4 | 6.25% | 明显方块感 | 快速预览 |
| 8 | 1.56% | 难以辨识细节 | 缩略图 |
| 16+ | <1% | 几乎只剩色块 | 极端压缩演示 |

## 三、像素邻域：什么是"邻居"？

### 3.1 三种邻域定义

考虑图像中的一个像素 p 位于坐标 (x, y)：

**4-邻域（N₄）**：上下左右四个邻居
```
         (x, y-1)
            ↑
(x-1, y) ← p → (x+1, y)
            ↓
         (x, y+1)
```
数学表示：N₄(p) = {(x±1, y), (x, y±1)}

**D-邻域（N_D）**：四个对角邻居
```
(x-1, y-1)      (x+1, y-1)
        \      /
          p
        /      \
(x-1, y+1)      (x+1, y+1)
```
数学表示：N_D(p) = {(x±1, y±1)}

**8-邻域（N₈）**：4-邻域 + D-邻域 = 8个邻居
```
N₈(p) = N₄(p) ∪ N_D(p)
```

### 3.2 边界像素的特殊处理

对于图像边缘的像素，它的邻域会部分"出界"。常见处理方式：

| 方式 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **零填充** | 出界位置当作0 | 简单 | 引入黑色伪影 |
| **边界复制** | 用边界像素值填充外 | 简单，无明显伪影 | 边界处过度处理 |
| **镜像反射** | 以边界为轴镜像 | 效果平滑 | 计算稍复杂 |
| **周期延拓** | 图像首尾相接 | 傅里叶分析中用 | 视觉上不自然 |

代码中 `mark_neighbors` 函数对越界位置**简单跳过**（不绘制）。

## 四、距离度量：从像素到几何

### 4.1 三种距离函数详解

考虑两点 p=(x₁, y₁) 和 q=(x₂, y₂)：

#### (1) 欧氏距离（Euclidean Distance）

```
D_e(p, q) = √[(x₁-x₂)² + (y₁-y₂)²]
```

**直觉**：两点间直线距离。

**性质**：
- ✅ 旋转不变性：坐标系旋转，距离不变
- ✅ 三角不等式：D_e(p, r) ≤ D_e(p, q) + D_e(q, r)
- ✅ 是一个"度量空间"（满足正定性、对称性、三角不等式）

**等距线**：以 p 为圆心的同心圆

#### (2) 街区距离（City-block / Manhattan Distance）

```
D₄(p, q) = |x₁-x₂| + |y₁-y₂|
```

**直觉**：像在曼哈顿街道上从一点走到另一点——只能沿街道，不能穿墙！

**等距线**：以 p 为中心的菱形/旋转45°的正方形

#### (3) 棋盘距离（Chessboard Distance）

```
D₈(p, q) = max(|x₁-x₂|, |y₁-y₂|)
```

**直觉**：王在棋盘上的最短移动步数——可以斜着走。

**等距线**：以 p 为中心的正方形（边平行于坐标轴）

### 4.2 统一视角：闵可夫斯基距离（Minkowski Distance）

上述三种距离都是闵可夫斯基距离的特例：

```
D(p, q) = ( |x₁-x₂|^p + |y₁-y₂|^p )^(1/p)
```

| 参数 p | 得到的距离 |
|--------|-----------|
| p=1 | 街区距离 D₄ |
| p=2 | 欧氏距离 D_e |
| p→∞ | 棋盘距离 D₈ |

**几何直观（等距线从圆到方的过渡）**：

```
p=1: ♦         p=2: ●         p→∞: ■
    菱形          圆形           正方形
```

### 4.3 距离变换（Distance Transform）

**定义**：对图像中每个像素，计算其到最近的前景（白色）像素的距离。

```
设二值图 B: B[x,y]=1 表示前景, B[x,y]=0 表示背景
距离变换 D: D[x,y] = min{ distance((x,y), (a,b)) | B[a,b]=1 }
```

**算法分类**：

| 算法 | 时间复杂度 | 精度 | 适用距离 |
|------|-----------|------|---------|
| **暴力搜索** | O(N²·M) | 精确 | 任意 |
| **两遍扫描** | O(N) | 近似 | D₄, D₈ |
| ** chamfer 距离** | O(N) | 近似D_e | 加权组合 |
| **Saito算法** | O(N·logN) | 精确 | D_e |

代码中使用 OpenCV 的 `distanceTransform`，内部实现是 chamfer 距离近似或精确算法。

**距离变换的应用（贯穿后续章节）**：

| 应用领域 | 具体用途 | 用到的章节 |
|---------|---------|-----------|
| **形状分析** | 骨架提取（距离变换的脊线） | 第9章（形态学） |
| **分水岭分割** | 用距离变换的局部极大值作为"种子" | 第10章（分割） |
| **目标匹配** | 形状上下文（Shape Context）描述符 | 第11、12章 |
| **细化/粗化** | 形态学操作的距离驱动版本 | 第9章 |

## 五、卷积：图像处理的"万能工具"

### 5.1 什么是卷积？——从加权平均说起

**通俗理解**：

想象你站在图像的一个像素上。你手里有一个"加权表"（卷积核），告诉你对邻居像素的信任程度：

```
我的加权表（3×3均值核）：
[1/9  1/9  1/9]
[1/9  1/9  1/9]   ← 每个邻居同等重要
[1/9  1/9  1/9]
```

新的像素值 = 我自己和邻居们按这个加权表算平均值。

**正式定义（二维离散卷积）**：

```
g[x, y] = (f * w)[x, y] = Σ Σ f[a, b] · w[x-a, y-b]
         a   b
```

其中 `f` 是输入图像，`w` 是卷积核（kernel / mask / filter）。

⚠️ **注意**：严格来说，卷积需要将核翻转180°后再加权求和。如果不翻转，称为**互相关（Cross-correlation）**。对于对称核（如高斯核、均值核），两者等价。代码中的 `ndimage.convolve` 执行真正的卷积，但由于核是对称的，效果与互相关相同。

### 5.2 卷积核设计：想要什么效果就设计什么核！

#### 例1：均值平滑（Box Filter）

```
        1 1 1
w = (1/9) 1 1 1    ← 所有邻居等权
        1 1 1
```

**效果**：每个像素被替换为3×3邻域的平均值 → 图像变模糊、噪声被平滑。

#### 例2：高斯平滑（Gaussian Filter）

```
σ=1.0 时的 5×5 近似核（归一化前）：
[ 1  4  6  4  1]
[ 4 16 24 16  4]   ← 中心权重高，远处权重小
[ 6 24 36 24  6]   ← 模拟"距离越近越重要"
[ 4 16 24 16  4]
[ 1  4  6  4  1]
```

**数学形式**：
```
w(x, y) = (1/2πσ²) · exp( -(x²+y²) / (2σ²) )
```

**与均值核对比**：

| 特性 | 均值核 | 高斯核 |
|------|--------|--------|
| 平滑均匀性 | 均匀加权，边缘模糊严重 | 中心加权，保留更多边缘 |
| 振铃现象 | 易产生（频域是 sinc） | 无（频域仍是高斯） |
| 视觉质量 | 尚可，但细节损失多 | 更自然，类似真实光学模糊 |

#### 例3：边缘检测（Sobel X方向）

```
    [-1  0  1]
w = [-2  0  2]   ← 左右差 = 检测垂直边缘
    [-1  0  1]
```

**直觉**：左右差异大 → 说明这里有垂直方向的边缘！

#### 例4：锐化（Sharpening）

```
    [ 0  -1   0]
w = [-1   5  -1]   ← "5×自己 - 1×邻居们" = 放大差异
    [ 0  -1   0]
```

**直觉**：如果我和邻居们一样，结果不变；如果我是个"与众不同"的边缘点，结果被放大。

### 5.3 卷积的边界处理

当卷积核中心位于图像边缘时，部分核会"超出"图像边界。常见处理策略：

| 策略 | OpenCV 代码 | 效果 | 适用场景 |
|------|------------|------|----------|
| 填充零 | `cv2.BORDER_CONSTANT` | 边缘出现黑色 | 图像中心区域重要 |
| 复制边界 | `cv2.BORDER_REPLICATE` | 边缘延伸 | 最常用默认 |
| **镜像反射** | `cv2.BORDER_REFLECT` | **最平滑** | **推荐选择** |
| 周期延拓 | `cv2.BORDER_WRAP` | 图像首尾相接 | 傅里叶分析 |

代码中 `ndimage.convolve(gray, kernel, mode='nearest')` 使用的是**复制边界**策略。

### 5.4 卷积的计算复杂度与加速

**朴素实现**：O(M·N·k²)，其中 M,N 是图像尺寸，k 是核的大小

对于 1024×1024 的图像 + 11×11 的核：
```
1024×1024×121 ≈ 1.27亿次乘法 + 1.27亿次加法 = 2.5亿次操作 ← Python 中这很慢！
```

**加速方法**：

1. **可分离核（Separable Kernel）**：
   - 高斯核可拆分为两个一维核的外积
   - 复杂度降为 O(M·N·k)，从 1.27亿 → 2300万（11倍加速！）

2. **FFT 卷积**：
   - 时域卷积 = 频域乘积
   - O(M·N·log(MN))，大核时尤其快
   - 第4章（频域滤波）的核心主题

3. **积分图（Integral Image）**：
   - 均值核的O(1)计算
   - Viola-Jones 人脸检测的核心技术

## 六、连通性与连通分量

### 6.1 连通性定义

像素之间的"连通"不仅需要相邻，还需要满足某种相似性条件。

**4-连通**：两个像素在4-邻域内且亮度/标签相似
**8-连通**：两个像素在8-邻域内且亮度/标签相似

**示例**：
```
考虑二值图像（1=前景，0=背景）：
[1 0 0]
[1 1 0]  ← 左上角的1群
[0 0 1]  ← 右下角的1

4-连通分析：有2个连通分量（左上和右下不相邻）
8-连通分析：有2个连通分量（同样，因为中间隔着0）

如果图像是：
[1 0 1]
[1 1 0]  ← 右上角的1和左上群的1是对角关系
[0 0 1]

4-连通：3个分量（右上1是孤立的）
8-连通：2个分量（右上1通过对角与左群相连）
```

**关键原则**：

> 对前景用8-连通，对背景用4-连通（或反之），避免拓扑悖论——这是数字拓扑学的经典结论。

### 6.2 连通分量标记算法：Two-Pass Algorithm

这是一种优雅的两遍扫描算法，用于给每个独立"物体"分配唯一ID（颜色）。

```
输入：二值图像 B（0=背景，1=前景）
输出：标签图像 L（每个连通分量有唯一标签）

【第一遍：从左上到右下扫描】
对每个前景像素 B[x,y]=1：
   检查邻居（左上、上、左、右上 ← 4连通；加上对角→8连通）
   情况1：邻居中只有1种标签 → 继承该标签
   情况2：邻居中有多种标签 → 选最小标签，并记录"这些标签等价"
   情况3：邻居中没有前景 → 分配新标签

【第二遍：合并等价标签】
使用并查集（Union-Find）数据结构合并等价标签
每个像素替换为其等价类的代表元

【后处理：颜色映射】
每个唯一标签分配一个独特的颜色用于可视化
```

**时间复杂度**：O(N) —— 只需扫描图像两遍，极快！

**应用示例**：
1. 细胞计数（医学图像）：每个细胞是一个连通分量
2. 车牌定位：提取最大/最矩形的连通分量作为车牌候选
3. 文本行检测：字符是连通分量，按位置连成行
4. 去除小噪声：过滤掉面积小于阈值的连通分量

## 七、视觉错觉：赫尔曼网格与侧抑制

### 7.1 现象描述

**赫尔曼网格（Hermann Grid Illusion）**：

当你注视白色方格组成的网格时，会在白色交叉点感知到"不存在的灰色斑点"——但定睛细看时斑点又消失了。

### 7.2 神经机制：侧抑制（Lateral Inhibition）

```
视网膜神经节细胞的感受野：
    [ -  -  - ]
    [ -  +  - ]   ← "中间兴奋，周围抑制"
    [ -  -  - ]
```

当感受野中心对准网格交叉点时：
- 中心接收到的白色刺激不变
- 周围接收的白色刺激更多（4条街道都有白色）→ 抑制更强
- 净效应：交叉点的"感知亮度"降低 → 看到灰色斑点

当定睛细看时：
- 中央凹的感受野更小
- 整个感受野都落在交叉点内部 → 没有抑制差异 → 斑点消失

### 7.3 与图像处理的联系

1. **高通滤波**：侧抑制本质是"中心-周围"的差，等价于一个高通滤波核
2. **对比度增强**：感知到的是相对亮度差异，而非绝对亮度
3. **视觉系统的灵感**：Retinex 图像增强算法正是模拟这一机制

## 八、概率与统计：从直方图说起

### 8.1 图像直方图

**定义**：直方图统计每个灰度值在图像中出现的次数。

```
h[r] = number of pixels with gray value r,  for r = 0, 1, ..., 255
```

**归一化直方图**（概率质量函数 PMF）：
```
p(r) = h[r] / N,  其中 N 是总像素数
Σ p(r) = 1  （所有概率之和为1）
```

### 8.2 用噪声改变直方图：高斯噪声的影响

**原始图像直方图**：可能有多个峰（物体、背景、天空等）

**加噪后直方图**：
1. 峰展宽（每个灰度值向两侧扩散）
2. 谷被填充（不同物体之间的区分度下降）
3. 形状趋近高斯（中心极限定理）

**数学描述**：如果原图的分布是 p(f)，噪声分布是 p_η(η) ~ N(0, σ²)，则加噪后：
```
p(g) = p(f) * p_η   （卷积！）
```

这就是为什么加噪声后直方图会"模糊"——它相当于对直方图做了一个高斯平滑。

### 8.3 信噪比（SNR / PSNR）

**峰值信噪比（PSNR）**是衡量图像质量的标准客观指标：

```
MSE = (1/MN) · Σ Σ (f[x,y] - g[x,y])²  （均方误差）
PSNR = 10 · log₁₀( MAX² / MSE )  dB
     = 20 · log₁₀( MAX / √MSE )  dB
```

其中 MAX 是像素最大值（uint8图像为255）。

**PSNR 与主观质量关系**：

| PSNR | 主观评价 | 典型情境 |
|------|---------|---------|
| 50+ dB | 无损（不可察觉） | 无损压缩，高精度处理 |
| 40-50 dB | 优秀（极难察觉差异） | 高质量 JPEG，专业去噪 |
| 30-40 dB | 良好（可察觉差异但可接受） | 一般压缩，标准去噪 |
| 20-30 dB | 一般（质量下降明显） | 高压缩比，低光图像 |
| < 20 dB | 差（严重失真不可用） | 极端噪声，严重损坏 |

对于高斯噪声：当 σ=15 时，MSE≈225，PSNR≈24.6dB（"一般"水平）

## 九、多波段成像：为什么不同传感器拍出来不一样？

### 9.1 电磁波谱与成像

```
波长从短到长：
γ射线 → X射线 → 紫外线 → 可见光 → 红外 → 微波 → 无线电波
           ↑                        ↑
         医学影像               遥感/夜视
         (高能量)               (热成像)
```

| 波段 | 典型图像 | 特点 | 处理方法差异 |
|------|---------|------|------------|
| **可见光** | 普通照片 | RGB三通道，纹理丰富 | 标准图像处理 |
| **红外** | 热成像 | 单通道，边缘模糊，亮=高温 | 先高斯模糊降噪，再增强 |
| **雷达/射线** | SAR/X光 | 边缘突出，斑点噪声 | Sobel梯度提取边缘特征 |

### 9.2 模拟不同波段：`spectrum_band_simulation` 解析

函数通过不同的滤波策略"伪造"不同传感器的成像特点：

**可见光 (visible)**：不做处理，直接输出原图

**红外 (infrared)**：
```
out = blur(f, 9×9) * 1.2  ← 模糊 + 亮度增强
```
- 9×9大核模拟红外传感器较低的空间分辨率
- ×1.2 模拟热物体在红外图像中更亮

**雷达/射线 (radar)**：
```
gx = Sobel_x(f),  gy = Sobel_y(f)
out = √(gx² + gy²)
```
- 模拟雷达/射线图像中"边缘突出，纹理缺失"的特点
- Sobel算子提取的梯度幅值强调物体轮廓（详见第3章）

## 十、本章函数完整参考

### 1. `downsample(img, factor=4)`

**功能**：将图像降采样后恢复原尺寸，演示低分辨率效果。

**算法流程**：
```
Step 1: 降采样（步进为 factor）
   small[x, y] = img[x*factor, y*factor]  （直接采样，无抗混叠）

Step 2: 最近邻插值恢复原尺寸
   result = resize(small, original_size, INTER_NEAREST)
   效果：产生方块状的马赛克
```

**参数调优**：
| factor | 信息保留率 | 推荐用途 |
|--------|----------|---------|

| 3 | 8 | 5 bits | 18.8 dB |
| 2 | 4 | 6 bits | 12.8 dB |
| 1 | 2 | 7 bits | 5.7 dB |

## 十一、初学者常见问题解答

### Q1: 卷积和"邻域求平均"是一回事吗？

**答**："邻域求平均"是卷积的一个特例，但不等同于卷积！

| 概念 | 关系 |
|------|------|
| 邻域操作 | 最广义：任何需要查看邻居像素的操作（包括排序、统计等） |
| 加权求和（线性滤波） | 邻域操作的子集：结果是邻居的加权求和 |
| 卷积 | 加权求和的特例（核需对称或翻转） |

所以：中值滤波是邻域操作但**不是**卷积（因为它用排序而非加权求和）。

### Q2: 为什么距离变换中 "越亮的地方离前景越远"？

**答**：距离变换 `D[x,y]` 计算的是该像素到最近前景像素的距离。

- 前景像素自身距离 = 0 → 黑色
- 靠近前景的背景像素距离小 → 深灰
- 远离前景的背景像素距离大 → 白色

如果你想要"到背景的距离"，只需先反色图像再做距离变换。

### Q3: 连通分量分析需要输入二值图，但我的图是灰度图，怎么处理？

**答**：这是**图像分割**的核心问题——怎样从灰度图得到有意义的二值图？方法包括：

1. **固定阈值**（最简单）：像素>127视为前景
2. **Otsu阈值**（最常用）：自动选择最优阈值（详见第3、10章）
3. **自适应阈值**：每个区域用不同阈值（详见第3章）
4. **边缘检测+填充**：先找边缘再闭合区域
5. **深度学习**：FCN, U-Net 等端到端分割

通常的流水线是：
```
输入图 → 预处理（去噪/增强） → 阈值化 → 形态学操作（开闭运算） → 连通分量分析
```

### Q4: 我自己实现卷积为什么比 OpenCV 慢 100 倍？

**答**：主要三个原因：

1. **语言层面**：OpenCV 用 C++ 实现，NumPy 也有C级循环优化。纯 Python for 循环极慢。
2. **算法层面**：OpenCV 会根据核大小自动选择最快方法（小核用滑动窗口，大核用 FFT）。
3. **内存层面**：OpenCV 使用 SIMD 指令集一次处理多个像素。

**正确做法**：永远不要在 Python 中用 for 循环实现图像处理操作。使用 NumPy 向量化操作或直接调用 OpenCV 函数。

```python
# ❌ 慢：双重 for 循环
for i in range(h):
    for j in range(w):
        result[i,j] = ...

# ✅ 快：向量化
result = cv2.filter2D(img, -1, kernel)  # 交给C++优化
```
