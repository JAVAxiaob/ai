## 一、频域视角：从空间到频率

### 1.1 傅里叶分析的核心思想

> **任何复杂的信号都可以分解为一系列简单正弦/余弦波的叠加。**

**一维示例（时间信号）**：

想象一个声音信号——它可以被分解为不同频率的正弦波：
```
复杂信号 = A₁·sin(2π·f₁·t + φ₁) + A₂·sin(2π·f₂·t + φ₂) + ...
              ↑低频（低音）              ↑高频（高音）
```

**二维扩展（图像）**：

图像可以被分解为不同"频率"的二维正弦/余弦模式：
```
复杂图像 = Σ Σ A(u,v) · sin/cos(2π·(u·x + v·y)/N)
              ↑ 频率对 (u,v)，表示在 x 方向振荡 u 次，y 方向振荡 v 次
```

**直观理解**：

| 频率 | 在图像中意味着什么 | 视觉特征 |
|------|------------------|---------|
| **低频** (u,v 小) | 图像中缓慢变化的部分 | 大片天空、背景、整体亮度 |
| **中频** (u,v 中) | 中等尺寸的物体和纹理 | 人脸轮廓、建筑结构 |
| **高频** (u,v 大) | 快速变化的部分 | 边缘、细节、纹理、**噪声**！|

```
图像示例  ──────────────>  频谱（幅度）

┌──────────┐     ┌───中心亮──────┐
│██████    │ →   │    ● (u=0,v=0) │  ← DC分量，整体亮度
│  ████    │ →   │      ●         │  ← 水平条纹频率
│    ██    │ →   │  ●             │  ← 其他频率
└──────────┘     └────────────────┘
```

---

### 1.2 二维离散傅里叶变换（2D DFT）

**正向变换（图像 → 频域）**：

```
F(u, v) = Σ(x=0..M-1) Σ(y=0..N-1) f(x,y) · exp(-j2π(ux/M + vy/N))

其中 j = √(-1) 是虚数单位
```

**反向变换（频域 → 图像）**：

```
f(x, y) = (1/MN) · Σ(u=0..M-1) Σ(v=0..N-1) F(u,v) · exp(+j2π(ux/M + vy/N))
```

**F(u,v) 是复数**，可以表示为：
- **幅度谱（Magnitude Spectrum）**：|F(u,v)| = √(Re² + Im²)
- **相位谱（Phase Spectrum）**：φ(u,v) = arctan2(Im, Re)
- **功率谱（Power Spectrum）**：P(u,v) = |F(u,v)|²

**幅度 vs 相位的相对重要性**：

这是一个深刻的实验观察——**相位谱包含的信息比幅度谱多得多**！

| 保留部分 | 丢失部分 | 从频谱重建的图像 |
|---------|---------|----------------|
| 原幅度 + 随机相位 | 相位 | ❌ 完全无法辨识（白噪声） |
| 随机幅度 + 原相位 | 幅度 | ✅ 轮廓依稀可辨！ |

**直觉**：相位告诉你"在哪里发生变化"，幅度只告诉你"变化有多强"。位置信息比强度信息更重要。

---

### 1.3 快速傅里叶变换（FFT）

**问题**：直接计算 DFT 需要 O(N²) 次操作。

对于 1024×1024 的图像：~10⁶ 像素 × 10⁶ 次求和 = **10¹² 次操作**（不可能！）

**FFT 算法**（Cooley-Tukey，1965）：利用对称性和周期性，将复杂度降为 **O(N·logN)**。

对于 1024×1024 的图像：
- 逐行 FFT: O(M·N·logN)
- 逐列 FFT: O(M·N·logM)
- 总计约 10⁶ × 10 ≈ **10⁷ 次操作**（毫秒级完成！）

---

### 1.4 fftshift：将低频移到中心

**原始 DFT 输出的布局问题**：

```
NumPy/OpenCV 的 DFT 输出（未中心化）：
┌─────────┐
│(0,0)    │  ← DC分量(0频率) 在角落！
│         │
│    ●    │  ← 高频（边界）
│         │
└─────────┘

应用 fftshift 后（中心化）：
┌─────────┐
│    ●    │  ← DC移到中心
│         │
│         │  ← 低频在中心区域，高频在边界
│         │
└─────────┘
```

**为什么要中心化？**
1. 可视化方便：中心=低频，边界=高频（直觉）
2. 设计滤波器方便：圆形掩模中心亮=保留低频
3. 便于分析对称性

**代码中的 `_dft_shift` 函数**：
```python
# 等价于：
F = np.fft.fft2(f)        # 正向变换 → 频率平面
Fshift = np.fft.fftshift(F)  # 中心化
```

### 1.5 频谱的对数显示

**问题**：DC 分量（0频率）的值通常比其他频率大 100-1000 倍。直接显示只能看到一个亮点，其他全黑。

**解决方案——对数压缩**（代码中 `dft_spectrum` 函数）：
```
显示 = 20 · log₁₀(1 + |F|)

原 |F| 的范围：0 ~ 10^6    → log后范围：0 ~ 120

这就是第3章学习的"对数变换"的实际应用！
```

**你在频谱图中看到什么？**
- 中心亮点：DC（零频率）→ 图像整体平均亮度
- 中心附近的亮区：低频 → 图像整体结构、大物体
- 远离中心的微弱亮区：高频 → 边缘、细节、纹理、噪声
- 亮线/十字：周期性噪声（如扫描线干扰，见第5章）

## 二、频域滤波的基本原理

### 2.1 卷积定理——频域方法的基石

> **时域（空间域）的卷积 等价于 频域的逐点乘法！**

```
如果 g(x,y) = (f * w)(x,y)   （空间域卷积）
则 G(u,v) = F(u,v) · W(u,v)  （频域逐点相乘）

其中:
  g = 滤波后图像, f = 输入图像, w = 卷积核
  G = FFT(g), F = FFT(f), W = FFT(w)
```

**为什么这很重要？**

1. **大核加速**：空间域卷积 O(N·K²) vs 频域 O(N·logN)，当核大时（K>15），频域更快
2. **设计直观**：在频域"切掉"某些频率 = 设计目标效果
3. **数学优雅**：很多空间域的"神秘"效果在频域有清晰解释

---

### 2.2 频域滤波流程

```
┌──────────────┐
│ 输入图像 f   │
└──────┬───────┘
       │
       ▼
┌──────────────┐    ┌─────────────────┐
│ FFT          │ →  │ F(u,v) 频谱     │
└──────┬───────┘    └────────┬────────┘
       │                     │
       ▼                     ▼
┌──────────────┐    ┌─────────────────┐
│ fftshift 中心化 │    │ H(u,v) 滤波器掩模 │
└──────┬───────┘    └────────┬────────┘
       │                     │
       ▼                     ▼
┌──────────────────────────────────────┐
│ 逐点相乘：G(u,v) = F(u,v) × H(u,v)  │  ← 核心一步！
└───────────────────┬──────────────────┘
                     │
                     ▼
┌──────────────┐
│ ifftshift 反中心化 │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ IFFT（逆FFT）│ → 恢复空间域图像
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 取实部+clamp │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 输出图像 g   │
└──────────────┘
```

**代码中的 `_apply_freq_filter` 函数**实现了上述流程。

### 2.3 滤波器的种类和设计

按"保留/消除"的频率范围分类：

| 滤波器类型 | 保留 | 消除 | 效果 | 空间域等价物 |
|-----------|------|------|------|------------|
| **低通 (Low-pass)** | 低频（中心） | 高频（边界） | 模糊、去噪 | 高斯/均值滤波 |
| **高通 (High-pass)** | 高频（边界） | 低频（中心） | 边缘检测、锐化 | Sobel/拉普拉斯 |
| **带通 (Band-pass)** | 特定频率带 | 过高和过低 | 纹理提取 | 特定核 |
| **带阻 (Band-reject)** | 除特定带外 | 特定频率带 | 去除周期噪声 | Notch滤波 |
| **同态 (Homomorphic)** | 高频（乘 γ_H）低频（乘 γ_L） | — | 光照不均匀校正 | 无直接等价 |

## 三、低通滤波器：让图像变模糊

### 3.1 理想低通滤波器（Ideal Low-pass Filter, ILPF）

**定义**：
```
H(u, v) = 1, 如果 D(u,v) ≤ D₀  （D=到中心的距离）
         = 0, 否则
```

其中 D₀ 是"截止频率"（cutoff frequency）。

**直观图像**：
```
H(u,v) = 1 ────────┐
                   │
                   │
                   └──────── H=0
                   ↑
                   D₀

在二维平面上：一个完美的圆形"洞"——洞内全部保留，洞外全部消除。
```

**参数 D₀ 的效果**：

| D₀（相对于图像尺寸%） | 视觉效果 | 保留的信息量 |
|---------------------|---------|------------|
| 2% | 严重模糊，只剩大体轮廓 | ~10% |
| 5% | 明显模糊，细节丢失 | ~50% |
| 10% | 轻微模糊，大致可辨识 | ~85% |
| 20% | 几乎看不出变化 | ~95% |

**严重问题：振铃现象（Ringing）**

> 理想低通的空间域等价核是 sinc 函数——它有正负交替的旁瓣！

```
理想低通的空间域核（逆FFT后）：
        ●
     ●  ●  ●
  ●  ●  ●  ●  ●     ← 类似墨西哥帽，但有正负交替
●○○○○○●○○○○○●
  ●  ●  ●  ●  ●     ← 负旁瓣 → 产生"振铃"伪影
     ●  ●  ●
        ●

效果：边缘两侧出现亮-暗-亮的"振铃"条纹，类似回声。
```

**理想低通 → 永不用于真正的图像处理**，只用于教学演示。

---

### 3.2 巴特沃斯低通滤波器（Butterworth Low-pass Filter, BLPF）

**定义**：
```
H(u, v) = 1 / (1 + (D/D₀)^(2n))

其中 n = 阶数（order），控制"陡峭程度"
```

**阶数 n 的影响**：

| n | 形状 | 振铃程度 | 过渡区 |
|---|-----|---------|-------|
| 1 | 平滑高斯形 | 无 | 宽 |
| 2 | 中等陡峭 | 轻微 | 中 |
| 5 | 接近矩形 | 明显 | 窄 |
| ∞ | 理想低通 | 严重 | 极窄 |

**与理想低通对比**：

- ✅ 无尖锐截止 → 无明显振铃
- ✅ 过渡平滑 → 更自然的模糊
- ⚠️ n 太小 → 过度保留高频 → 模糊不够
- **实践中 n=2 是良好折中**

---

### 3.3 高斯低通滤波器（Gaussian Low-pass Filter, GLPF）

**定义**：
```
H(u, v) = exp(-D² / (2D₀²))
```

**关键特性**（数学上可证明）：

1. **高斯函数的傅里叶变换仍是高斯函数**——这是唯一的！
2. **无振铃**——空间域核全为正值，无正负交替
3. **可分离**——计算可加速
4. **与空间域高斯滤波完全等价**（当 σ = D₀ 的适当缩放时）

**参数关系（空间域 σ 与频域 D₀）**：
```
对于 M×N 图像：
频域 D₀ → 对应空间域 σ = M/(2π·D₀)

例：M=512, D₀=50 → σ ≈ 512/(314) ≈ 1.6 像素
```

**三种低通的视觉对比**：

```
频率响应曲线（H vs D）：

H=1 ┤
    │  ▆▆▆ 理想(n=∞)  ─── 突然截止
    │  ▂▃▅ 巴特沃斯(n=2) ~ 中等陡峭
    │ ▃▃▃▃ 高斯(n=1)     ── 平滑下降
H=0 └────────────────────────
       ↑ D₀

视觉效果：
理想低通    → 严重振铃，边缘有光环 ✗
巴特沃斯n=2 → 轻微振铃，可接受 ⚠️
高斯        → 无振铃，自然模糊 ✅ （推荐）
```

## 四、高通滤波器：检测边缘和细节

### 4.1 构造方法：高通 = 1 - 低通

```
H_highpass(u, v) = 1 - H_lowpass(u, v)
```

**三种高通滤波器**：

| 名称 | 公式 | 特点 |
|------|------|------|
| 理想高通 | H = 0 if D≤D₀ else 1 | 振铃严重 |
| 巴特沃斯高通 | H = 1/(1+(D₀/D)^(2n)) | 较平滑 |
| 高斯高通 | H = 1 - exp(-D²/2D₀²) | 无振铃，推荐 |

**注意**：H(0,0) = 0 → 直流分量被消除 → 输出图像平均亮度为0 → 必须加上偏移（如128）才能正确显示！

---

### 4.2 高频强调（High-Frequency Emphasis）

> 纯高通会丢失整体亮度信息，实际中常常保留一点点直流。

```
H_HFE(u, v) = a + b · H_highpass(u, v)

通常 a=0.5, b=1.5（代码思路）
```

直觉：图像 = 整体亮度（a） + 1.5倍的细节（b·H_hp·F）——细节被增强但不丢失整体样貌。

---

### 4.3 Unsharp Masking 的频域视角

```
空间域：g = f + amount · (f - blur(f))
频域： G = F + amount · (F - H_lp·F) = F · [1 + amount·(1-H_lp)]
        = F · [H_lp + amount·(1-H_lp)] = F · H_um

其中 H_um = 1 + amount·H_hp  ← 高频强调滤波器！
```

结论：Unsharp Masking 等价于一个高频强调滤波器——两种视角殊途同归。

## 五、带通/带阻滤波器

### 5.1 带阻滤波器（Band-reject / Band-stop）

**目的**：消除特定频率带（例如周期性扫描线噪声）。

**高斯带阻**：
```
H(u,v) = 1 - exp(-(D²-D₀²)² / (2D²·W²))

其中:
  D₀ = 要消除的中心频率
  W = 带阻的宽度
```

**形状**：一个"环形沟"——只有环形区域内的频率被抑制。

### 5.2 带通滤波器（Band-pass）

```
H_bandpass = 1 - H_bandreject
```

只保留特定频率带，用于纹理分析、特定模式提取。

## 六、同态滤波（Homomorphic Filtering）——光照校正神器

### 6.1 问题背景：图像的照度-反射模型

**Fourier 的老师——Lambert 定律**：

图像的亮度 = 入射光照（illumination）× 表面反射率（reflectance）
```
f(x,y) = i(x,y) · r(x,y)
         ↑照度（慢变，低频）  ↑反射率（快变，高频，含物体边界）
```

**问题场景**：
- 不均匀光照（如台灯照射的纸张，一半亮一半暗）
- 背光照片（人物暗背景亮）
- 阴影中的图像

这些场景中，照度 i(x,y) 变化缓慢（低频），而我们关心的物体信息在反射率 r(x,y) 中（高频）。

---

### 6.2 同态滤波的核心思路

**问题**：f = i · r 是**乘法**关系，但傅里叶只对**加法**线性。

**解决方案——对数将乘法变加法**：

```
Step 1: 取对数（乘法变加法）
   ln(f) = ln(i·r) = ln(i) + ln(r)
              ↓         ↓
            低频部分    高频部分

Step 2: 做傅里叶变换
   F(ln(f)) = F(ln(i)) + F(ln(r))

Step 3: 应用同态滤波器 H(u,v)
   H(u,v) 对低频小增益（γ_L < 1），对高频大增益（γ_H > 1）
   → 压缩照度变化 + 增强反射率对比

Step 4: 逆FFT → 回到空间域
Step 5: 取指数 → 恢复图像（取消对数）
   g = exp( H · F(ln(f)) 的逆变换 )
```

**滤波器形状**（代码中实现）：
```
H(u,v) = (γ_H - γ_L) · (1 - exp(-c·D²/D₀²)) + γ_L

其中:
  γ_L = 低频增益（代码默认 0.5 < 1 → 压缩照度）
  γ_H = 高频增益（代码默认 2.0 > 1 → 增强细节）
  c   = 控制过渡陡峭程度（代码默认 1.0）
  D₀ = 截止频率（代码默认 30）

图形:
H │
  │    ●●●●●●●●● γ_H=2.0 ← 高频大增益
  │   /
  │  / ← 过渡区（高频增强从这里开始）
  │ /
  │● γ_L=0.5 ← 低频小增益
  └─────────────── D
         ↑D₀
```

**直观效果**：
- 图像整体亮度的不均匀被"拉平"（低频被压缩）
- 同时局部细节和边缘被增强（高频被放大）
- 类似"逆光补偿"或"自动亮度"

**同态滤波 vs 直方图均衡化**：

| 方面 | 直方图均衡化 | 同态滤波 |
|------|------------|---------|
| 原理 | 改变灰度分布 | 分离照度-反射并分别处理 |
| 光照不均 | ❌ 效果差（会放大暗区噪声） | ✅ 针对性强 |
| 非线性 | 强烈（CDF变换） | 温和可控（γ参数） |
| 参数 | 无 | γ_L, γ_H, c, D₀ |
| 适用 | 一般对比度不足 | **光照不均、背光图像** |

## 七、本章函数完整参考

### 1. `dft_spectrum(img)`

**功能**：计算并可视化频谱幅度（对数压缩）。

**流程**：
```
DFT → fftshift → |F| → 20·log₁₀(1+|F|) → 归一化到0-255
```

**典型输出解读**：
- 中心点 = DC（0频率，整体亮度）
- 离中心越远 = 频率越高（边缘/噪声）
- 有方向性的亮线 = 图像中有对应方向的条纹
- 均匀散布亮点 = 随机噪声（如高斯噪声）

---

### 2. `ideal_lowpass(img, D0=30)`

**功能**：理想低通滤波（教学演示，振铃明显）。

**参数 D0**：截止频率（以像素为单位，图像中心到边缘的像素数）。

**注意**：实际工程中**不要用**，仅用于理解频域概念。

---

### 3. `ideal_highpass(img, D0=30)`

**功能**：理想高通。

**注意**：输出会出现负值，需要归一化或加偏移显示。

---

### 4. `butterworth_lowpass(img, D0=30, order=2)`

**功能**：巴特沃斯低通。

**参数 order**：阶数，控制"截止的陡峭程度"。n=1最平滑，n→∞退化为理想低通。n=2是常用折中。

---

### 5. `butterworth_highpass(img, D0=30, order=2)`

**功能**：巴特沃斯高通。

---

### 6. `gaussian_lowpass(img, D0=30)`

**功能**：高斯低通——平滑、去噪、无振铃的最佳选择。

**等价性**：在频域用高斯低通 = 在空间域用高斯模糊（参数有对应关系）。

---

### 7. `gaussian_highpass(img, D0=30)`

**功能**：高斯高通——边缘检测/增强。

---

### 8. `bandpass_filter(img, D0=40)`

**功能**：带通滤波——只保留以 D0 为中心的环形频率带。

**用途**：提取特定尺寸的纹理/结构（例如D0=40对应中等尺寸的物体）。

---

### 9. `bandreject_filter(img, D0=40)`

**功能**：带阻滤波——消除特定频率带。

**典型用途**：去除周期性噪声（如扫描线、打印网点）。

---

### 10. `fft_filter_pipeline(img, filter_type='gaussian_low', D0=30)`

**功能**：完整演示FFT滤波流水线——参数化选择滤波器类型。

**可选类型**：`'ideal_low'`, `'ideal_high'`, `'gaussian_low'`, `'gaussian_high'`, `'butterworth_low'`, `'butterworth_high'`

---

### 11. `homomorphic_filter(img, gamma_L=0.5, gamma_H=2.0, c=1.0, D0=30)`

**功能**：同态滤波——光照校正神器。

**参数调优指南**：

| 参数 | 推荐范围 | 效果 |
|------|---------|------|
| γ_L | 0.0 - 1.0 | 越小 → 越压缩照度差异（图像整体变平） |
| γ_H | 1.0 - 3.0 | 越大 → 越增强高频细节和边缘 |
| c | 0.5 - 2.0 | 控制低-高过渡的陡峭程度 |
| D0 | 20 - 100 | 越小 → "低频"的定义越严格，增强越激进 |

**典型问题的参数**：
- 严重背光：γ_L=0.3, γ_H=2.5, D0=20
- 轻度光照不均：γ_L=0.7, γ_H=1.5, D0=50
- 老照片：γ_L=0.5, γ_H=2.0, c=1.5（默认）

## 八、初学者常见问题解答

### Q1: 频域滤波 vs 空间域滤波——我应该用哪个？

**答**：取决于问题性质和滤波器大小。

| 场景 | 推荐 | 理由 |
|------|------|------|
| 小核（<15×15），模糊/锐化 | **空间域**（直接用 OpenCV blur/Sobel） | 实现简单，无 FFT 开销 |
| 大核（>31×31）或复杂频率需求 | **频域**（FFT加速） | FFT卷积更快，且频率操作直观 |
| 周期性噪声（扫描线/网格） | **频域** | 在频谱中是亮线，画个圈就能消除！ |
| 光照不均校正 | **同态滤波（频域）** | 照度-反射分离在频域最自然 |
| 一般边缘检测 | **空间域 Sobel/Canny** | 足够快，参数少 |
| 教学/理解频率概念 | **频域** | 可视化直观 |

**经验法则**：如果你的滤波器能用 5×5 或更小的核实现，直接用空间域；否则考虑频域。

### Q2: 为什么频谱图总是中心亮、四周暗？这不意味着"大部分能量在低频"吗？

**答**：完全正确！这是**自然图像的统计特性**——大部分能量（约85-95%）集中在低频。

原因：
1. 自然图像在空间上是"平滑"的——相邻像素高度相关（这是图像压缩的基础，见第8章）
2. 边缘和细节只占图像面积的一小部分
3. 所以在频域中，大部分"权重"在中心

**压缩的直觉**：JPEG 之所以能压缩 10-20 倍而视觉无损，正是因为它可以丢弃大部分高频系数——反正它们本来就很小！

### Q3: "振铃"听起来很抽象，能给我一个日常生活的类比吗？

**答**：想象你在一个空房间里大喊——声音会"回响"：

```
理想低通 = 用"方形"频率响应的滤波器
空间域 = sinc函数（像一个铃，有正负振荡的旁瓣）

类比：
你大喊  →  直接声音 + 回声 + 回声的回声...
         = 原信号 * sinc（理想滤波器的空间域响应）
         ↓
         边缘处出现"回声条纹" → 这就是振铃！

高斯低通 = "软"截止，没有旁瓣 → 类似在消音室说话，干净无回声。
```

### Q4: 同态滤波看起来很厉害，为什么我不总是用它？

**答**：同态滤波是一个**特定工具**，不是万能的。

它的适用/不适用场景：

✅ **应该用同态滤波的情况**：
- 光照明显不均匀（一边亮一边暗）
- 背光照片（主体暗背景亮）
- 有阴影的文档扫描
- 高动态范围场景（暗部有细节需要保留）

❌ **不应该用同态滤波的情况**：
- 普通对比度不足（用 CLAHE 更快更简单）
- 已经光照均匀的图像（同态会引入不必要的非线性失真）
- 高噪声图像（同态的对数操作会放大暗部噪声）

## 十、章节总结与知识图谱

```
本章知识结构
├── 傅里叶分析基础
│   ├── 核心思想：任何信号 = 正弦波叠加
│   ├── 2D DFT 公式
│   ├── FFT 加速：O(N²) → O(N·logN)
│   ├── 幅度谱 |F| 和 相位谱 φ（相位更重要！）
│   ├── fftshift：将DC从角落移到中心（便于可视化和滤波）
│   └── 对数压缩：20·log₁₀(1+|F|)（解决DC过大问题）
├── 频域滤波原理（卷积定理）
│   ├── 空间域卷积 = 频域乘法！
│   ├── 完整流水线：FFT → fftshift → ×H(u,v) → ifftshift → IFFT
│   ├── 滤波器设计：H(u,v) 掩模
│   └── 大核时FFT比直接卷积快
├── 低通滤波器（模糊/去噪）
│   ├── 理想低通：H=1 if D≤D₀ else 0 → ❌ 严重振铃，仅教学
│   ├── 巴特沃斯：H = 1/(1+(D/D₀)^(2n)) → ⚠️ 轻微振铃，n=2常用
│   ├── 高斯：H = exp(-D²/2D₀²) → ✅ 无振铃，推荐！
│   ├── 参数：D₀ = 截止频率（越小→越模糊）
│   └── 振铃现象：源于理想截止的"锐变" → 高斯无此问题
├── 高通滤波器（边缘/锐化）
│   ├── 构造：H_hp = 1 - H_lp
│   ├── 注意：H(0,0)=0 → 平均亮度丢失 → 需+128显示
│   ├── 高频强调：H = a + b·H_hp（保留部分直流）
│   └── Unsharp Masking 的频域视角 = 高频强调
├── 带通/带阻
│   ├── 带通：只保留环形区域 → 纹理/特定尺寸提取
│   └── 带阻：消除环形区域 → 去除周期性噪声
├── 同态滤波
│   ├── 模型：f = i(x,y) · r(x,y) （照度 × 反射率）
│   ├── 流程：ln → FFT → ×H(u,v) → IFFT → exp
│   ├── 滤波器：H = (γ_H-γ_L)·(1-exp(-c·D²/D₀²)) + γ_L
│   ├── 直觉：低频小增益(γ_L<1)压缩照度，高频大增益(γ_H>1)增强细节
│   └── 适用：光照不均、背光、HDR场景
└── 实践要点
    ├── 核大小 < 15：优先空间域
    ├── 核大小 > 31：优先频域FFT
    ├── 周期性噪声：频域带阻最直观
    └── 自然图像：85-95% 能量在低频
```
