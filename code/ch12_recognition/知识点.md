# 第12章：目标识别与匹配

> **面向零基础读者**：前面我们学习了如何从图像中提取特征（Hu矩、HOG、GLCM等）。目标识别 = "给一个未知图像/物体，告诉我们它属于哪一类"。本章学习：模板匹配、特征匹配（SIFT/SURF）、传统分类器（KNN、SVM）、以及深度学习（CNN）的基本思想。

---

## 一、识别方法总览

| 方法 | 思想 | 适用 | 代表 |
|------|------|------|------|
| **模板匹配** | 比较像素相似度 | 完全对齐的相同物体 | cv2.matchTemplate |
| **特征+分类器** | 提取描述符 → 训练分类器 → 预测 | 通用物体（需要分割） | Hu矩+KNN, HOG+SVM |
| **局部特征匹配** | 检测兴趣点 → 描述符 → 匹配 → 几何验证 | 部分可见、视角变化 | SIFT/SURF/ORB + RANSAC |
| **深度学习** | CNN端到端学习特征+分类 | 大规模通用识别 | ResNet, YOLO, ViT |

## 二、模板匹配（Template Matching）

### 2.1 基本思想

```
在图像 I 上滑动模板 T（大小M×N），在每个位置计算相似度，取最高/最低处。

滑动窗口:
T  → 在 I 上逐像素移动

相似度度量:
1. 平方差（SSD）: 
   R(x,y) = Σ Σ (I(x+s,y+t) - T(s,t))²
   → 最小值处 = 匹配位置

2. 归一化平方差:
   R(x,y) = ΣΣ(I-T)² / √(ΣΣI² · ΣΣT²)
   → 不受整体亮度影响

3. 相关系数（Correlation）:
   R(x,y) = ΣΣ(I-Ī)(T-T̄) / √(ΣΣ(I-Ī)² · ΣΣ(T-T̄)²)
   → 范围 [-1, 1]，1=完美正相关，-1=完美负相关，0=不相关
   → 对亮度偏移和缩放不敏感（相对强度匹配）

4. OpenCV实现: cv2.TM_CCOEFF_NORMED（归一化相关系数，最常用）
```

### 2.2 多尺度模板匹配

**问题**：如果目标大小与模板不同怎么办？

**解决**：对图像做高斯金字塔（多尺度），在每个尺度上匹配。

```
输入图像 I, 模板 T

1. 构建 I 的高斯金字塔: I₀=I, I₁=downsample(I₀), I₂=downsample(I₁), ...
2. 构建 T 的高斯金字塔: T₀=T, T₁=downsample(T₀), ...
3. 对每个尺度 i:
   a. 在 I_i 上用 T_i 做模板匹配
   b. 记录最佳匹配分数和位置
4. 所有尺度中取最高分 → 检测结果 + 目标尺寸
```

### 3.2 K-近邻（K-Nearest Neighbors, KNN）

**思想**：一个样本的类别 = 它附近 K 个邻居的多数投票。

```
训练阶段: 存储所有训练样本 { (x₁, y₁), (x₂, y₂), ..., (x_N, y_N) }
          x_i = 特征向量, y_i = 类别标签

预测阶段（对新样本 x_test）:
1. 计算 x_test 与所有训练样本的距离:
   d_i = distance(x_test, x_i)  ← 通常欧氏距离 √(Σ(x_test-x_i)²)

2. 找到距离最小的 K 个训练样本: NN = {x_{i1}, ..., x_{iK}}

3. 投票（多数类）: y_pred = mode(y_{i1}, ..., y_{iK})
   （mode = 出现次数最多的类别）

K的选择:
- K=1: 最近邻（对噪声敏感，但在某些简单场景非常好）
- K=5: 常用默认
- K=√N: 经验法则（N=训练样本数）
- K大: 平滑决策边界（但可能过度平滑）

距离度量的选择:
- 欧氏距离: 默认，特征尺度相近时
- 曼哈顿距离: 高维稀疏数据有时更好
- 马氏距离: 特征相关/尺度差异大时（需估计协方差矩阵）
```

**代码中 `knn_classifier(features, labels, n_neighbors=3)` 用 sklearn KNeighborsClassifier**

### 3.3 支持向量机（Support Vector Machine, SVM）

**核心思想**：在特征空间中找一个"最优"超平面，将两类尽可能分开——最大化两类之间的"间隔"（margin）。

```
线性SVM（线性可分数据）:

设训练数据: (x₁,y₁), ..., (x_N,y_N), y_i ∈ {+1, -1}

找超平面: w·x + b = 0

满足: y_i·(w·x_i + b) ≥ 1  for all i （每个样本都在正确一侧且距离≥1）

目标: 最小化 ||w||²/2 （等价于最大化间隔 2/||w||）

     +1 类  ●              
              \            
     ────────\────────  w·x+b = +1  (支持向量)
                \          
                 \         
     ─────────────────  w·x+b = 0   (决策边界)
                   \       
                    \     
     ────────\────────  w·x+b = -1  (支持向量)
              ○  ○  ○      -1 类

支持向量(SV) = 靠近边界的样本 → 只有它们决定边界！
（这就是"支持"的意思）

线性不可分? → 软间隔（Soft Margin）:
允许一些样本违反边界，但惩罚它们:
min ||w||²/2 + C·Σ ξ_i    (ξ_i = 第i个样本的"违反程度")
   C大 = 少容忍违反 → 边界更贴合训练数据 → 可能过拟合
   C小 = 多容忍违反 → 边界更平滑 → 可能欠拟合

非线性? → 核技巧（Kernel Trick）:
用 φ(x) 将 x 映射到高维空间，在高维空间中线性可分
常用核:
- 线性: K(x,x') = x·x'    （最快，特征多时默认）
- 多项式: K(x,x') = (γx·x' + r)^d
- RBF（高斯核）: K(x,x') = exp(-γ||x-x'||²)  ← 默认最常用
- Sigmoid: K(x,x') = tanh(γx·x' + r)

RBF核直觉: 把点映射到无穷维 → 总能找到线性分隔
γ 参数:
γ大 = 核"尖" → 每个训练样本自己的影响范围小 → 复杂边界 → 过拟合
γ小 = 核"宽" → 平滑边界 → 欠拟合

多类SVM:
- One-vs-All: 为每类训练一个SVM（该类 vs 其他所有），预测时选最高分
- One-vs-One: 每两类之间训练一个SVM，投票决定（K类需要 K(K-1)/2个SVM）
```

**代码中 `svm_classifier(features, labels, kernel='rbf')` 使用 sklearn SVC**

## 四、局部特征匹配（SIFT/SURF/ORB）

### 4.1 局部特征 vs 全局特征

| 全局特征（Hu矩、HOG） | 局部特征（SIFT关键点） |
|---------------------|---------------------|
| 对整个物体/图像计算 | 只对"关键点"周围计算 |
| 需要完整、对齐的物体 | 部分遮挡也能工作 |
| 对视角变化敏感 | 对视角/缩放/部分遮挡鲁棒 |
| 简单快速 | 复杂但强大 |

---

### 4.2 SIFT（Scale-Invariant Feature Transform，Lowe 1999/2004）

**SIFT 四步骤**：

```
Step 1: 尺度空间极值检测（在哪里找关键点？）
   - 在多个尺度的高斯差分图像（DoG = G_{σ·k} - G_σ）中找局部极值
   - 每个候选点: 在当前尺度、上一尺度、下一尺度的 3×3×3 邻域中是最大/最小值
   - 目的: 找到在不同尺度上都"显著"的点（缩放不变的基础）

Step 2: 关键点定位与过滤
   - 精确化关键点位置（用二次函数插值 DoG）
   - 去除低对比度点（阈值对比度 < 0.03，数值稳定性）
   - 去除边缘响应（沿边缘的点有一个方向曲率大但垂直方向小 → 不稳定）
   - 目的: 只保留稳定、高对比度的关键点（通常减少80%候选点）

Step 3: 方向分配（旋转不变的关键！）
   - 在关键点邻域内计算梯度方向直方图
   - 选主方向（最高峰）+ 辅方向（≥主方向80%的峰）
   - 目的: 每个关键点有独立方向 → 旋转时描述子也跟着旋转

Step 4: 关键点描述子（128维向量）
   - 在关键点周围 16×16 邻域内
   - 分成 4×4 = 16 个子区域
   - 每个子区域计算 8 方向（0-360°）梯度方向直方图
   - 16 × 8 = 128 维描述子向量
   - 归一化到单位长度（对光照不变）
   - 设大值为0.2后再归一化（对大梯度变化鲁棒）

最终: 每个关键点 = (x, y, 尺度σ, 方向θ, 128维描述子)

匹配两个图像的SIFT:
1. 分别提取图像A和B的SIFT关键点+描述子
2. 对A中每个描述子，在B中找最近邻（距离最小）和次近邻
3. 最近邻距离 / 次近邻距离 < 0.7 → 接受为好匹配
   （Lowe比率测试，过滤掉"模糊"匹配）
4. 对匹配对做几何验证（RANSAC估计单应矩阵/仿射变换）
5. 几何一致的匹配对数量 > 阈值 → 认为匹配成功
```

**SIFT 的专利状态**：2020年3月专利到期，现在 OpenCV 免费提供（xfeatures2d.SIFT_create）。

---

### 4.3 SURF（Speeded-Up Robust Features，Bay 2006）

**SIFT 的加速版**：
- 用盒式滤波器（Box Filter）近似高斯二阶导数 → 可快速用积分图计算
- Hessian 矩阵检测关键点（比DoG快）
- 64维描述子（比SIFT的128小，计算更快）
- 通常比SIFT快3-10倍，但稍欠鲁棒

---

### 4.4 ORB（Oriented FAST and Rotated BRIEF，Rublee 2011）

**OpenCV 免费、快速替代 SIFT**：
- FAST 角点检测（比DoG快得多）
- BRIEF 描述子（二值字符串，用汉明距离匹配，速度极快）
- "Oriented" = 给BRIEF加上方向信息（旋转不变）
- 256位描述子（32字节！比SIFT的128 float=512字节小16倍）
- 匹配用汉明距离（popcount CPU指令，纳秒级）

**代码中 `feature_matching(img1, img2, method='sift')` 封装了 SIFT/SURF/ORB**

## 五、几何验证：RANSAC（Random Sample Consensus）

**问题**：即使特征匹配后，仍然有很多"错匹配"（outlier）——我们需要在大量错误匹配中找到正确的几何变换。

```
RANSAC 算法（Fischler & Bolles, 1981）:

目标: 从包含大量异常值（outlier）的数据中估计模型参数

输入: 匹配点对集合 {(p₁,p₁'), (p₂,p₂'), ..., (p_N,p_N')}
      p_i = 图像1中的点, p_i' = 图像2中的对应点

模型: 单应矩阵（H, 3×3, 8自由度, 需至少4对点求解）
       p' ≈ H·p

迭代:
for k = 1 to max_iter:
   1. 随机选最小采样数 s（对单应矩阵 s=4）个匹配对
   2. 用这 s 个点求解模型 H
   3. 计算所有其他匹配点与 H 的一致程度:
      inlier_i = 1 if distance(p_i', H·p_i) < ε （ε=阈值，如5像素）
               = 0 otherwise
   4. 统计 inlier 数: n_inliers = Σ inlier_i
   5. if n_inliers > 当前最佳: 更新最佳模型 H_best

最终: 用所有 inlier 重新拟合 H_best → 得到最终模型

迭代次数的自适应计算:
k = log(1-p) / log(1 - w^s)
   p = 期望成功概率（通常0.99）
   w = inlier比例（未知，从迭代中估计）
   s = 最小采样数

直觉: "从少量随机样本中找到一个足够好的模型，
       它能解释最多的数据点"= 从噪声中鲁棒地估计模型
```

**代码中 `homography_verification(pts1, pts2)` 使用 cv2.findHomography with RANSAC**

## 六、图像分类：Bag of Features（BoF，词袋模型）

**思想**：把图像看作"视觉单词"的集合——类似文本分类把文档看作单词的集合。

```
训练阶段:
1. 从所有训练图像中提取 SIFT/ORB 局部特征（每张图可能有几百到几千个特征）
2. 用 K-Means 聚类所有特征到 K 个中心 → 这 K 个中心 = "视觉单词"
3. 构建"字典"：每个视觉单词有一个ID（1~K）
4. 对每张图像:
   a. 提取它的所有局部特征
   b. 每个特征 → 找最近的视觉单词（量化）
   c. 构建 K 维直方图（每个视觉单词出现多少次）
   → 这就是图像的BoF特征向量
5. 用BoF特征向量 + 标签训练SVM分类器

预测阶段:
1. 提取新图像的局部特征
2. 用相同字典量化 → 得到BoF直方图
3. 送入SVM → 得到类别

扩展: Spatial Pyramid Matching (SPM)
- 不是对整张图一个直方图，而是分 1×1, 2×2, 4×4 三个层级
- 每个子区域独立计算BoF直方图
- 拼接 → 保留空间位置信息（比纯BoF显著更好）

典型参数:
- K=1000 视觉单词
- 特征: SIFT（高质量）或 ORB（高速）
- 分类器: 线性SVM（速度+精度最佳平衡）
```

**代码中 `bag_of_features(train_imgs, train_labels, test_img, k_clusters=100)` 实现BoF**

## 七、深度学习入门：CNN一瞥

**为什么传统方法不够？**
- 需要手动设计特征（Hu矩、HOG、SIFT都是人类设计的）
- 在复杂场景（不同光照、遮挡、姿态）下难以设计足够鲁棒的特征
- 大规模分类（如 ImageNet 1000类）时传统方法精度有限

**CNN 的优势**：自动从数据中学习特征——端到端学习！

```
典型 CNN 架构（如 AlexNet/VGG/ResNet）:

输入图像 (224×224×3)
    │
    ▼
┌──────────────┐
│ Conv 3×3, 64 │ ← 卷积层: 学习64种3×3的边缘/纹理模式
│ ReLU         │ ← 非线性: max(0,x)
│ MaxPool 2×2  │ ← 降采样: 保留最大响应，空间尺寸减半
└──────┬───────┘
       │
       ▼  （重复多次 Conv+Pool，通道数越来越多，空间越来越小）
       │
┌──────┴────────┐
│ Conv 3×3, 512 │ ← 学习更抽象的模式: 边缘组合→纹理→部分形状
│ ...           │
└──────┬────────┘
       │
       ▼
┌──────────────┐
│ AdaptivePool │ ← 全局平均池化或展平
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ FC 4096      │ ← 全连接层: 学习"特征组合→类别"的映射
│ ReLU + Dropout│
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ FC 1000      │ ← 输出1000维（ImageNet 1000类的logits）
│ Softmax      │ ← 转换为概率分布 Σp_i=1
└──────┬───────┘
       │
       ▼
  预测类别 = argmax(p)


训练:
- 前向传播: 输入 → 预测类别
- 计算损失: loss = CrossEntropy(预测, 真实标签)
- 反向传播: loss对每个参数的梯度（链式法则）
- 优化器更新: w = w - η·∂loss/∂w （SGD/Adam）
- 重复数百万次（在GPU上）
```

**预训练 + 微调（Transfer Learning）**：

对于小数据集（几千张图，几类）：
```
1. 取在 ImageNet（1000万图，1000类）上预训练好的 ResNet50
2. "冻结"前面所有层（保留通用特征提取能力）
3. 替换最后的 FC 层为你自己的（比如10类）
4. 用你的数据训练这最后一层
5. （可选）解冻几层并以小学习率微调

原因: 前几层学习的是通用的边缘/纹理，在你的数据上也适用
    = 用1000万张图学到的知识来"帮助"你的小数据集任务
    = 通常比从零训练好得多，也快得多
```

## 八、性能评估：混淆矩阵、精度、召回、F1

```
二分类的混淆矩阵:
                预测为正  预测为负
实际为正        TP        FN     (TP=True Positive, FN=False Negative)
实际为负        FP        TN     (FP=False Positive, TN=True Negative)

准确率 Accuracy = (TP+TN)/(TP+FP+FN+TN)
精确率 Precision = TP/(TP+FP)   （预测为正的里面真的是正的比例）
召回率 Recall   = TP/(TP+FN)   （真的是正的被找出来的比例）
F1分数         = 2·P·R/(P+R)  （精确率和召回率的调和平均）

多分类: 对每类做 One-vs-All 计算，然后求平均

常见问题:
- 数据不平衡（90%是A类，10%是B类）:
  盲目猜A类 → 90%准确率但没意义
  → 用F1或AUC（Area Under ROC Curve）更公平
  → 训练时对B类样本加权重或过采样
```

### 12. `evaluate_classifier(classifier, test_features, test_labels)`：评估分类器（准确率、混淆矩阵）

## 十、方法对比与实践建议

| 场景 | 推荐方法 | 理由 |
|------|---------|------|
| 固定视角、无缩放、完美对齐 | 模板匹配 | 简单，几行代码 |
| 能分割出完整物体、类别≤10 | Hu矩 + KNN | 特征维度低，快 |
| 能分割但类别多、形状变化大 | HOG + SVM 或 BoF | 经典目标检测流程（2005-2014年标准） |

| 大规模分类（>100类） | 预训练CNN + 微调 | 现代标准（2012至今） |
| 实时检测 | YOLO / SSD | 速度最快（FPS高） |
| 高精度检测 | Faster R-CNN / DETR | mAP最高 |

## 十一、初学者常见问题解答

### Q1: KNN 的 K 怎么选？距离度量用什么？

**答**：

```
K选择:
1. 小数据集: 试 K=1,3,5,7,9，用验证集选最佳
2. 经验: K=√N（N=训练样本数）
3. 永远用奇数（避免平票）

距离度量:
- 特征尺度相近: 欧氏距离（默认）
- 特征尺度差异大（如面积=1000, Hu矩=0.01）: 先归一化! 
  每个特征: x' = (x - mean) / std （Z-score归一化）
- 二值特征（如ORB）: 汉明距离（popcount，极快）
- 稀疏特征: 余弦相似度（文本/词袋）

为什么归一化重要?
未归一化: 距离主要由"面积"（值大）决定，Hu矩贡献可忽略
归一化后: 所有特征权重相等
```

### Q2: SIFT 听起来很复杂，我需要自己实现吗？

**答**：**不需要！**

```
实际工作中永远用 OpenCV / scikit-image 的优化实现:
import cv2
sift = cv2.xfeatures2d.SIFT_create()
kps, des = sift.detectAndCompute(gray, mask=None)

# 或用免费替代（速度更快，但稍欠鲁棒）
orb = cv2.ORB_create(nfeatures=2000)
kps, des = orb.detectAndCompute(gray, mask=None)

匹配:
bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)  # ORB用汉明距离
bf = cv2.BFMatcher(cv2.NORM_L2, crossCheck=False)       # SIFT用L2距离
matches = bf.knnMatch(des1, des2, k=2)

Lowe比率测试:
good = []
for m, n in matches:
    if m.distance < 0.75 * n.distance:
        good.append(m)

几何验证（RANSAC + 单应矩阵）:
if len(good) >= 4:
    pts1 = np.float32([kps1[m.queryIdx].pt for m in good]).reshape(-1,1,2)
    pts2 = np.float32([kps2[m.trainIdx].pt for m in good]).reshape(-1,1,2)
    H, mask = cv2.findHomography(pts1, pts2, cv2.RANSAC, 5.0)
    inliers = mask.ravel().sum()
    if inliers >= 10:  # 至少10个内点才认为有效
        print(f"匹配成功! {inliers}/{len(good)}个内点")
```

**核心原则**：复杂但已被广泛验证的算法（SIFT、RANSAC、SVM）——永远用库，不要自己写！
