## 一、从光学图像到数字图像：什么是采样与量化？

### 1.1 现实世界 vs 计算机世界

想象你用手机拍照：

```
现实场景（连续的光） →  相机传感器  →  数字图像（离散的像素）
                    ↓              ↓
                 采样            量化
```

**采样（Sampling）** = 把连续的空间切成一个个小格子（像素）
**量化（Quantization）** = 把每个格子的亮度值整量化成有限个级别

| 概念 | 通俗比喻 | 关键问题 |
|------|----------|----------|
| 采样 | 用网格盖在画上，只看网格中心的颜色 | 格子太粗会怎样？ |
| 量化 | 给每个格子的颜色打分，满分255分 | 分数级别太少会怎样？ |

---

### 1.2 采样详解：分辨率是怎么来的？

**数学定义**：

采样是将连续二维函数 f(x, y) 在一系列离散坐标点上取值的过程。

```
设连续图像为 f(x, y)，其中 x, y ∈ ℝ（实数）
采样后得到 f[m, n] = f(m·Δx, n·Δy)，其中 m, n ∈ ℤ（整数）
Δx, Δy 为采样间隔（像素间距）
```

**直观理解**：
- Δx 越小 → 采样越密集 → 图像越清晰 → 文件越大
- Δx 越大 → 采样越稀疏 → 图像越模糊（马赛克） → 文件越小

**奈奎斯特-香农采样定理**（最重要的理论基础）：

> 为了能够从采样后的信号完美重建原始信号，采样频率必须至少是信号最高频率的 2 倍。

```
fs ≥ 2 · fmax
```

如果不满足这个条件，就会产生**混叠（Aliasing）**现象——听起来是频率混在一起，视觉上就是：
- 条纹图案出现波浪状伪影
- 远处的细纹理出现锯齿
- 这也是为什么高级相机有"抗锯齿滤镜（AA Filter）"

**常见分辨率对照**：

| 分辨率 | 像素数 | 典型用途 | 视觉感受 |
|--------|--------|----------|----------|
| 320×240 | 7.68万 | 早期手机 | 模糊，马赛克明显 |
| 640×480 | 30.7万 | VGA标准 | 基本可辨识 |
| 1280×720 | 92万 | 高清(720p) | 清晰可辨 |
| 1920×1080 | 207万 | 全高清 | 人眼舒适 |
| 3840×2160 | 829万 | 4K超高清 | 细节丰富 |

### 1.3 量化详解：灰度级是怎么来的？

**数学定义**：

量化是将连续的亮度值映射到有限个离散级别的过程。

```
设原始亮度 f ∈ [0, Lmax]
量化级别数为 K，量化步长 Δ = Lmax / K
量化后 q = round(f / Δ) · Δ  或  q = floor(f / Δ) · Δ
```

**量化的两种方式**：

1. **均匀量化**（本章使用的方式）：每个量化区间大小相等
   ```
   step = 256 / levels
   q = floor(gray / step) * step
   ```

2. **非均匀量化**：对人眼敏感的灰度范围分配更多级别（更高效，JPEG压缩中用到）

**量化误差（Quantization Error）**：

```
ε = f - q
|ε| ≤ Δ/2  （均匀量化下的最大误差）
```

**量化级别与视觉效果**：

| bits | levels | 视觉描述 | 典型现象 |
|------|--------|----------|----------|
| 1 | 2 | 二值图像 | 完全黑白，类似印章 |
| 2 | 4 | 四级灰度 | 明显假轮廓（如人脸出现环形伪影） |
| 3 | 8 | 八级灰度 | 假轮廓可察觉，渐变不自然 |
| 4 | 16 | 十六级灰度 | 轻微假轮廓，基本可用 |
| 5 | 32 | 三十二级灰度 | 人眼很难察觉到假轮廓 |
| 8 | 256 | 标准灰度 | 人眼感知极限，完美渐变 |

**假轮廓（False Contouring）是什么？**

想象你画一条从黑到白的渐变条。如果只能用4种灰色，你会得到4条明显的色带，而不是平滑渐变——这就是假轮廓。

数学上的解释是：当量化步长 Δ 超过人眼的亮度辨别阈值（约为整个亮度范围的1%-2%）时，相邻像素的亮度跳变变得可感知。

## 二、噪声模型：图像为什么会有"雪花"？

### 2.1 噪声的来源

图像噪声来源于成像过程的各个环节：

| 环节 | 典型噪声 | 说明 |
|------|----------|------|
| 光子入射 | 光子噪声（泊松） | 光本身是量子化的，光子到达传感器是随机事件 |
| 光电转换 | 热噪声（高斯） | 电子热运动产生的随机扰动 |
| 读出电路 | 读出噪声（高斯） | 放大器的固有噪声 |
| 量化过程 | 量化噪声（均匀） | 舍入误差 |
| 传输过程 | 椒盐噪声 | 传输错误导致某些像素完全黑/完全白 |
| 环境干扰 | 周期噪声 | 电源干扰、射频干扰产生条纹 |

---

### 2.2 高斯噪声（Gaussian Noise）——最常见的噪声

#### 什么是高斯分布？

高斯分布（正态分布）是概率论中最重要的分布之一，其概率密度函数为：

```
p(z) = (1 / (σ·√(2π))) · exp( -(z - μ)² / (2σ²) )
```

其中：
- **μ**（mu）= **均值**：噪声的中心位置（通常为0，表示噪声在正负方向对称）
- **σ**（sigma）= **标准差**：噪声的强度大小（σ 越大，噪点越重）
- **σ²** = **方差**：噪声的能量

**直观理解**：

想象你向靶子射箭：
- μ=0 表示你瞄准靶心
- σ 越小，箭越集中在靶心附近 → 噪声小
- σ 越大，箭散布得越开 → 噪声大

#### 图像中的高斯噪声

在图像处理中，高斯噪声是**加性噪声**，意味着：

```
g(x, y) = f(x, y) + η(x, y)
```

其中：
- `f(x, y)` = 原始（干净）图像
- `η(x, y)` = 高斯噪声，每个像素独立从 N(0, σ²) 采样
- `g(x, y)` = 被噪声污染后的图像

**参数 σ 的物理意义**：

| σ 值 | 视觉效果 | 对应场景 | 信噪比(SNR) |
|------|----------|----------|------------|
| 2-5 | 几乎不可察 | 高档相机低ISO | >40dB |
| 10-15 | 轻微颗粒感 | 普通相机ISO200 | ~25dB |
| 25-30 | 明显噪点 | 手机低光拍摄 | ~15dB |
| 50-80 | 严重噪声覆盖 | 极暗环境/高压缩 | <10dB |

**信噪比（SNR）计算**：

```
PSNR = 10 · log₁₀( 255² / MSE )  dB
MSE = (1/N)·Σ( f - g )²  =  σ²  （当噪声为零均值高斯时）
```

所以当 σ=15 时：
```
PSNR ≈ 10 · log₁₀(65025/225) ≈ 10 · log₁₀(289) ≈ 24.6 dB
```

这是一个"还行"的质量水平（>30dB 为良好，>40dB 为优秀）。

#### 高斯噪声的性质

1. **线性不变性**：两个独立高斯噪声相加仍然是高斯噪声
2. **概率函数完全由均值和方差确定**：知道 μ 和 σ 就知道了一切
3. **统计独立性**：不同像素的噪声值互不相关（白噪声）
4. **中心极限定理**：多个独立小噪声叠加后趋近于高斯分布（这就是为什么实际噪声常表现为高斯分布）

---

### 2.3 噪声家族：高斯噪声 vs 其他噪声

理解高斯噪声后，对比其他常见噪声类型能帮助你建立完整的知识体系：

| 噪声类型 | 数学模型 | 典型来源 | 视觉特征 | 去除方法 |
|----------|----------|----------|----------|----------|
| **高斯噪声** | N(0, σ²) 加性 | 热噪声、电子噪声 | 均匀散布的颗粒 | 高斯/均值/中值滤波 |
| **泊松噪声** | P(λ·f) 乘性 | 光子计数限制 | 与亮度成正比，亮处噪点多 | 方差稳定变换 + 高斯去噪 |
| **椒盐噪声** | P(f=0)=p, P(f=255)=q | 传输错误、死像素 | 黑白散点 | 中值滤波！ |
| **均匀噪声** | U(-a, a) | 量化误差 | 颗粒均匀但强度固定 | 高斯滤波 |
| **指数噪声** | λ·exp(-λz) | 激光成像 | 长尾分布 | 非线性滤波 |
| **周期噪声** | A·sin(ωx+φ) | 电源/射频干扰 | 规则条纹 | 频域陷波滤波 |
| **斑点噪声** | 乘性 f·η | 超声、SAR雷达 | 纹理状颗粒 | 各向异性扩散 |

#### 重点对比：高斯噪声 vs 泊松噪声

| 对比项 | 高斯噪声 | 泊松噪声 |
|--------|----------|----------|
| **数学形式** | g = f + N(0, σ²) | g ~ P(λ·f)（以f为参数的泊松分布） |
| **与信号关系** | 加性、独立于信号 | 信号相关：越亮的地方噪声越大 |
| **方差-均值关系** | 方差=σ²（固定） | 方差=均值=λ·f |
| **参数意义** | σ 控制整体噪声强度 | λ 控制光子数倒数，越暗噪声越大 |
| **分布形状** | 对称、钟形 | 正偏斜，低亮度时尤其明显 |
| **适用场景** | 相机电子噪声、读出噪声 | 低光拍摄、天文图像、荧光显微 |
| **去噪难度** | 相对容易 | 困难（需先做方差稳定变换） |

**为什么泊松噪声更难处理？**

因为泊松噪声的强度取决于信号本身（信号越大，噪声方差越大），这破坏了线性滤波的假设。通常先用 Anscombe 变换将其转换为近似恒定方差的噪声，再用高斯去噪方法：

```
A(z) = 2·√(z + 3/8)
```

#### 重点对比：高斯噪声 vs 椒盐噪声

| 对比项 | 高斯噪声 | 椒盐噪声 |
|--------|----------|----------|
| **对像素的影响** | 每个像素值都轻微偏移 | 少数像素值变为0或255 |
| **分布** | 连续概率分布 | 离散：0概率p，255概率q，原值概率1-p-q |
| **适用均值滤波** | ✅ 有效，平滑噪声 | ❌ 效果差，黑白点会扩散 |
| **适用中值滤波** | ⚠️ 有损失但可接受 | ✅ **最佳选择**，完全去除孤立点 |
| **视觉效果** | 整幅图蒙上"颗粒" | 随机散布的纯黑/纯白点 |

**中值滤波为什么能对付椒盐噪声？**

想象邻居像素值：`[120, 0, 125, 122, 255]`（中间两个是椒盐噪声）
- 均值滤波：(120+0+125+122+255)/5 = 124.4 → 把0和255的"脏"值混入了结果
- 中值滤波：排序 `[0, 120, 122, 125, 255]`，取中间值 = **122** ✅ 完全不受极值影响

这就是为什么中值滤波是椒盐噪声的克星！

### 2.4 随机种子（Seed）的意义

在 `simulate_sensor_noise` 函数中，第二个可选参数是 `seed`。

**为什么需要 seed？**

计算机的"随机数"实际上是**伪随机数**——给定相同的起点，会产生完全相同的数列。

```
seed=42 → [0.73, -1.21, 0.55, -0.84, ...]
seed=42 → [0.73, -1.21, 0.55, -0.84, ...]  ← 完全相同！
seed=99 → [1.22, -0.31, -0.92, ...]        ← 不同起点，不同序列
seed=None → 每次都不同（基于系统时间）
```

**为什么要固定 seed？**

1. **科学实验可复现性**：甲乙两人做同一个去噪实验，用相同 seed 才能公平对比算法效果
2. **调试**：程序出问题时，固定 seed 可以精确复现问题
3. **教学演示**：课堂上每个人看到相同的演示效果

## 三、模拟量化：深入理解 `simulate_quantization`

### 3.1 算法详细步骤

```
输入：灰度图 gray (uint8, 范围0-255)
参数：levels (默认16)

步骤1：计算量化步长
  step = floor(256 / levels)
  例：levels=16 → step=16
       levels=4 → step=64

步骤2：对每个像素量化
  q = floor(gray / step) * step
  例：gray=100, step=16
      floor(100/16) = floor(6.25) = 6
      q = 6 * 16 = 96  ← 100被"向下取整"到最近的量化级别

步骤3：输出 q (uint8)
```

**量化级别的实际含义**：

| levels | step | 可表示的灰度值 | 丢失的信息 |
|--------|------|----------------|------------|
| 256 | 1 | 0,1,2,...,255 | 无（无损） |
| 128 | 2 | 0,2,4,...,254 | 最低1bit |
| 16 | 16 | 0,16,32,...,240 | 最高4bit（约75%信息）|
| 4 | 64 | 0,64,128,192 | 只剩2bit（93%丢失） |
| 2 | 128 | 0, 128 | 只剩1bit |

### 3.2 量化误差分析

**均方误差（MSE）**：

```
MSE = (1/N) · Σ (gray - q)²
```

均匀量化下，理论 MSE 为：

```
MSE ≈ step² / 12 = (256/levels)² / 12
```

| levels | step | 理论 MSE | PSNR（dB） |
|--------|------|----------|-----------|
| 256 | 1 | 0.08 | 49.1 |
| 64 | 4 | 1.33 | 36.9 |
| 32 | 8 | 5.33 | 30.9 |
| 16 | 16 | 21.33 | 24.8 |
| 8 | 32 | 85.33 | 18.8 |
| 4 | 64 | 341.33 | 12.8 |

可以看到：**每减少一半量化级别，PSNR大约下降6dB**——这是一个重要的经验规律。

## 四、图像缩放：深入理解 `resize_for_display`

### 4.1 插值方法详解

当你缩小或放大图像时，需要对新像素位置"猜测"它应该是什么颜色——这就是**插值（Interpolation）**。

| 插值方法 | OpenCV 常量 | 原理 | 适用场景 | 质量 | 速度 |
|----------|------------|------|----------|------|------|
| 最近邻 | `INTER_NEAREST` | 取距离最近的像素值 | **缩小后放大**（演示马赛克） | 低 | 最快 |
| 双线性 | `INTER_LINEAR` | 4个邻居像素加权平均 | 一般放大/缩小 | 中 | 快 |
| 双三次 | `INTER_CUBIC` | 16个邻居像素样条插值 | 高质量放大 | 高 | 中 |
| 区域 | `INTER_AREA` | 像素区域重采样 | **缩小**（抗锯齿） | 最佳 | 中 |
| Lanczos | `INTER_LANCZOS4` | 8×8 sinc插值 | 专业级放大 | 最高 | 最慢 |

### 4.2 为什么缩小要用 INTER_AREA？

**问题**：缩小图像意味着多个原始像素要合并为一个新像素。

```
原图（4×4缩小到2×2）：
[10 20 30 40]      [? ?]
[15 25 35 45]  →   [? ?]
[50 60 70 80]
[55 65 75 85]
```

- **最近邻**：只取左上角像素 → `[10,30; 50,70]` ❌ 丢掉了大部分信息，出现锯齿
- **双线性**：对新位置插值 → 但缩小场景下效果不如 AREA
- **区域**：计算每个新像素覆盖的原图区域平均值 → `[17.5, 37.5; 57.5, 77.5]` ✅ 信息保留最好

**数学原理**（以缩小 factor=2 为例）：

```
g_new[m,n] = (1/4) · Σ Σ f(2m+i, 2n+j),  i,j ∈ {0,1}
```

这本质上是一个 2×2 的均值平滑 + 下采样，天然具有抗混叠效果。

## 六、本章函数完整参考

### 1. `simulate_sensor_noise(img, sigma=15.0, seed=None)`

**功能**：为图像添加高斯噪声，模拟传感器在低光或高ISO下的噪声表现。

**完整算法流程**：

```
输入: img (原始图像)
     sigma (噪声标准差, 默认15.0)
     seed (随机数种子, 默认None)

Step 1: 图像预处理
  ├─ 将输入图像转换为单通道灰度图
  └─ 确保像素值为 uint8 类型

Step 2: 生成噪声
  ├─ 初始化随机数生成器 (numpy Random Generator)
  │  └─ 若指定 seed，则使用固定种子保证可复现
  └─ 生成与图像同尺寸的高斯噪声矩阵 η ~ N(0, σ²)
     └─ 注意：numpy.random.normal 接受 sigma（标准差），不是方差

Step 3: 噪声注入
  ├─ 将原图转换为 float64（防止 uint8 加减溢出）
  ├─ 执行加法: noisy = gray + η
  └─ 此处验证: uint8 最大值为255，加噪声后可能超限

Step 4: 范围约束（Clip）
  └─ 使用 np.clip(noisy, 0, 255) 限制在合法范围
     └─ 为什么不直接用模运算？因为 255+5=4 这种"回绕"会产生严重伪影

Step 5: 类型还原
  └─ 转换回 uint8 以符合 OpenCV 标准格式

输出: 被高斯噪声污染后的图像
```

**参数调优指南**：

| sigma | 适用场景 | 预期 PSNR | 肉眼观察 |
|-------|----------|-----------|----------|
| 2-5 | 演示轻微噪声 | 40-48dB | 几乎不可察觉 |
| 10 | 模拟普通相机 | ~32dB | 轻微颗粒感 |
| 15-20 | 默认演示值 | 22-27dB | 明显噪点 |
| 30 | 低光模拟 | ~18dB | 噪点影响观察 |
| 50+ | 极端噪声挑战 | ~14dB | 用于测试去噪算法极限 |

**常见陷阱**：
- ❌ 错误：`noisy = gray + noise`（uint8 加法会回绕！必须先转 float）
- ✅ 正确：`noisy = gray.astype(np.float64) + noise`
- ❌ 错误：忘记 clip（负值会被 uint8 解释为大正数）

### 5. `resize_for_display(img, width=512)`

**功能**：将图像缩放到指定宽度以适应显示窗口，保持宽高比。

**智能判断逻辑**：
- 如果原图宽度 ≤ 目标宽度 → **不做任何处理**（避免不必要的质量损失）
- 如果原图宽度 > 目标宽度 → 使用 `INTER_AREA` 插值缩小

**为什么这是合理的？**
- 不放大：放大只会插值创造信息，不会增加真实细节，反而降低清晰度
- 使用 INTER_AREA：缩小时的最佳选择，具有天然抗混叠效果

## 七、初学者常见问题解答

### Q1: 为什么噪声总是"加性"的？实际情况不是这样吧？

**答**：你说得对，严格来说不完全是。但：

1. **加性高斯模型是一阶近似**：在中等亮度、非极低光环境下，电子噪声（热噪声、读出噪声）确实是主导的加性成分
2. **简化教学需要**：先理解加性模型，再逐步引入乘性（泊松）噪声
3. **实际工程中常做方差稳定变换**：将更复杂的噪声转换为近似高斯后再处理

### Q2: 我看到的照片噪声不是均匀的，暗部噪点更多，为什么？

**答**：这是真实相机的特点——暗部噪声主要是**光子噪声（泊松）+ 读出噪声**：

1. 光子到达传感器是泊松过程，光子越少（越暗），信噪比越低
2. 读出噪声是固定的（每个像素约1-10个电子），暗部信号本身就小，信噪比就差
3. 亮部光子数充足，信噪比高，噪声就不明显

我们的高斯噪声模型做了简化（均匀噪声强度），但对于教学目的已经足够。真实去噪算法如 BM3D、DnCNN 会考虑信号相关的噪声模型。

### Q3: 中值滤波对高斯噪声有效吗？

**答**：有一定效果，但**会比高斯滤波损失更多细节**。原因：

1. 中值滤波对排序后的所有值取中间值，而不是加权平均
2. 这在去除极值（椒盐噪声）时特别有效
3. 但对高斯噪声这种每个像素都"有点不对"的情况，均值/高斯滤波通过加权平均能更好地保留边缘信息
4. 经验法则：椒盐噪声→中值滤波，高斯噪声→高斯/双边/NLM/BM3D 滤波

### Q4: 采样和量化哪个对图像质量影响更大？

**答**：取决于具体条件，但一般经验：

1. **分辨率（采样）在 256×256 以下时影响最大**：低于这个分辨率，人脸都难以辨识
2. **灰度级在 8级以下时影响最大**：低于8级会出现明显假轮廓
3. **对自然图像**，人眼对空间分辨率的敏感度高于灰度分辨率

经典实验：保持总比特数不变（如 256×256×8bit = 512KB），对比不同的空间-灰度级分配——通常 512×512×4bit 看起来比 128×128×16bit 更好，说明空间分辨率更重要。

### Q5: JPEG 压缩和量化是什么关系？

**答**：JPEG 使用的是**频域量化**而不是空间域量化，但核心思想是相通的：

1. JPEG 先将图像分成 8×8 块
2. 对每个块做 DCT（离散余弦变换）得到频域系数
3. **用量化表对高频系数做粗量化**（即舍弃人眼不敏感的信息）
4. 这正是"利用人眼特性做信息压缩"——本质上是智能量化

所以：你在本章学习的量化概念是理解 JPEG、PNG 等压缩标准的基础！

## 八、进阶阅读方向

| 主题 | 推荐学习顺序 | 关键词 |
|------|-------------|--------|
| 噪声模型 | 高斯 → 泊松 → 混合模型 | PDF, CDF, 矩估计 |

| 量化优化 | 均匀量化 → Lloyd-Max → 向量量化 | rate-distortion theory |
