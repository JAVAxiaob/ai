# 第5章 图像复原与重建

退化模型（噪声/模糊）、空域与频域复原、Radon 投影重建。

本章实现 **13** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `adaptive_denoise`

- **中文别名**: 自适应去噪

- **说明**: 自适应滤波（双边）。参数: d, sigma_color, sigma_space

- **JSON 示例**: `{"adaptive_denoise": ""}` 或 `{"自适应去噪": "参数1, 参数2"}`


### `add_periodic_noise`

- **中文别名**: 周期噪声

- **说明**: 添加周期噪声（正弦条纹）。参数: amplitude, frequency_x, frequency_y (默认 30, 0.15, 0.1)

- **JSON 示例**: `{"add_periodic_noise": ""}` 或 `{"周期噪声": "参数1, 参数2"}`


### `add_salt_pepper_noise`

- **中文别名**: 椒盐噪声

- **说明**: 椒盐噪声。参数: amount (默认 0.05)

- **JSON 示例**: `{"add_salt_pepper_noise": ""}` 或 `{"椒盐噪声": "参数1, 参数2"}`


### `blind_deconvolution`

- **中文别名**: 盲复原

- **说明**: 盲复原简化（Richardson-Lucy 近似，迭代少）。参数: iterations (默认 5)

- **JSON 示例**: `{"blind_deconvolution": ""}` 或 `{"盲复原": "参数1, 参数2"}`


### `constrained_least_squares`

- **中文别名**: 约束最小二乘

- **说明**: 约束最小二乘滤波近似（拉普拉斯正则）。参数: gamma (默认 0.1)

- **JSON 示例**: `{"constrained_least_squares": ""}` 或 `{"约束最小二乘": "参数1, 参数2"}`


### `defocus_blur`

- **中文别名**: 散焦模糊

- **说明**: 散焦模糊（圆盘核）。参数: radius (默认 5)

- **JSON 示例**: `{"defocus_blur": ""}` 或 `{"散焦模糊": "参数1, 参数2"}`


### `inverse_filter`

- **中文别名**: 逆滤波

- **说明**: 逆滤波（频域，带阈值防除零）。参数: threshold (默认 0.01)

- **JSON 示例**: `{"inverse_filter": ""}` 或 `{"逆滤波": "参数1, 参数2"}`


### `mean_denoise`

- **中文别名**: 均值去噪

- **说明**: 均值去噪。参数: kernel_size (默认 5)

- **JSON 示例**: `{"mean_denoise": ""}` 或 `{"均值去噪": "参数1, 参数2"}`


### `median_denoise`

- **中文别名**: 中值去噪

- **说明**: 中值去噪。参数: kernel_size (默认 5)

- **JSON 示例**: `{"median_denoise": ""}` 或 `{"中值去噪": "参数1, 参数2"}`


### `motion_blur`

- **中文别名**: 运动模糊

- **说明**: 运动模糊。参数: size, angle (默认 15, 0)

- **JSON 示例**: `{"motion_blur": ""}` 或 `{"运动模糊": "参数1, 参数2"}`


### `radon_reconstruction_demo`

- **中文别名**: Radon重建

- **说明**: Radon 变换与反投影重建演示。

- **JSON 示例**: `{"radon_reconstruction_demo": ""}` 或 `{"Radon重建": "参数1, 参数2"}`


### `wiener_filter_freq`

- **中文别名**: 频域维纳

- **说明**: 频域维纳滤波。参数: K (默认 0.01)

- **JSON 示例**: `{"wiener_filter_freq": ""}` 或 `{"频域维纳": "参数1, 参数2"}`


### `wiener_filter_spatial`

- **中文别名**: 维纳滤波

- **说明**: 维纳滤波（频域实现）。参数: K (默认 0.01)

- **JSON 示例**: `{"wiener_filter_spatial": ""}` 或 `{"维纳滤波": "参数1, 参数2"}`
