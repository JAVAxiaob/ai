# 第10章 图像分割

分割：梯度/Canny 边缘、全局/自适应/Otsu 阈值、区域生长、分水岭。

本章实现 **13** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `adaptive_threshold`

- **中文别名**: 自适应阈值

- **说明**: 自适应阈值。参数: block_size, C (默认 11, 2)

- **JSON 示例**: `{"adaptive_threshold": ""}` 或 `{"自适应阈值": "参数1, 参数2"}`


### `canny_edge`

- **中文别名**: Canny边缘

- **说明**: Canny 边缘。参数: low, high (默认 50, 150)

- **JSON 示例**: `{"canny_edge": ""}` 或 `{"Canny边缘": "参数1, 参数2"}`


### `combined_edge_region`

- **中文别名**: 边缘区域结合

- **说明**: 边缘与区域结合：Canny 边缘与 Otsu 区域相乘。

- **JSON 示例**: `{"combined_edge_region": ""}` 或 `{"边缘区域结合": "参数1, 参数2"}`


### `laplacian_edge`

- **中文别名**: 拉普拉斯边缘

- **说明**: 拉普拉斯边缘。参数: ksize (默认 3)

- **JSON 示例**: `{"laplacian_edge": ""}` 或 `{"拉普拉斯边缘": "参数1, 参数2"}`


### `multi_threshold`

- **中文别名**: 多阈值

- **说明**: 多阈值（双阈值三类）。参数: t1, t2 (默认 85, 170)

- **JSON 示例**: `{"multi_threshold": ""}` 或 `{"多阈值": "参数1, 参数2"}`


### `otsu_threshold`

- **中文别名**: Otsu阈值

- **说明**: Otsu 阈值分割。

- **JSON 示例**: `{"otsu_threshold": ""}` 或 `{"Otsu阈值": "参数1, 参数2"}`


### `prewitt_edge`

- **中文别名**: Prewitt边缘

- **说明**: Prewitt 边缘。

- **JSON 示例**: `{"prewitt_edge": ""}` 或 `{"Prewitt边缘": "参数1, 参数2"}`


### `region_growing`

- **中文别名**: 区域生长

- **说明**: 区域生长。参数: row, col, threshold (默认中心, 15)

- **JSON 示例**: `{"region_growing": ""}` 或 `{"区域生长": "参数1, 参数2"}`


### `region_moments_vis`

- **中文别名**: 区域矩特征

- **说明**: 区域矩与几何特征可视化（面积、周长、圆形度、偏心率）。

- **JSON 示例**: `{"region_moments_vis": ""}` 或 `{"区域矩特征": "参数1, 参数2"}`


### `region_split_merge`

- **中文别名**: 区域分裂合并

- **说明**: 区域分裂合并（四叉树简化：均匀块合并）。

- **JSON 示例**: `{"region_split_merge": ""}` 或 `{"区域分裂合并": "参数1, 参数2"}`


### `sobel_edge`

- **中文别名**: Sobel边缘

- **说明**: Sobel 边缘。参数: ksize (默认 3)

- **JSON 示例**: `{"sobel_edge": ""}` 或 `{"Sobel边缘": "参数1, 参数2"}`


### `threshold_global`

- **中文别名**: 全局阈值

- **说明**: 全局固定阈值分割。参数: thresh[, maxval] (默认 127, 255)

- **JSON 示例**: `{"threshold_global": ""}` 或 `{"全局阈值": "参数1, 参数2"}`


### `watershed_segment`

- **中文别名**: 分水岭

- **说明**: 分水岭分割。参数: markers_count (默认 3)

- **JSON 示例**: `{"watershed_segment": ""}` 或 `{"分水岭": "参数1, 参数2"}`
