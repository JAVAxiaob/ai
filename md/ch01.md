# 第1章 绪论

涵盖数字图像处理概念、获取与显示环节模拟（传感器噪声、量化、系统标注）。

本章实现 **5** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `annotate_system_info`

- **中文别名**: 系统信息标注

- **说明**: 在图像上标注处理系统信息（模拟显示环节）。

- **JSON 示例**: `{"annotate_system_info": ""}` 或 `{"系统信息标注": "参数1, 参数2"}`


### `application_domains_demo`

- **中文别名**: 应用领域标注

- **说明**: 典型应用领域标注（医学/遥感/安防等）。

- **JSON 示例**: `{"application_domains_demo": ""}` 或 `{"应用领域标注": "参数1, 参数2"}`


### `resize_for_display`

- **中文别名**: 显示缩放

- **说明**: 缩放至指定宽度，模拟显示适配。参数: width (默认 512)

- **JSON 示例**: `{"resize_for_display": ""}` 或 `{"显示缩放": "参数1, 参数2"}`


### `simulate_quantization`

- **中文别名**: 量化模拟

- **说明**: 模拟量化（降低灰度级）。

- **JSON 示例**: `{"simulate_quantization": ""}` 或 `{"量化模拟": "参数1, 参数2"}`


### `simulate_sensor_noise`

- **中文别名**: 模拟传感器噪声

- **说明**: 模拟传感器噪声（高斯）。

- **JSON 示例**: `{"simulate_sensor_noise": ""}` 或 `{"模拟传感器噪声": "参数1, 参数2"}`
