# 第7章 小波和多分辨率处理

小波分解、金字塔、小波去噪/边缘/压缩演示。

本章实现 **5** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `dwt_decompose`

- **中文别名**: 小波分解

- **说明**: 二维小波分解可视化（拼接 LL/LH/HL/HH）。

- **JSON 示例**: `{"dwt_decompose": ""}` 或 `{"小波分解": "参数1, 参数2"}`


### `pyramid_downsample`

- **中文别名**: 金字塔降采样

- **说明**: 高斯金字塔降采样。参数: levels (默认 3)

- **JSON 示例**: `{"pyramid_downsample": ""}` 或 `{"金字塔降采样": "参数1, 参数2"}`


### `wavelet_compress_demo`

- **中文别名**: 小波压缩

- **说明**: 小波压缩演示（丢弃高频）。参数: keep_ratio (默认 0.1)

- **JSON 示例**: `{"wavelet_compress_demo": ""}` 或 `{"小波压缩": "参数1, 参数2"}`


### `wavelet_denoise`

- **中文别名**: 小波去噪

- **说明**: 小波软阈值去噪。参数: wavelet, sigma (默认 db4, 自动)

- **JSON 示例**: `{"wavelet_denoise": ""}` 或 `{"小波去噪": "参数1, 参数2"}`


### `wavelet_edge_detect`

- **中文别名**: 小波边缘

- **说明**: 小波高频子带边缘。参数: wavelet (默认 haar)

- **JSON 示例**: `{"wavelet_edge_detect": ""}` 或 `{"小波边缘": "参数1, 参数2"}`
