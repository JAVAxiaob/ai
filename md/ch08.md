# 第8章 图像压缩

无损/有损压缩：霍夫曼、行程、LZW、DCT、JPEG/JPEG2000 及视频帧预测。

本章实现 **8** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `arithmetic_encode_vis`

- **中文别名**: 算术编码

- **说明**: 算术编码压缩比演示（使用 zlib 作为工程实现参考）。

- **JSON 示例**: `{"arithmetic_encode_vis": ""}` 或 `{"算术编码": "参数1, 参数2"}`


### `dct_compress`

- **中文别名**: DCT压缩

- **说明**: DCT 块压缩。参数: keep_coeffs (默认 16，8x8 块保留系数个数)

- **JSON 示例**: `{"dct_compress": ""}` 或 `{"DCT压缩": "参数1, 参数2"}`


### `huffman_encode_decode_vis`

- **中文别名**: 霍夫曼演示

- **说明**: 霍夫曼编码演示（在图像上标注压缩比）。

- **JSON 示例**: `{"huffman_encode_decode_vis": ""}` 或 `{"霍夫曼演示": "参数1, 参数2"}`


### `jpeg2000_compress`

- **中文别名**: JPEG2000压缩

- **说明**: JPEG2000 压缩（需 OpenCV 支持）。参数: quality (默认 20)

- **JSON 示例**: `{"jpeg2000_compress": ""}` 或 `{"JPEG2000压缩": "参数1, 参数2"}`


### `jpeg_quality_compress`

- **中文别名**: JPEG压缩

- **说明**: JPEG 有损压缩。参数: quality (默认 30)

- **JSON 示例**: `{"jpeg_quality_compress": ""}` 或 `{"JPEG压缩": "参数1, 参数2"}`


### `lzw_compress_vis`

- **中文别名**: LZW压缩

- **说明**: LZW（zlib）压缩比演示。

- **JSON 示例**: `{"lzw_compress_vis": ""}` 或 `{"LZW压缩": "参数1, 参数2"}`


### `run_length_encode_vis`

- **中文别名**: 行程编码

- **说明**: 行程编码可视化（二值图）。

- **JSON 示例**: `{"run_length_encode_vis": ""}` 或 `{"行程编码": "参数1, 参数2"}`


### `video_frame_prediction_demo`

- **中文别名**: 视频帧预测

- **说明**: 视频帧间预测演示：用平移模拟第二帧，显示帧间差分（运动估计简化）。

- **JSON 示例**: `{"video_frame_prediction_demo": ""}` 或 `{"视频帧预测": "参数1, 参数2"}`
