# 第9章 形态学图像处理

二值/灰度形态学：腐蚀膨胀、开闭、击中击不中、骨架、顶帽及重建。

本章实现 **18** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `black_hat`

- **中文别名**: 黑帽

- **说明**: 黑帽变换。

- **JSON 示例**: `{"black_hat": ""}` 或 `{"黑帽": "参数1, 参数2"}`


### `boundary_extract`

- **中文别名**: 边界提取

- **说明**: 边界提取（原图减腐蚀）。

- **JSON 示例**: `{"boundary_extract": ""}` 或 `{"边界提取": "参数1, 参数2"}`


### `closing`

- **中文别名**: 闭运算

- **说明**: 闭运算。参数: kernel_size (默认 3)

- **JSON 示例**: `{"closing": ""}` 或 `{"闭运算": "参数1, 参数2"}`
