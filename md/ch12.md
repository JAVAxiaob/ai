# 第12章 目标识别

识别：模板匹配、距离分类、贝叶斯、SVM、Hu 矩、BP/CNN 特征演示。

本章实现 **9** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `bayesian_threshold_demo`

- **中文别名**: 贝叶斯阈值

- **说明**: 贝叶斯思想：两类高斯混合阈值（Otsu 近似）。

- **JSON 示例**: `{"bayesian_threshold_demo": ""}` 或 `{"贝叶斯阈值": "参数1, 参数2"}`


### `bp_neural_demo`

- **中文别名**: BP神经网络

- **说明**: BP 神经网络分类演示（MLP 对像素块二分类并可视化决策区域）。

- **JSON 示例**: `{"bp_neural_demo": ""}` 或 `{"BP神经网络": "参数1, 参数2"}`


### `cnn_feature_map_demo`

- **中文别名**: CNN特征演示

- **说明**: 深度学习特征演示：使用 OpenCV DNN 若不可用则 Sobel 堆叠模拟特征图。

- **JSON 示例**: `{"cnn_feature_map_demo": ""}` 或 `{"CNN特征演示": "参数1, 参数2"}`


### `graph_matching_demo`

- **中文别名**: 图匹配

- **说明**: 图匹配演示：提取轮廓多边形顶点并连线匹配相似形状。

- **JSON 示例**: `{"graph_matching_demo": ""}` 或 `{"图匹配": "参数1, 参数2"}`


### `minimum_distance_classifier_demo`

- **中文别名**: 最小距离分类

- **说明**: 最小距离分类演示（KMeans 聚类着色）。

- **JSON 示例**: `{"minimum_distance_classifier_demo": ""}` 或 `{"最小距离分类": "参数1, 参数2"}`


### `shape_matching_hu`

- **中文别名**: Hu矩匹配

- **说明**: Hu 矩形状匹配标注。

- **JSON 示例**: `{"shape_matching_hu": ""}` 或 `{"Hu矩匹配": "参数1, 参数2"}`


### `svm_segment_demo`

- **中文别名**: SVM分割

- **说明**: SVM 像素分类演示（简化：采样训练）。

- **JSON 示例**: `{"svm_segment_demo": ""}` 或 `{"SVM分割": "参数1, 参数2"}`


### `syntactic_pattern_demo`

- **中文别名**: 句法模式识别

- **说明**: 句法模式识别演示：用链码方向序列匹配简单形状（圆/方）。

- **JSON 示例**: `{"syntactic_pattern_demo": ""}` 或 `{"句法模式识别": "参数1, 参数2"}`


### `template_matching`

- **中文别名**: 模板匹配

- **说明**: 模板匹配（使用图像中心块为模板）。

- **JSON 示例**: `{"template_matching": ""}` 或 `{"模板匹配": "参数1, 参数2"}`
