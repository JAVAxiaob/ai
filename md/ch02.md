# 第2章 数字图像基础

涵盖采样量化、邻域与连通性、距离度量、卷积及视觉/波段演示。

本章实现 **10** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `add_gaussian_noise`

- **中文别名**: 添加高斯噪声

- **说明**: 添加高斯噪声。参数: sigma (默认 25)

- **JSON 示例**: `{"add_gaussian_noise": ""}` 或 `{"添加高斯噪声": "参数1, 参数2"}`


### `connectivity_components_vis`

- **中文别名**: 连通分量

- **说明**: 连通分量标记可视化（4/8 连通）。参数: connectivity (4|8，默认 8)

- **JSON 示例**: `{"connectivity_components_vis": ""}` 或 `{"连通分量": "参数1, 参数2"}`


### `convolve_demo`

- **中文别名**: 卷积演示

- **说明**: 矩阵卷积演示（平滑核）。参数: kernel_size (默认 3)

- **JSON 示例**: `{"convolve_demo": ""}` 或 `{"卷积演示": "参数1, 参数2"}`


### `distance_transform_vis`

- **中文别名**: 距离变换可视化

- **说明**: 距离变换可视化（欧氏/街区/棋盘由 metric 决定）。

- **JSON 示例**: `{"distance_transform_vis": ""}` 或 `{"距离变换可视化": "参数1, 参数2"}`


### `downsample`

- **中文别名**: 降采样

- **说明**: 降低空间分辨率（采样）。参数: factor (默认 4)

- **JSON 示例**: `{"downsample": ""}` 或 `{"降采样": "参数1, 参数2"}`


### `mark_neighbors`

- **中文别名**: 邻域标记

- **说明**: 标记 4/8 邻域中心像素。

- **JSON 示例**: `{"mark_neighbors": ""}` 或 `{"邻域标记": "参数1, 参数2"}`


### `optical_illusion_demo`

- **中文别名**: 视觉错觉

- **说明**: 视觉错觉演示：在输入图上叠加赫尔曼网格错觉图案。

- **JSON 示例**: `{"optical_illusion_demo": ""}` 或 `{"视觉错觉": "参数1, 参数2"}`


### `probability_noise_demo`

- **中文别名**: 概率噪声演示

- **说明**: 概率与随机过程演示：对图像施加高斯噪声并显示灰度直方图对比条。

- **JSON 示例**: `{"probability_noise_demo": ""}` 或 `{"概率噪声演示": "参数1, 参数2"}`


### `quantize_levels`

- **中文别名**: 灰度量化

- **说明**: 灰度量化。参数: bits (默认 4，即 16 级)

- **JSON 示例**: `{"quantize_levels": ""}` 或 `{"灰度量化": "参数1, 参数2"}`


### `spectrum_band_simulation`

- **中文别名**: 波段成像

- **说明**: 模拟不同波段成像（可见光/红外/雷达风格）。

- **JSON 示例**: `{"spectrum_band_simulation": ""}` 或 `{"波段成像": "参数1, 参数2"}`
