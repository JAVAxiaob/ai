# 第3章 灰度变换与空间滤波

空间域增强核心：灰度变换、直方图处理、平滑/锐化滤波与模糊集增强。

本章实现 **15** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `contrast_stretch`

- **中文别名**: 对比度拉伸

- **说明**: 对比度拉伸。参数: low_percent, high_percent (默认 2, 98)

- **JSON 示例**: `{"contrast_stretch": ""}` 或 `{"对比度拉伸": "参数1, 参数2"}`


### `fuzzy_enhancement`

- **中文别名**: 模糊集增强

- **说明**: 模糊集空间增强：低/中/高灰度隶属度加权。

- **JSON 示例**: `{"fuzzy_enhancement": ""}` 或 `{"模糊集增强": "参数1, 参数2"}`


### `gaussian_filter`

- **中文别名**: 高斯滤波

- **说明**: 高斯平滑。参数: kernel_size, sigma (默认 5, 1.0)

- **JSON 示例**: `{"gaussian_filter": ""}` 或 `{"高斯滤波": "参数1, 参数2"}`


### `highpass_filter`

- **中文别名**: 高通滤波

- **说明**: 高通滤波（原图减低通）。参数: kernel_size (默认 15)

- **JSON 示例**: `{"highpass_filter": ""}` 或 `{"高通滤波": "参数1, 参数2"}`


### `histogram_equalization`

- **中文别名**: 直方图均衡化

- **说明**: 直方图均衡化。

- **JSON 示例**: `{"histogram_equalization": ""}` 或 `{"直方图均衡化": "参数1, 参数2"}`


### `histogram_matching`

- **中文别名**: 直方图规定化

- **说明**: 直方图规定化（匹配参考图路径或默认均匀）。

- **JSON 示例**: `{"histogram_matching": ""}` 或 `{"直方图规定化": "参数1, 参数2"}`


### `laplacian_sharpen`

- **中文别名**: 拉普拉斯锐化

- **说明**: 拉普拉斯锐化。参数: ksize (默认 3)

- **JSON 示例**: `{"laplacian_sharpen": ""}` 或 `{"拉普拉斯锐化": "参数1, 参数2"}`


### `linear_transform`

- **中文别名**: 线性变换

- **说明**: 线性变换 g=af+b。参数: a, b (默认 1.2, 10)

- **JSON 示例**: `{"linear_transform": ""}` 或 `{"线性变换": "参数1, 参数2"}`


### `local_histogram_equalization`

- **中文别名**: 局部直方图均衡

- **说明**: 局部直方图均衡（CLAHE）。参数: clip_limit, tile_size (默认 2.0, 8)

- **JSON 示例**: `{"local_histogram_equalization": ""}` 或 `{"局部直方图均衡": "参数1, 参数2"}`


### `log_transform`

- **中文别名**: 对数变换

- **说明**: 对数变换。参数: c (默认 1.0)

- **JSON 示例**: `{"log_transform": ""}` 或 `{"对数变换": "参数1, 参数2"}`


### `mean_filter`

- **中文别名**: 均值滤波

- **说明**: 均值平滑。参数: kernel_size (默认 5)

- **JSON 示例**: `{"mean_filter": ""}` 或 `{"均值滤波": "参数1, 参数2"}`


### `median_filter`

- **中文别名**: 中值滤波

- **说明**: 中值滤波。参数: kernel_size (默认 5)

- **JSON 示例**: `{"median_filter": ""}` 或 `{"中值滤波": "参数1, 参数2"}`


### `power_law_transform`

- **中文别名**: 幂律变换

- **说明**: 幂律（伽马）变换。参数: gamma (默认 0.5)

- **JSON 示例**: `{"power_law_transform": ""}` 或 `{"幂律变换": "参数1, 参数2"}`


### `sobel_gradient`

- **中文别名**: Sobel梯度

- **说明**: Sobel 梯度幅值。参数: ksize (默认 3)

- **JSON 示例**: `{"sobel_gradient": ""}` 或 `{"Sobel梯度": "参数1, 参数2"}`


### `unsharp_mask`

- **中文别名**: 非锐化掩模

- **说明**: 非锐化掩模。参数: amount, sigma (默认 1.5, 3.0)

- **JSON 示例**: `{"unsharp_mask": ""}` 或 `{"非锐化掩模": "参数1, 参数2"}`
