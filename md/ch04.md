# 第4章 频率域滤波

频域增强：DFT/FFT 频谱、理想/巴特沃斯/高斯及带通/带阻、同态滤波。

本章实现 **11** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `bandpass_filter`

- **中文别名**: 带通滤波

- **说明**: 带通滤波。参数: D0 (默认 40)

- **JSON 示例**: `{"bandpass_filter": ""}` 或 `{"带通滤波": "参数1, 参数2"}`


### `bandreject_filter`

- **中文别名**: 带阻滤波

- **说明**: 带阻滤波。参数: D0 (默认 40)

- **JSON 示例**: `{"bandreject_filter": ""}` 或 `{"带阻滤波": "参数1, 参数2"}`


### `butterworth_highpass`

- **中文别名**: 巴特沃斯高通

- **说明**: 巴特沃斯高通。参数: D0, order (默认 30, 2)

- **JSON 示例**: `{"butterworth_highpass": ""}` 或 `{"巴特沃斯高通": "参数1, 参数2"}`


### `butterworth_lowpass`

- **中文别名**: 巴特沃斯低通

- **说明**: 巴特沃斯低通。参数: D0, order (默认 30, 2)

- **JSON 示例**: `{"butterworth_lowpass": ""}` 或 `{"巴特沃斯低通": "参数1, 参数2"}`


### `dft_spectrum`

- **中文别名**: 频谱显示

- **说明**: 显示频谱幅度（对数）。

- **JSON 示例**: `{"dft_spectrum": ""}` 或 `{"频谱显示": "参数1, 参数2"}`


### `fft_filter_pipeline`

- **中文别名**: FFT滤波

- **说明**: FFT 频域滤波完整流程演示：DFT -> 掩模 -> IDFT。

- **JSON 示例**: `{"fft_filter_pipeline": ""}` 或 `{"FFT滤波": "参数1, 参数2"}`


### `gaussian_highpass`

- **中文别名**: 高斯高通

- **说明**: 高斯高通。参数: D0 (默认 30)

- **JSON 示例**: `{"gaussian_highpass": ""}` 或 `{"高斯高通": "参数1, 参数2"}`


### `gaussian_lowpass`

- **中文别名**: 高斯低通

- **说明**: 高斯低通。参数: D0 (默认 30)

- **JSON 示例**: `{"gaussian_lowpass": ""}` 或 `{"高斯低通": "参数1, 参数2"}`


### `homomorphic_filter`

- **中文别名**: 同态滤波

- **说明**: 同态滤波（光照校正）。

- **JSON 示例**: `{"homomorphic_filter": ""}` 或 `{"同态滤波": "参数1, 参数2"}`


### `ideal_highpass`

- **中文别名**: 理想高通

- **说明**: 理想高通。参数: D0 (默认 30)

- **JSON 示例**: `{"ideal_highpass": ""}` 或 `{"理想高通": "参数1, 参数2"}`


### `ideal_lowpass`
