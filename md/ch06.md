# 第6章 彩色图像处理

彩色模型转换、彩色增强与滤波、基于颜色的分割。

本章实现 **13** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `color_contrast_enhance`

- **中文别名**: 彩色对比度增强

- **说明**: 在 HSV 空间增强 V 通道。参数: scale (默认 1.3)

- **JSON 示例**: `{"color_contrast_enhance": ""}` 或 `{"彩色对比度增强": "参数1, 参数2"}`


### `color_edge_canny`

- **中文别名**: 彩色边缘

- **说明**: 彩色边缘（各通道 Canny 合并）。参数: low, high (默认 50, 150)

- **JSON 示例**: `{"color_edge_canny": ""}` 或 `{"彩色边缘": "参数1, 参数2"}`


### `color_region_growing`

- **中文别名**: 彩色区域生长

- **说明**: 彩色区域生长（种子点）。参数: row, col, threshold (默认中心, 25)

- **JSON 示例**: `{"color_region_growing": ""}` 或 `{"彩色区域生长": "参数1, 参数2"}`


### `color_sharpen`

- **中文别名**: 彩色锐化

- **说明**: 彩色锐化。参数: amount (默认 1.0)

- **JSON 示例**: `{"color_sharpen": ""}` 或 `{"彩色锐化": "参数1, 参数2"}`


### `color_smooth`

- **中文别名**: 彩色平滑

- **说明**: 彩色平滑。参数: kernel_size (默认 5)

- **JSON 示例**: `{"color_smooth": ""}` 或 `{"彩色平滑": "参数1, 参数2"}`


### `color_threshold_segment`

- **中文别名**: 颜色阈值分割

- **说明**: HSV 颜色阈值分割。参数: h_low, h_high, s_low, s_high, v_low, v_high

- **JSON 示例**: `{"color_threshold_segment": ""}` 或 `{"颜色阈值分割": "参数1, 参数2"}`


### `color_to_gray`

- **中文别名**: 彩色转灰度

- **说明**: 彩色转灰度。参数: method (weighted|avg|max，默认 weighted)

- **JSON 示例**: `{"color_to_gray": ""}` 或 `{"彩色转灰度": "参数1, 参数2"}`


### `pseudocolor`

- **中文别名**: 伪彩色

- **说明**: 伪彩色（应用 colormap）。参数: colormap (默认 jet)

- **JSON 示例**: `{"pseudocolor": ""}` 或 `{"伪彩色": "参数1, 参数2"}`


### `rgb_to_cmy`

- **中文别名**: RGB转CMY

- **说明**: BGR 转 CMY（C=255-B, M=255-G, Y=255-R）并水平拼接。

- **JSON 示例**: `{"rgb_to_cmy": ""}` 或 `{"RGB转CMY": "参数1, 参数2"}`


### `rgb_to_cmyk`

- **中文别名**: RGB转CMYK

- **说明**: BGR 转 CMYK 并水平拼接四通道（K 为黑色分量）。

- **JSON 示例**: `{"rgb_to_cmyk": ""}` 或 `{"RGB转CMYK": "参数1, 参数2"}`


### `rgb_to_hsi`

- **中文别名**: RGB转HSI

- **说明**: RGB 转 HSI 并拼接显示（OpenCV 用 HSV 近似 HSI 的 H/S/I 通道）。

- **JSON 示例**: `{"rgb_to_hsi": ""}` 或 `{"RGB转HSI": "参数1, 参数2"}`


### `rgb_to_hsv`

- **中文别名**: RGB转HSV

- **说明**: RGB(BGR) 转 HSV 并拼接显示通道。

- **JSON 示例**: `{"rgb_to_hsv": ""}` 或 `{"RGB转HSV": "参数1, 参数2"}`


### `rgb_to_ycbcr`

- **中文别名**: RGB转YCbCr

- **说明**: 转 YCbCr 并水平拼接。

- **JSON 示例**: `{"rgb_to_ycbcr": ""}` 或 `{"RGB转YCbCr": "参数1, 参数2"}`
