# 第11章 表示与描述

表示与描述：链码、多边形、区域矩、纹理、PCA、Harris/SIFT/ORB。

本章实现 **11** 个图像处理方法，可通过 `main.py` JSON 配置按序调用。

## 方法列表

### `chain_code_boundary`

- **中文别名**: 链码边界

- **说明**: 链码边界绘制。

- **JSON 示例**: `{"chain_code_boundary": ""}` 或 `{"链码边界": "参数1, 参数2"}`


### `harris_corners`

- **中文别名**: Harris角点

- **说明**: Harris 角点。参数: block_size, k, threshold (默认 2, 0.04, 0.01)

- **JSON 示例**: `{"harris_corners": ""}` 或 `{"Harris角点": "参数1, 参数2"}`


### `marked_graph_boundary`

- **中文别名**: 标记图边界

- **说明**: 标记图边界：为每个连通区域分配不同颜色边界。

- **JSON 示例**: `{"marked_graph_boundary": ""}` 或 `{"标记图边界": "参数1, 参数2"}`


### `orb_features`

- **中文别名**: ORB特征

- **说明**: ORB 特征点。参数: nfeatures (默认 500)

- **JSON 示例**: `{"orb_features": ""}` 或 `{"ORB特征": "参数1, 参数2"}`


### `pca_projection`

- **中文别名**: PCA重建

- **说明**: PCA 降维重建。参数: components (默认 50)

- **JSON 示例**: `{"pca_projection": ""}` 或 `{"PCA重建": "参数1, 参数2"}`


### `polygon_approximation`

- **中文别名**: 多边形近似

- **说明**: 多边形近似。参数: epsilon_factor (默认 0.02)

- **JSON 示例**: `{"polygon_approximation": ""}` 或 `{"多边形近似": "参数1, 参数2"}`


### `sift_features`

- **中文别名**: SIFT特征

- **说明**: SIFT 特征点绘制。

- **JSON 示例**: `{"sift_features": ""}` 或 `{"SIFT特征": "参数1, 参数2"}`


### `surf_features`

- **中文别名**: SURF特征

- **说明**: SURF/ORB 替代（OpenCV 4 可能无 SURF）。使用 ORB 若 SURF 不可用。

- **JSON 示例**: `{"surf_features": ""}` 或 `{"SURF特征": "参数1, 参数2"}`


### `texture_glcm_vis`

- **中文别名**: 纹理方差

- **说明**: 纹理统计（局部方差图）。

- **JSON 示例**: `{"texture_glcm_vis": ""}` 或 `{"纹理方差": "参数1, 参数2"}`


### `texture_spectral_vis`

- **中文别名**: 纹理频谱

- **说明**: 纹理频谱特征：对数幅度谱可视化。

- **JSON 示例**: `{"texture_spectral_vis": ""}` 或 `{"纹理频谱": "参数1, 参数2"}`


### `texture_structural_vis`

- **中文别名**: 纹理结构

- **说明**: 纹理结构特征：局部梯度方向一致性。

- **JSON 示例**: `{"texture_structural_vis": ""}` 或 `{"纹理结构": "参数1, 参数2"}`
